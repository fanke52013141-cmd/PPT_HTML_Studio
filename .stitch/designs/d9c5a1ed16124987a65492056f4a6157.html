01 Token是模型处理文本的基本单位

搞清楚 Token 到底是什么

Token 是模型处理文本的基本单位。

分词器切分

Token 由分词器按规则从连续文本中切分而来。

边界 ≠ 单词

Token 的边界并不等同于日常的单词: 块大小不一, 部分与单词边界不对齐。

编号 → 向量

每个 Token 对应词表中的编号, 模型把编号转成向量再计算。
