## 已实现

- 预览重任务复用 local_jobs、账号上下文、受限执行器。前端保存任务 ID、显示阶段进度、支持显式取消；关闭或切页不会冒充服务端取消。返回原页再次点击预览恢复当前 revision 的任务。
- 取消在笔迹逐帧生成、编译和发布边界检查；结果发布前重新校验 revision 和输入快照。已完成任务读取也检查输入过期。
- OCR 在网络调用后、项目锁内重新检查当前图片哈希、取消状态及布局快照，防止换图、取消或人工纠正期间旧识别覆盖当前布局。
- 兼容统一 API Key 与 AK/SK 签名；新增 Secret Access Key 密码输入和脱敏存储。凭据不进入公开快照、报告或源码。鉴权依据百度官方 BCE v1 规范 https://cloud.baidu.com/doc/Reference/s/njwvz1yfu-en 。
- AI/定位重复点击保护，页级失败不再显示成功。动态目标冲突保留关联文字时间、目标就绪时间、差值，通过持久任务返回可读诊断。
- 任意改写的 TTS 文本不再以 difflib replace 整段映射冒充原文精确定位；对齐缓存引擎版本更新，旧缓存不复用。
- 人工校准增加前/后一帧、当前位置前后 1 秒循环试听、恢复讲稿定位。网页实际验证后一帧为 0.033333 秒。
- 修复正式导出发现的两个阻塞：内部 Step 10/9 与输出 Step 8 的历史状态转换兼容；build_remotion_props.py 直接 CLI 执行不依赖外部 PYTHONPATH。
- 统一八个可见步骤映射，状态转换使用实际流程顺序 1、2、3、4、5、6、7、10、9、8；输出完成保留标注状态和可选数字人状态。修正输出列表写死的 v5 标签。
- 修复刷新后直接进入输出页时标注侧栏误显示“待完成”：项目入口先加载保存的标注决策，跨项目复位清除旧决策；浏览器刷新重进已显示“已完成”，并增加延迟旧项目响应不污染新项目的回归测试。
- 修复分镜 resize 事件在旁白模块尚未加载时访问未定义函数的错误，回退到共享 textarea 调整函数。新一轮浏览器加载未出现该错误（开发日志仍保留早前错误）。

最后补充验证：annotation save flow 与 frontend quality 均通过，git diff --check 通过。test_workspace_ux.js 无法独立运行，当前根目录 Node 环境缺少 playwright；以上网页交互验收通过 Codex 浏览器工具进行，不能把该脚本记为通过。

## 100 条精度验收

固定样本：`checks/fixtures/annotations/alignment_acceptance_100.json`。普通中文 30、重复 15、长句后段 15、数字金额百分比 20、中英混合 10、停顿/语速 10。字段标记 development/held_out，尚无音频和人工真值。

评测入口：`python scripts/evaluate_annotation_alignment.py <已标注JSON> --output <报告JSON>`。

拒绝重复 ID、模型作为真值、音频哈希不匹配和非法时间；缺真值不算通过。冻结门槛：至少 100 条、自动可靠覆盖 ≥90%、P95 ≤150ms、可靠样本无 >300ms 严重误判。目前 automatic_coverage=0、p95=null、passed=false。样本字段 truth_source=human 是要求，**不表示已经由人工标注**。
