## 100 条独立人工标记

- 项目：隔离项目 `annotation_truth_100`，端口 8015，任务 `908a573dcd9d431aa22b2d6627251a32`。
- 使用当前配置的 MiniMax `speech-2.8-hd`，通过正式后台 TTS 接口和网关配额执行；没有增加额度或绕过限流。
- TTS 先生成暂存文件，整批完成并检查输入版本后才发布。因此正式音频目录的数量不能代表当前合成进度。
- `scripts/watch_annotation_truth.py` 只读取已完整生成、讲稿与样本一致的暂存结果，复制到独立验收目录，固定音频哈希；不提前发布到项目音频目录。最多等待两小时，超时记录失败，不冒充完成。
- 审核入口：`http://127.0.0.1:8017/`。浏览器页面不提供模型预测时间；预测文件存放在公开目录之外。逐帧定位已实际验证为 0.033333 秒，服务器支持音频范围请求。
- 输入标记者编号，听音，定位高亮短语第一个实际发音的起点，保存本条，最后导出 JSON。同一句内重复短语按高亮位置区分。标记文件绑定音频哈希；音频变化不能复用旧标签。
- 模型预测将在音频收集齐后，使用当前生产对齐工作器逐条计算并保存，仍不写入人工标签。

输出：`outputs/annotation-bcd/human-truth/`。`public/status.json` 是音频快照数量的当前状态；`public/index.html` 为标记页面；`predictions.json` 和 `alignment/` 不通过审核服务器公开。

合并并评估人工结果：

```powershell
python scripts/merge_annotation_truth.py --predictions outputs/annotation-bcd/human-truth/predictions.json --labels <人工导出的JSON绝对路径> --output outputs/annotation-bcd/human-truth/evaluation
```

验收门槛保持不变：100 条已标记、自动可靠覆盖至少 90%、P95 不超过 150ms、可靠预测没有超过 300ms 的严重误判。重复 ID、未知 ID、没有标记者、音频哈希不一致和超出已知音频时长的真值会被拒绝。

样本设计限制：100 条中只有 26 种不同讲稿；音频是逐条请求生成，最终还需核对不同音频哈希数。固定样本中“停顿语速”目前是文本分类标签，统一供应商速度并没有额外覆盖不同速度、真实停顿变体；不得把分类名称当作这些声学条件已经验收。

## 动态 Mask 完整场景

三组精确 RLE Mask：标题 0 秒出现，人工标注目标 4.5 秒开始出现，智能标注目标 8 秒开始出现；各自出现动画 0.4 秒。两条笔迹在 6.133333 和 11.2 秒起笔，目标就绪时间为 4.9 和 8.4 秒，满足先出现目标再同步绘制。

分别使用 1920×1080、1080×1920 画布。音频来自已保留真实来源信息的 Windows SAPI 录制夹具，本轮动态场景不冒充重新调用 MiniMax。

每种画布比较 12 帧：0、134、147、183、193、202、239、252、335、345、354、446。覆盖目标出现前后、两条笔迹起笔前/中途/完成、末尾状态。预览与最终 Props 的 build_id、事件时间完全相同；每种画布实际复制的 24 个笔迹 PNG 文件全部哈希相同。

浏览器截图排除播放器控制条后，完整画面与缩放成片的 RGB 平均绝对差为 1.67–3.87（0–255）。这不是逐像素相同的证明；浏览器字体回退、截图缩放和 MP4 压缩的差异尚未分别量化。轨迹资产和时间一致，主体画面抽样检查通过。

晚出现反例：将人工标注目标改为 7 秒出现，服务拒绝预览，返回 `target_not_ready`、关联内容起点 6.104、目标就绪 7.4、差值 1.296 秒。恢复 4.5 秒出现后，预览、确认、导出成功；没有通过推迟笔迹起点掩盖冲突。

另有自由筆迹与人工音频时刻测试：两笔区域路径经正式 PATCH/预览/确认/导出，第二条采用音频时刻 10.682 秒加播放延迟后起笔。该笔迹是 API 测试输入，不能宣称已覆盖真实鼠标手绘全流程。

证据目录：`outputs/annotation-bcd/dynamic/`，包括两份渲染结果、预览结果、24 个预览截图、24 个成片截图、`asset-equivalence.json`、`comparison.json`、冲突/修复及自由笔迹测试结果。
