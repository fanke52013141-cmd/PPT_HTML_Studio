# 原生时间戳与局部对齐验证（2026-10-06）

结论：原生词级时间戳的数据链路与一段实际音视频导出已验证；局部对齐在原24条上略有退步，不采纳。自动时间精度的全面人工验收仍未通过。

## 原生时间戳

使用配置的 MiniMax 模型与音色，以同步接口新合成一段测试语音，请求 subtitle_type=word。服务返回 subtitle_file；下载的 JSON 外层只有一条句子，内部 timestamped_words 有25条实际字级区间。不能以外层条目数判断它只有句级时间。

正式代码已接通：

- 通用 TTS 的 MiniMax 子进程请求词级字幕；该参数只用于同步接口，现有异步接口不擅自切换。
- 下载并保存未经字幕拆分的原始时间戳，绑定对应音频 SHA-256。
- 定位模块优先读取有效原生词级区间，核验整个发音文本序列，并映射到讲稿码点位置。重复短语按顺序绑定。
- 音频哈希不符、缺词、文字不符、非法时间和明显重叠时回退原对齐器。
- 多字词保留服务实际给出的整体区间。仅选择其中一部分时不按字数拆时间，该锚点需要更细定位或人工校准。

原24条均未保存原生词级数据。新探针是不同音频，因此没有用原标签为它计算精度，也没有覆盖原24条音频。

## 局部对齐

对原24段音频使用同一固定中文模型，以锚点前后各6码点上下文重新对齐；音频窗口由原声学对齐区间推导并各留120ms，未使用人工时间决定窗口。

| 指标 | 原整页对齐 | 局部声学上下文试验 |
| --- | ---: | ---: |
| 150ms内 | 16/24 | 15/24 |
| P50 | 103ms | 107ms |
| P95 | 241ms | 242ms |
| 最大误差 | 770ms | 790ms |

该候选不进入生产。本试验是基于既有声学窗口的局部重对齐，不等同于可靠原生句级分段；旧字幕按字数分配的区间也不能作为可靠分段证据。

## 实际导出检查

使用真实新音频、既有“核心概念”位图和生产勾画构建器，导出约5.9秒的30fps测试视频。生产 props 和导出使用同一时间轴，包含完整渐进围画轨迹。

- 服务给出的“核”起点：音频2.168889s。
- 页面音频延迟：0.5s；计划轨迹开始：2.7s。
- 第一处可见笔迹：第83帧，2.766667s；完整轨迹：3.3s。
- 绘制阶段橙色像素由0逐步增加至完整轨迹，帧内压缩造成末端少量像素波动；提前帧没有笔迹。
- 完整解码导出音频后与源音频比对：相关系数0.997289，额外时移42.6875ms。此残余时移被明确记录，未改写标签或生产时间。
- 第一可见笔迹相对经上述时移输送的服务起点晚约55.09ms，处于本组150ms同步检查尺度内。

这证明原生时间数据能够正确进入导出与轨迹播放，不证明服务给出的字级边界已经由独立人工验收。测试视频不是全场景验收。
