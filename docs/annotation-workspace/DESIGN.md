# Design System: PPT Studio 勾画标注

## 1. Visual Theme & Atmosphere
按照 Stitch Design Taste 工作流设计一个以任务为中心的编辑器。密度 7、变化 3、运动 2：第一次进入即可知道先做什么。保留现有工作区页头与八步侧栏，主要区域为画面与勾画结果两列；不要把内部数据结构当成用户流程。

## 2. Color Palette & Roles
- 品牌橙 #ee5d36：当前流程、选中勾画、焦点。
- 表面白 #FFFFFF：编辑与结果区域。
- 背景 #F8FAFC：页面与辅助区域。
- 深墨 #0F172A：主操作与正文。
- 次要文字 #64748B：简短操作说明。
- 分隔线 #E2E8F0：结构分隔，不用多层卡片表达步骤。
保持 docs/ui-spec.md 的颜色和 30px 操作规格，优先于 skill 的通用视觉默认值。

## 3. Typography Rules
沿用工作区中文无衬线字体。正文 14px/1.6、区域标题 15px/600、辅助说明 12px；层级用字重与间距表达。避免英文内部术语和过多状态标签。

## 4. Component Stylings
首次使用：一个深色“AI 勾画本页”作为主要入口，明确自动完成识别文字、选择重点和匹配语音。已有结果时，呈现数量、勾画文字与待确认状态；正常几何不额外显示标签，异常保留。
操作保持真实功能：框选/手绘/样式在“手动调整”常显区域；识别文字、定位语音、撤销、重做、预览保留一行。逐字候选与讲稿绑定置于常显的“手动关联讲稿与文字”面板。
加载：在结果区域显示当前实际任务阶段，不伪造进度；禁用重复 AI 提交。错误保留原因与重试入口；已有勾画不隐藏、不删除。
确认按钮置于结果底部，旁边说明确认的是当前页。空页不允许确认。

## 5. Layout Principles
顶部是一条无卡片的流程线：AI 自动勾画 → 检查画面与语音 → 确认本页。由真实标注状态驱动当前步骤，不将浏览预览等同于已确认。
主内容左侧为画面，右侧依次为勾画结果、选中条目编辑、手动讲稿关联。文字候选保留独立的有限高度区域。桌面约 62:38，低于 1000px 单列，移动端工具可换行、无横向溢出。页面标签、页头和所有现有 DOM IDs/API 保留。

## 6. Motion & Interaction
仅活动任务指示与按钮反馈使用 transform/opacity。静止标签不呼吸、不跑马；尊重 prefers-reduced-motion。聚焦和选中明确；手动调整和讲稿关联使用常显 section 与标题，不使用折叠入口。

## 7. Anti-Patterns (Banned)
不堆放说明卡片、不创建三列等宽卡片、不以多个动画争夺视觉重点、不显示“几何有效”等正常内部状态、逐字候选使用有限高度的独立区域、不用假进度、不覆盖用户已保存的标注。
