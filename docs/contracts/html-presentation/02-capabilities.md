# HTML 演示体系：能力目录

所属契约包：0.5.0。现行设计与开发规则基线。
本文件约束对应能力的后续定义与实现，不是已实现清单。具体字段名、建议值和候选
能力仍须通过定义卡、字段模型与样板落定；正式 Schema、运行注册与校验器尚未完成。
规范入口见 [契约入口](README.md)，构建与归属见 [详细说明](01-building-and-ownership.md)，
变更与兼容见 [生产规则](04-production-and-compatibility.md)。

全体系分类以 [体系分类与扩展机制](framework/README.md) 为入口；本文保留基础能力说明。
P01 的有限能力不是完整产品的布局/组件上限。

## 1. 共同约定

公共规范横跨组件、布局、风格、素材、动画与输出，约束它们如何协作。它不规定
所有风格都使用某种颜色、某个字号或某种卡片外观。

| 约定 | 内容 |
| --- | --- |
| 身份 | 页面、节点、组件子项、资源、旁白语块和动作均有稳定 ID；列表重排不能以新的数组下标替换身份 |
| 内容角色 | 标题、副标题、正文、图注、标签、关键数据、引用、来源说明等角色；各风格为这些角色提供具体视觉值 |
| 坐标 | 页面具有明确的设计画布与宽高；排版几何统一使用画布坐标，预览缩放与输出分辨率另行转换 |
| 单位 | 设计尺寸采用画布单位，时间统一为毫秒；帧号与时间转换显式携带帧率 |
| 引用 | 页面通过标识与版本引用风格、布局、组件及资源；不能隐式依赖未登记的全局 CSS |
| 有效性 | 类型、字段、引用、内容容量和动作目标都须可检查；未知类型和溢出不能悄悄消失 |
| 可复现 | 保存场景、版本、资源与解析后的布局/时间结果；相同输入与渲染条件得到相同画面 |
| 分层 | 作者编辑内容与布局意图；排版生成几何；讲稿绑定音频时间；HTML 是这些结果的渲染产物 |

风格包是符合公共接口的视觉实现与组合约束，并非公共规范本身的子集。某种风格
可以选择较少的布局和组件变体，但不改变组件表达的含义。

## 2. 场景数据

场景描述“这一页包含什么”，避免把所有信息埋进 HTML 和 CSS。

| 部分 | 包含内容 |
| --- | --- |
| 页面身份 | 场景 ID、协议版本、页标题/用途 |
| 画布 | 设计宽高、比例、安全区；后续可显式预留数字人区域 |
| 视觉引用 | 风格 ID/版本、布局 ID/版本、组件版本 |
| 内容节点 | 节点 ID、类型、语义角色、文字或组件数据、子节点 |
| 资源引用 | 素材 ID、使用方式、裁切/缩放、必要锚点 |
| 排版意图 | 放入哪个槽位、主次关系、排列方向、尺寸约束和布局参数 |
| 讲稿映射 | 旁白语块 ID、文字、对应页面与节点/文字片段 |
| 动作 | 谁被操作、动作类型、触发语块/时间、顺序、持续时间 |

输入是内容与上述引用；输出是可校验的场景描述。排版后的几何与音频绑定后的时间
结果作为派生产物保存，不和作者输入混为一份任意修改的坐标文件。

“概念、对比、步骤”等讲解意图可以指导选布局，但不等同于固定几何。AI 后续主要
选择登记的能力并填写数据；文本标记语言如有需要，可编译到同一场景。

## 3. 组件体系

### 原子能力

| 原子 | 数据与能力 | 控制粒度 |
| --- | --- | --- |
| 文字 | 内容、富文本片段、语义角色、换行/对齐、可定位文本锚点 | 整段及明确标识的句内片段 |
| 图片 | 资源引用、显示边界、裁切/适配、透明区域及资源锚点 | 整张图及作者登记的锚点 |
| 矢量 | 矩形、圆、线、路径、箭头、填充和描边 | 独立图形与路径 |
| 分组 | 子节点、局部坐标、裁切和整体变换；排列交给声明的布局策略 | 整组及其稳定子节点 |

图标是矢量或图片资产的用途；卡片外观由分组、背景图形和文字组合；不能因为名称
不同就无限增加原子类型。这四类覆盖首轮静态画面，不代表所有课程媒体都能由它们
完整表达。视频、公式、代码、表格等需要登记后续组件及能力。

### 中层表达组件候选

| 组件 | 表达职责 | 主要数据 |
| --- | --- | --- |
| 概念块 | 说明一个概念 | 标题、解释、可选图标/插图 |
| 对比项 | 说明对照中的一个对象 | 对象名、特征列表、可选素材 |
| 步骤项/步骤组 | 表达顺序及当前步骤 | 稳定步骤 ID、名称、解释、连接关系 |
| 指标块 | 突出数值与含义 | 数值、单位、标签、补充解释 |
| 图示标注组 | 在插图旁解释局部 | 插图、资源锚点、标签、连接线 |
| 关系图 | 表达因果、层级或关联 | 节点、边、关系类型 |
| 数据图表 | 表达数值比较或变化 | 数据、轴、系列、标签和可定位数据项 |
| 引用/提示块 | 突出引文、例子或要点 | 内容、来源、用途角色 |

这些是候选目录，不要求首轮全部实现。组件的内容结构、子节点身份、绑定能力是
公共的；色彩、线条、容器外观和装饰由风格配置。组件可以声明通用变体，如
有图/无图、紧凑/舒展；风格选择变体，不复制组件代码。复杂风格可使用登记过的
可复用呈现变体，但必须保留同一语义数据及公共目标接口；不能要求所有视觉差异
都只能通过改几个颜色实现。

例如“对比项”是组件，“左右两列”是布局，“浅色插画”是风格，“左右各解释一种
方法”是页面实例。它们不能合并为一个只供某个风格使用的组件。

## 4. 布局体系

布局接收组件集合、槽位映射、画布、实际字体度量和风格间距，输出区域与节点几何。
优先排版稳定，动画默认沿用排版结果，不因某个元素暂时不可见而重新挤压其他元素。

### 几何版式候选

| 家族 | 常见变化 | 可承载内容 |
| --- | --- | --- |
| 标题聚焦 | 居中、左对齐、标题加辅助图 | 封面、章节、核心结论 |
| 上下分区 | 上标题下主体、上图下解释 | 概念说明、图示、数据 |
| 左右分区 | 左文右图、左右互换、不同宽度比例 | 解释与插图、图示与标注 |
| 多列 | 两列、三列、可变列宽 | 对比项、分类、并列要点 |
| 网格/矩阵 | 卡片网格、行列对照 | 分类、表格、多个指标 |
| 顺序流 | 横向、纵向、阶梯、时间轴 | 步骤、过程、历史变化 |
| 中心关联 | 中心发散、树状、层级 | 关系图、结构说明 |
| 主图叠加 | 大图与边侧/角落文字，明确文字保护区 | 情景页、案例、插图讲解 |

每个登记布局必须包含：槽位角色、可接收的组件类型、数量范围、主次比例、对齐与
间距、文本行数/内容容量约束、素材显示方式、数字人区域适配，以及溢出处理。

容量检查依据真实字体与区域测量，不能只用固定中文字数保证不溢出。溢出策略可以
是换到允许的布局变体、按规则拆页或明确提示修改内容；不得无下限地缩小字号。
自动拆页还需同步讲稿与动作映射，首轮可先报告容量错误。

风格可推荐或约束比例、间距和允许的布局变体，布局算法仍按同一接口工作。换风格
可能改变字体度量，必须重新排版。16:9 和 9:16 属于不同布局目标，不能仅同比缩放。

## 5. 风格包

风格定义“以什么视觉语言呈现”，既包含属性，也包含组合规则与具体资产。

| 类别 | 必须定义的内容 |
| --- | --- |
| 色彩 | 背景、主文字、次文字、强调、容器、边框、图表系列；颜色的语义用途 |
| 字体 | 字体文件/可用来源、回退策略；标题、副标题、正文、图注、标签、数据的字号、字重、行高 |
| 节奏 | 页面留白、区域间距、组件内边距、文字段落间距、信息密度 |
| 形状 | 线宽、圆角、箭头、分隔线、容器、阴影与装饰使用规则 |
| 组件外观 | 对公共组件和通用变体提供的具体外观映射 |
| 素材画风 | 插图色系与线条、图标笔画/填充、背景材质、光影、构图与透明边界 |
| 组合约束 | 允许/推荐的布局变体、强调数量、装饰比例、配图比例和安全区 |
| 动作表现 | 已支持动作的缓动、时长范围、强弱程度；不改变讲稿触发关系 |
| 参考页 | 经过审阅的典型页面、分步状态和可复用配方 |

美感不能只靠文档形容词。参考页和验证过的组合配方需要成为风格包的实际资产。
配方引用既有组件与布局，记录搭配参数，不复制它们的实现。

## 6. 素材体系

素材分为插图、图标、背景/纹理、照片和独立图示对象。来源可以是本地库、设计资源
或 Image2 等生图工具；来源不应改变运行时资源接口。

每项素材登记：ID/版本、用途、所属或适配风格、文件位置、尺寸/比例、透明性、
安全边界、裁切策略、建议槽位、资源内锚点，以及生成/替换所需的描述。

素材与页面的对接顺序是：确定表达对象和槽位 → 确定比例与风格 → 找素材或生成
素材 → 检查适配 → 引用到场景。不要先随机生图，再强行塞进布局。

需要独立出现的对象应独立生成或绘制；需要稳定编辑的标题、数字、图注和标签由
HTML 绘制。任意位图内部对象没有自动产生可控 DOM 节点，须使用锚点或继续标注。

## 7. 讲稿与动画体系

这一部分分开存储语义关联和最终时间：先知道“讲哪一句时操作哪个对象”，再绑定
实际音频时间戳。一个语块可关联多个对象，一个对象也可在多处被强调。

| 类别 | 内容 |
| --- | --- |
| 讲稿语块 | ID、文字、页关联、音频片段/时间戳来源 |
| 目标 | 元素 ID、组件子项 ID、文字锚点或素材锚点 |
| 出现/消失 | 整体或分组显示、淡入/淡出、允许的遮罩揭示 |
| 强调 | 高亮、颜色/透明度变化、缩放、状态切换 |
| 勾画/指向 | 下划线、圈画、箭头、连接线或指示器 |
| 空间动作 | 移动、局部缩放、聚焦；首轮不必全部实现 |
| 组织方式 | 顺序、并行、触发点、持续时间、结束后的保持/恢复 |
| 播放接口 | 当前时间、播放、暂停、跳转、重置、给定时间求画面状态 |

首轮只实现出现、强调、下划线/圈画三类。每个动作可由指定时间直接求值，不依赖
之前是否真的播放过。动画风格和讲解语义分开，例如同一个“出现”可以使用不同
缓动，但始终对应同一语块和同一节点。

讲稿文字变化影响音频与时间绑定；页面显示文字变化主要影响排版、文字锚点和画面，
不能因此一律重做音频。若页面含义与既有讲稿可能不一致，标记语义关联待检查。
具体影响按配套契约的变更矩阵处理。首轮可用人工测试时间戳，生产对齐随后接入。

## 8. 渲染、定位与输出

渲染器接收解析后的场景、风格、素材和时间状态，负责字体/资源就绪、HTML/SVG
生成、预览缩放、排版测量、目标定位、动作应用，以及指定时刻的画面。

定位分三种：元素整体矩形；文字 Range 的多行矩形；素材锚点变换后的画布坐标。
勾画层和页面内容采用同一坐标系，字体/排版变化后重新测量。

| 输出目标 | 共用来源 | 需要独立实现的适配 |
| --- | --- | --- |
| HTML 预览 | 场景、排版、资源、时间 | 浏览器播放与交互 |
| 静态图片 | 给定时刻的 HTML/SVG 画面 | 截图/栅格化 |
| MP4 | 同一时间求值和画面 | 帧渲染、编码、音频及后续数字人合成 |
| 图片型 PPTX | 页面最终/分步快照 | 图片置入幻灯片 |
| 可编辑 PPTX | 结构化节点、几何和风格 | 受支持原生对象映射、局部转图、原生动画支持集 |

输出适配不反向成为组件的业务依赖；对每种输出声明支持集，不能默认任意 CSS
与动画都能映射到 PowerPoint 原生对象。

## 9. 首轮定义范围与风格验证

首轮公共定义覆盖：稳定身份、文本角色、画布/坐标、四类原子、概念块数据、左右
布局接口、风格字段、素材接口、三个动作、语块映射、时间求值和定位。中层组件
目录、完整布局库、自动规划、AI 生图编排、TTS、数字人与原生 PPTX 暂列后续能力。

第一种风格建议为“清爽课程插画风”，这是待讨论的方向，不是已选定的品牌规范：
浅色背景、深色文字、少量强调色、清晰层级、统一线条的插图与图标、克制的动效。
具体色值、字体、尺寸和素材先在参考页上验证，再写入风格包。

第一份样板仍用“两种概念对比”：一个标题、两个概念块、两张素材、三个讲稿语块。
制作该风格下的最终页和逐步呈现状态，检验美感、内容容量与定位。验收后再用
第二种明显不同的风格验证：仅替换风格与资产引用，组件的语义和数据保持不变。

定义阶段的成果是这份模块清单与接口边界；下一阶段成果是一个实际可播放的单风格
样板。定义允许在样板验证中修订，不把未经验证的字段提前冻结为长期兼容协议。
