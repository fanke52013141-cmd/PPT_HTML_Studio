# HTML 演示体系：数据与运行契约

所属契约包：0.3.0。现行设计与开发规则基线。
本文件约束对应能力的后续定义与实现，不是已实现清单。具体字段名、建议值和候选
能力仍须通过定义卡、字段模型与样板落定；正式 Schema、运行注册与校验器尚未完成。
规范入口见 [契约入口](README.md)，构建与归属见 [详细说明](01-building-and-ownership.md)，
变更与兼容见 [生产规则](04-production-and-compatibility.md)。

## 1. 数据层级、来源与归属

### 1.1 文档与页面

| 对象 | 最低字段/职责 | 数据所有者 |
| --- | --- | --- |
| PresentationDocument | documentId、schemaVersion、revision、标题、语言、画布配置、默认风格引用、slideOrder、章节、公共资源、输出配置 | 文档层 |
| Slide | slideId、revision、讲解目的、内容引用、布局/配方引用、节点、语块引用、动作、允许的局部覆盖 | 页面层 |
| ContentUnit | contentId、类型、值、来源定位、重要程度、是否必须呈现 | 内容层 |
| SemanticRelation | 关联内容 ID、对比/先后/因果/包含等关系 | 内容层 |
| NodeInstance | nodeId、组件类型/版本、语义数据、内容引用、槽位/父节点、变体、目标声明 | 页面层 |
| NarrationBeat | beatId、讲稿文字及修订、内容引用、主属页面；音频绑定单独保存 | 讲稿层 |
| AssetReference | assetId、固定资源版本、显示参数、锚点引用 | 素材层 |
| Action | actionId、语义目标、动作类型、触发、参数、时长来源、结束行为 | 讲解层 |
| ResolvedLayout | 输入摘要、环境标识、节点/文字几何、裁切与目标映射、诊断 | 排版派生产物 |
| ResolvedTimeline | 输入摘要、页面/文档时间、动作区间、音频绑定、诊断 | 时间派生产物 |
| RenderBundle | 本次采用的源数据修订、定义、实际资源、几何、时间和渲染条件 | 固定渲染输入集合 |

文档负责页序、章节、默认语言/风格/画布、页码及合成顺序，页面负责本页内容。
首轮一份文档使用一种画布。9:16 派生版本可复用内容身份，但有独立布局与修订，
不得覆盖 16:9 的人工排版。跨页面的引用必须可检查，页面不能各自计算全片时间。

### 1.2 内容覆盖

内容单位说明“为什么有这个对象”。同一个数字在图表、正文和讲稿出现时，应关联
同一来源，才能检查矛盾。首轮只需轻量内容引用，不建设完整知识图谱。
规划要列出必讲内容已映射到哪些画面/语块、哪些省略及原因、哪些对象只是装饰。
关系不能因布局方便被改写，例如并列关系不能自动画成因果箭头；无数值依据的
定性对比不能伪造为具有精确比例的定量图表。来源与讲者备注单独保存，备注默认不显示。

### 1.3 源数据与共同字段约束

内容、组件数据、布局意图、人工约束是编辑来源；几何、文本分行、解析时间是
派生产物。不得让编辑器直接修改派生 DOM 后丢失源数据。
结构树中节点只属于一个父节点，禁止循环包含；语义关系图与视觉包含树分别保存。

字段定义须区分缺省、空值和继承，不能以 0/空字符串等“假值”代表未设置。数值必须
有限，几何尺寸/持续时间的范围显式验证；引用带类型与版本。未知组件类型应报错，
扩展字段使用登记的命名空间，不靠任意字段混入内部样式或逻辑。

样式有三个命名空间：应用操作界面、演示内容、字幕/数字人合成。更换幻灯片风格
不改变工作台按钮的 CSS；字幕与数字人只引用它们需要的演示参数。

## 2. 组件契约与稳定目标

### 2.1 每个组件的定义卡

| 项目 | 必须写明 |
| --- | --- |
| 身份/版本 | type、definitionVersion、兼容的场景协议版本 |
| 语义职责 | 表达什么、适合什么输入、哪些用途不适合 |
| 输入模型 | 字段类型、必填、缺省、可空、默认值、枚举、范围、示例 |
| 变体 | 名称、适用内容、可配参数与范围；保留哪些公共目标 |
| 测量 | 给定内容、字体、区域，返回尺寸需求、最小尺寸、容量与诊断 |
| 内部布局 | 在所分配区域内安排子项；输出局部几何和目标映射 |
| 公开目标 | 可绑定的整体、标题、正文、插图、列表项等；分别支持哪些动作 |
| 状态 | 默认、隐藏、强调、禁用等状态的含义 |
| 风格接口 | 消费哪些语义参数，支持哪些可复用呈现变体 |
| 编辑接口 | 可改字段、可保护字段、复制/删除对子项绑定的影响 |
| 输出能力 | 各目标的原生支持、局部转图、其他降级或不支持 |
| 失败行为 | 长文本、缺图、非法值、缺字、未知变体怎样报告 |

页面布局分配外部区域；组件内部布局只处理本区域子项。组件不能移动兄弟组件，
也不能根据某一页的特殊内容修改全局风格。分组负责包含和变换，排列策略显式引用。

首轮概念块的数据为标题、正文、可选素材及内容引用；公开目标为整体、标题、正文、
插图。图在上方或侧边可以是变体，数据含义和公开目标必须一致。新增外观不必新增
组件类型；新增语义职责才考虑新增类型。四类原子只是首轮渲染基础，不是全部课程能力。

### 2.2 目标不绑定临时 DOM

动作引用实例 ID 和公开目标，例如 conceptA 的 body，不能持久绑定 CSS 选择器、
DOM 子节点顺序或组件内部临时 ID。渲染器把公开目标映射到真实元素和几何。
列表项使用稳定 itemId，不以“第二项”作为身份；装饰子节点默认不成为讲解目标。

文本锚点包含目标、文本修订、引用短语、范围和必要上下文。重复短语不能只靠字符串
匹配。字符范围沿用原项目 annotation_contracts.py：Unicode 码点的 [start, end)，
前端显式转为 DOM UTF-16 偏移，交互选择不切断组合字符。修改文本后必须验证锚点，
找不到或不唯一时标为待检查，不能默默绑定到另一处同名文字。

图片锚点声明点/矩形/路径、资源版本、原图尺寸坐标或归一化坐标。替换图片不因长宽比
相同就自动继承旧锚点。图内对象可被锚点定位，不等于它已成为可独立揭示的图层；
单独出现仍需要分层资源或明确遮罩能力。

### 2.3 身份的生命周期

文档内 slideId/nodeId/beatId/actionId 唯一；定义 ID 与实例 ID 分开。宿主分配正式 ID。
编辑和排序保留身份；复制页面/对象分配新 ID 并重映射内部引用；固定资源版本可共享。
删除对象列出受影响绑定，不能把动作自动转给相邻对象；悬空绑定阻断相关有效性检查。
AI 编辑现有对象只能引用提供的 ID；新增对象可用局部临时引用，交由宿主正式分配。

## 3. 风格、布局、配方与覆盖优先级

### 3.1 职责边界

布局决定区域分配；组件承担表达职责；风格提供视觉参数、变体选择与组合约束；
配方记录经过设计的组件组合、槽位映射、推荐素材、讲解阶段与参考状态。
配方引用公共组件/布局，不复制实现，也不保存某个项目的正文。

纯装饰差异用样式参数；结构差异用登记的可复用呈现变体；新增语义用新组件。
风格包公开它覆盖的组件、变体、布局和配方。只实现概念块外观，不能宣称整个组件库
都已支持。任意风格不必支持任意组合，但必须声明缺项与兼容策略。

### 3.2 参数解析

值解析顺序：组件/布局基础默认值 → 风格参数 → 登记变体 → 配方默认值 →
允许的文档、页面、节点覆盖。后层只能覆盖已声明允许覆盖的字段；解析结果记录
最终值及来源。覆盖顺序不能代替约束检查，也不能依赖 CSS 加载顺序决定。

几何最终由布局输出；风格提供字体、间距和允许范围；配方提供组合偏好；局部编辑
表达作者约束。画布安全区、可读尺寸下限、槽位类型、组件数量、人工锁定发生冲突时
返回具体冲突及来源。作者拖动保存为放置/偏移约束，不能只写回临时像素位置。

### 3.3 切换和扩展风格

切换时保留内容和实例身份，检查新风格覆盖范围、变体、局部覆盖和素材适配，再重排。
缺项时可使用明示的通用变体或报告不支持，不得偷偷保留上一个风格的 CSS。
已被人工锁定的属性先保留并报告冲突，不能为了“统一风格”静默覆盖。

整份演示保持同一概念的颜色/图标含义、术语和素材角色一致；页面之间的视觉节奏
通过布局与密度变化实现。风格验收同时检查跨页一致性和重复是否过多。

公共规范定义文字角色、颜色用途和参数字段；风格填写具体字体/色值/度量与参考页。
组件内部不重复硬编码品牌值。美感参考不只是一张最终截图，还包括各讲解状态。

## 4. 排版、坐标、图层与容量

首轮画布建议为 1920×1080 设计单位，通过配置传入。预览缩放、设备像素比和导出
分辨率另行转换，不能让组件硬编码显示器尺寸。

排版流程：确定画布/永久安全区 → 加载确定字体与资源尺寸 → 解析风格/配方 →
测量内容 → 页面分区 → 组件内部排版 → 溢出/遮挡校验 → 输出几何与诊断。
重试需有界；超长文本可以选择允许的布局变体或报告修改建议，不无限缩字号。
拆页属于内容规划变更，须同步讲稿与动作，首轮不自动拆页。

几何至少含实例/目标 ID、父节点、局部矩形、到画布的变换、裁切、图层和文本分行。
坐标链为：素材原始坐标 → 裁切/适配 → 节点局部坐标 → 父组 → 画布 → 预览窗口。
勾画输出使用画布坐标；旋转对象不能只用未旋转矩形代替实际目标几何。

基础排版在无动画变换时测量，时刻 t 的空间状态在其上应用动作变换。标注默认
跟随同一变换和裁切；固定屏幕标注是单独模式。禁止把已包含动画的 DOM 测量结果
再乘一次动画矩阵。图片裁切后，原图锚点也必须经过对应的裁切/缩放变换。

默认图层：背景 → 内容 → 内容标注 → 数字人 → 字幕。选框/工具条仅属于编辑 UI，
不进入输出。字幕和数字人通过安全区避让重要内容；特殊叠放需显式声明并检查。
整页裁切、组内裁切和素材裁切分别保存。

暂未出现的元素默认保留位置；动态重排是后续独立能力。初始、各阶段和最终画面
均需检查构图。容量根据实际字体测量，不靠固定中文字数保证所有主题都能放下。

## 5. 讲稿、动作与时间契约

### 5.1 语义与时间分开

作者先定义哪段话操作哪些目标；时间编译器解析开始/结束。无音频样板使用显式
人工时间。音频绑定记录音频版本、语块区间、对齐来源、人工调整和有效状态；句级
回退不能标成精确词级对齐。时间统一为毫秒，偏移是否可为负在字段卡中单独规定，
最终解析出的区间必须位于所声明的有效范围。

文档时间、页面局部时间、音频片段时间分别标记。语块有主属页面；跨页使用显式
区间，不能重复播放整段。交互式逐步讲解可以按阶段驱动，视频导出前必须把点击
触发解析成确定时刻。首轮只实现固定时间播放，不要求完整现场演示交互。

### 5.2 动作状态

| 动作 | 初始 | 过程 | 结束 |
| --- | --- | --- | --- |
| 出现 | 透明且保留布局，目标身份存在 | 显式时长内改变可见度 | 保持可见，除非后续明确消失 |
| 强调 | 基础风格 | 独立强调通道改变允许属性 | 明确恢复/到语块结束/到页面结束/自定区间 |
| 勾画 | 没有笔画 | 按目标几何与进度绘制 | 按保持策略保留/移除，不改原文字 |

动作定义含目标、触发、偏移、持续、缓动、参数、结束策略和所写属性通道。
已确认的实例时长优先于风格缺省；修改风格默认动效参数后重新编译受影响动作。
对象存在、是否参与布局、是否可见是三个不同概念。

### 5.3 冲突与求值

不同通道可并行。首轮同一目标/属性的重叠写入报冲突，不使用“最后播放者获胜”。
未来叠加必须定义合成方法；父子变换按固定层级组合。强调不自动揭示尚未出现的目标。

开始边界取初始进度，结束边界取最终进度再执行保持策略；零时长是离散切换。
活动区间采用 [start, end)。相邻同通道动作在边界先结算前段，再应用后段起点；
后段初值必须声明固定值或承接前段状态。已结束动作的保持值成为通道基础状态，
可被后续明确动作替换；不视为无限长的活动写入。零时长动作同刻冲突也须明确顺序。
无法唯一决定则报冲突。回退、跳转
均从输入时刻计算，不依赖先前触发事件。随机装饰使用固定种子，不读取墙钟决定画面。

页面时长覆盖语音、有效动作和尾部停留。超时动作需报错或显式延长，不能静默截断。
视频由帧号与有理帧率求时间；音频使用样本时间，避免逐帧累计舍入误差。
转场、静音与尾部填充由文档合成安排统一拥有，不由各组件增加时长。

## 6. 素材、字体、就绪与可重复渲染

资源区分定义（用途/要求）、请求（寻找/生成）、版本（实际文件）和引用（某页用法）。
再生图创建新版本，不覆盖已被作品引用的文件。资产记录哈希、真实尺寸、透明边界、
锚点版本、风格兼容及生成描述来源。相同用途的替代图也要检查构图和锚点。

资源状态至少区分待处理、处理中、待审阅、可用、失败。草稿可以显示明确占位符，
正式输出要求实际引用资源可用。失败可定位到资源和页面；取消/重试不得破坏旧的
可用版本。同输入请求应有去重/复用标识，具体生成治理在原应用集成时复用。

字体属于受版本控制的资源，记录实际字体/字重、加载结果与采用的回退。替换字体
在预览中可见；正式导出采用已确认且可记录的字体方案。文字规范涵盖中英混排、
数字、标点、行高、字间距、断行、上下标与缺字；公式/代码交给后续专用组件。

RenderBundle 固定源文档修订、组件/布局/风格版本、资源/字体哈希、几何、时间、
画布、渲染器/浏览器版本及输出配置。ready 意味着字体就绪、图片解码、布局和目标
解析完成、没有阻断诊断，不能只依赖 DOMContentLoaded。

可重复的承诺限定于相同受控环境。跨浏览器和系统的像素一致性需要实测，不能由
使用 HTML 推导。首轮固定一种渲染环境；预览与导出使用同一输入修订。
作品引用逻辑资源 ID/包内相对路径，宿主解析本机路径。固定 D 盘开发目录不等于
作品可以永久绑定 D 盘。离线传播必须收集实际依赖，不能把在线资源引用称为自包含。

## 7. 人工编辑与 AI 生成边界

最低操作目录：改文字、换素材、换布局/风格、调允许的样式/位置、绑定语块、调动作、
排序/复制/删除页面、撤销/恢复。首轮可通过结构化文件编辑验证，完整编辑器后建。

人工保护分内容、排版、样式、素材和时间，不用一个总开关。局部重生成只修改授权
范围。提交携带 expectedRevision，修订冲突时返回差异，不覆盖新修改。撤销恢复
源数据及引用，再重新判断派生产物是否有效。

规划输入包括材料/来源、受众、表达目的、时长/页数约束、目标比例、必讲项与人工
保护。先生成内容分组、页面目的、讲稿及映射，再选择登记的组件/布局/风格与素材。

AI 提交结构化提案和资源需求；宿主分配身份、解析默认值、检查引用、内容覆盖、
容量和输出能力。失败返回具体诊断与有限修复范围，不无限整页重写。本文没有新增
生产 Prompt；后续 Prompt 工作依照项目既有优化流程。
普通文字按文本处理，富文本仅使用协议支持结构；任意脚本、外部 CSS 和未知组件
不属于首轮生成输入。扩展渲染能力另行登记其数据、公开目标与导出边界。

## 8. 版本、编辑影响与任务快照

schemaVersion 表示文件结构；definitionVersion 表示组件/风格定义；revision 表示
用户内容修订；inputFingerprint 表示某个产物的实际输入摘要。四者不可互代。
旧作品固定引用版本，新风格发布不自动改变旧作品；升级显式迁移并检查。不能把
未知较新协议按旧版读写后默默丢字段。

作者数据与派生产物分开，缓存失效不等于删除用户内容。旧作品可继续查看并标注
对应修订。任务绑定启动时快照；结束时已有新修订，则保存为旧修订结果，不覆盖
“当前最新”。重试/恢复须验证输入快照，不能混合两次修订的帧、素材或音频。

| 变更 | 重新计算/检查 | 通常可复用 |
| --- | --- | --- |
| 纯颜色变化 | 画面、相关输出、视觉检查 | 音频、文字几何、动作时间 |
| 字体/字号/间距 | 排版、锚点几何、标注、画面输出 | 未改的讲稿、音频和显式时间 |
| 页面显示文字 | 本页排版、文字锚点、画面、内容/讲稿一致性 | 未改变的语音输入与音频文件 |
| 讲稿文字 | 音频确认、对齐、动作时间、字幕、口型、合成 | 未改素材及页面基础布局 |
| 配图替换 | 素材适配、锚点、画面；必要的局部排版/语义检查 | 无关节点、未改音频 |
| 布局/画布比例 | 该规格排版、安全区、空间定位、画面输出 | 内容、兼容资源与未改音频 |
| 动作顺序/时长 | 时间、画面、必要的页时长及全局合成 | 基础几何与原音频 |
| 语音时长/语速 | 对齐、页面/全局时间、口型、合成 | 未改场景及基础几何 |
| 页面排序 | 全片合成、页码/章节引用、跨页语义 | 页面本地内容和语音 |
| 字幕样式/数字人位置 | 合成、安全区；区域改变时必要重排 | 原音频及未受影响布局 |
| 无实际变化的保存 | 不失效 | 全部原有有效结果 |

按输入依赖尽量缩小范围；描边宽度/阴影可能影响边界，不按纯颜色处理。字节输入
仍新鲜与语义仍一致分别判断：显示文字改了可以保留音频文件，但若与语音矛盾，
作品的内容检查不能因此自动通过。
集成时扩展现有 impact_registry.py/project_impact_service.py；路径接入
repository_paths.py；持久化与 Agent 同步遵守 AGENTS.md，避免另建脱节的规则。

## 9. 输出能力与合成接口

根据实际节点、样式、动作、媒体生成能力报告：原生支持、转图、静态/分步降级、
不支持及原因。降级须处于所选输出策略内，要求全部可编辑时不能静默用整页图片。

| 能力 | HTML/视频 | PPTX |
| --- | --- | --- |
| 文字、基本形状、图片 | 首轮目标 | 原生对象候选，需验证字体/定位 |
| 复杂 CSS | 登记渲染器能力决定 | 局部转图或不支持，按输出策略 |
| SVG 图形 | 记录实际支持范围 | SVG、位图或原生形状分别验证 |
| 讲解动作 | 固定时间/阶段求值 | 原生动画、分步快照、最终状态分别声明 |
| 数字人/字幕/配乐 | 合成轨处理 | 嵌入媒体/静态替代/省略另行定义 |
| 点击交互 | 预览可按能力支持 | 视频先解析固定时间；PPTX 交互另行映射 |

合成接口预留旁白、字幕、数字人、背景音、转场、尾部停留。媒体轨有来源修订、
起止时间、显示区域/裁切、音量/静音。数字人口型绑定实际音频版本，不能只按页面
ID 复用。首轮仅使用测试旁白，其他轨为空。
静态导出明确最终状态或给定时刻；分步快照明确取哪些阶段。输出配置含页序、时长、
分辨率、帧率、色彩、透明性和资源打包方式。输出声明不等于已通过兼容性测试。

## 10. 验证、诊断与美感验收

校验顺序：结构/类型 → 引用/版本 → 内容覆盖/语义 → 资源/字体 → 排版/定位 →
动作/时间 → 输出兼容 → 视觉审阅。通过机器检查不等于通过美感验收。

诊断至少含 code、severity、stage、对象 ID、字段路径、原因、修复方向、是否阻断
当前输出。建议错误码有 MISSING_TARGET、TEXT_OVERFLOW、FONT_UNRESOLVED、
ACTION_CONFLICT、STALE_ANCHOR、UNRESOLVED_TIMING、UNSUPPORTED_EXPORT；具体枚举
在实现前统一登记。需要检查什么、由谁修复，应比“生成失败”更明确。

| 维度 | 客观检查 | 人工审阅 |
| --- | --- | --- |
| 信息 | 内容映射、遗漏、来源、数字一致、关系存在 | 解释准确、重点清晰 |
| 排版 | 越界、截断、意外遮挡、间距和保护区 | 留白、重心、密度 |
| 风格 | 参数/变体/素材兼容、实际字体 | 文字与素材协调、视觉成熟度 |
| 动画 | 时间冲突、目标跟随、跳转状态 | 节奏是否帮助理解、强调是否过多 |
| 输出 | 支持集、时间与帧、资源完整 | 预览与作品的可见差异是否接受 |

首个风格参考集含最终页、初始与各讲解阶段、长标题/正文、替换内容和不同配图比例。
扩展时覆盖图文、对比、步骤、数据等代表页面，不能由一个漂亮封面推导整个风格成立。
具体最小字号、行数、对比要求、间距容差与截图差异阈值，在风格和运行环境确定后
填入验收卡并实测；当前不编造统一美感分数。截图比较只能提示变化，不替代审阅。

按阶段覆盖：长文本、中英数字混排、emoji/组合字符、重复短语、缺字体/图片、换图、
子项重排、换风格、预览缩放、父组变换、动作重叠、无音频预览、音频重做、跳转回退、
复制/删除、无变化保存、旧修订任务完成、未知输出能力。未实现功能不写空洞测试。

## 11. 样板的数据流与变更示例

用“两种概念对比”：两项内容、两个概念块、三段讲稿。先分别介绍，再讲两者关系。

1. 文档保存内容及关系，页面和语块引用各自覆盖的内容。
2. 选择左右配方，建立 conceptA/conceptB，公开 title/body/figure。
3. 风格提供文字与概念块变体参数，素材引用固定版本。
4. 页面布局分区域，组件内部排版，得到正文分行与插图几何。
5. 语块绑定公开目标；显式测试时间编译成动作区间。
6. 指定时刻求可见性、强调与勾画；同一输入集合驱动预览与输出。

换色只更新画面；正文增长重排并检查文字锚点；语音重做绑定新时间；复制页重映射
实例和动作；换风格保留公开目标。每个变化都能说明失效与复用范围，才算验证了契约。

## 12. 后续定义卡与完成标准

每张卡填写：ID/版本、用途/边界、输入字段（类型、必填、可空、默认、范围、示例）、
输出、依赖、公开目标、状态、失败、修改影响、输出兼容、验收样例、实施阶段。

| 卡片 | 专有字段 |
| --- | --- |
| 文字角色 | 语义、富文本、换行/截断、语言/标点、锚点、字体参数 |
| 原子/组件 | 内部结构、测量、子项身份、公开目标、变体、几何、动作、编辑性 |
| 布局 | 槽位、容量、比例、约束优先级、安全区、溢出、重排/拆页 |
| 风格 | 参数完整表、覆盖矩阵、素材规则、配方、动效默认、允许覆盖、参考页 |
| 配方 | 表达意图、组合、槽位映射、素材建议、讲解阶段、限制和参考状态 |
| 素材 | 用途、比例、透明边界、裁切、锚点、版本、替换/审阅 |
| 动作 | 初始/过程/结束、属性通道、时间来源、冲突、跳转、保持 |
| 输出 | 输入集合、支持集、降级、时间/分辨率、资源携带、兼容实测 |

卡片“定义完成”须有正常与边界例子、明确失败行为且不与相邻模块冲突。写代码前
再把字段转成 Schema/类型；抽象未通过样板验证前不承诺长期兼容。
