# 组件、布局、风格与动作的定义卡模板

所属契约包：0.5.0。填写后的卡片是具体能力的契约，不能只保留自然语言功能介绍。
本文件是模板；下列空栏不表示已有实现或已选定设计。

## 1. HPS-018：定义卡完成条件

一张卡必须能回答：谁提供什么输入、谁产生什么结果、什么可以由风格改变、什么
可以由用户修改、哪里会失败、失败怎样呈现、改动影响什么、如何验证。字段之间及
相邻组件之间的约束必须一致，所有 TODO 都标注影响阶段。

状态分别记录：定义状态 draft/specified/deprecated；实现状态 not_implemented/
implemented；验证状态 not_verified/partial/verified。定义完成不自动提升后两者。
这里只定义记录用语，未向应用增加同名运行枚举。

## 4. 通用协作接口

- 依赖：字体、资源、其他组件、布局、环境及版本。
- 公共目标：名称、含义、子项 ID、文本/图片锚点、支持动作。
- 排版：测量、最小尺寸、内部排列、坐标/裁切、溢出处理。
- 外观：消费的语义参数、登记变体、主题缺项处理。
- 时间：初始/活动/结束状态、属性通道、冲突、跳转和保持。
- 编辑：可改字段、人工保护、复制/删除/重排及引用处理。
- 输出：各格式原生支持、转图、其他降级或不支持。
- 错误：诊断码、严重度、对象/字段路径、修复方向、阻断范围。
- 兼容：引入版本、旧数据处理、升级与恢复、受影响派生产物。

不适用项填写“不适用及原因”，不为每个原子伪造完整的业务接口。

## 5. 不同类别的必填补充

| 类别 | 专有定义 |
| --- | --- |
| 文字 | 角色、富文本、语言/标点、换行、字体、字符范围与定位 |
| 图片/素材 | 语义用途、实际尺寸、比例、透明边界、裁切、锚点、资源版本 |
| 矢量/分组 | 路径或子项结构、包含关系、变换、裁切与图层 |
| 语义组件 | 内容模型、子项身份、内部结构、公开目标、呈现变体 |
| 布局 | 槽位类型、数量/容量、比例、约束优先级、安全区、溢出 |
| 风格 | 完整参数、字体与资产、支持矩阵、允许覆盖、配方与参考集 |
| 配方 | 讲解意图、组件组合、槽位映射、素材要求、阶段与边界 |
| 动作 | 目标类型、触发、时长、初始/终态、属性通道、冲突和结束策略 |
| 输出 | 输入集合、分辨率/时间、资源携带、支持矩阵、降级与实测 |
