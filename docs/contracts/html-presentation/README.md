## 适用范围与效力

本目录是新 HTML 演示路线的规范入口，用于今后的定义、实现、AI 生成接入、素材
生产和验收。用户本轮已要求将定义作为项目规则，故基础原则与协作约束从本版本起
约束后续工作。尚未确定的字段名称、具体参数和能力明确保留待定义状态，不能声称
它们已经成为运行 API。

现有图片路线继续遵守原规则。课程/项目管理、数据库迁移、Agent 同步、任务和
影响登记继续遵守项目 AGENTS.md。本契约不替换这些既有服务的职责。

正文的“必须/不得”为约束，“应”为推荐，“可”为允许选项；“示意/建议/候选/待确定”
不等于正式字段或已支持能力。示例不能覆盖规范正文，索引不能覆盖其所指正文。
发现正文之间的矛盾时须登记并在同次改动中统一，不允许临时选择有利于当前实现的一句。
用户明确的新要求优先，应将受影响规则同步修订并记录理由。

当前实现状态必须独立报告：规则已存在，不代表自动执行、视觉验收或导出兼容已通过。
实施具体能力前，先填写定义卡和字段模型，再实现校验/渲染并取得对应验证证据。

## 唯一事实来源

本入口及索引负责版本、规则位置与状态；各正文负责对应领域的规则。定义卡记录某个
具体组件/布局/风格的契约，未来 Schema/注册表与它同步。相同规则不得在 Prompt、
组件代码、样式文件或其他计划文档中另维护一套不同解释。

原 docs/plans 下的基础定义、协作草案和审查记录保留为历史依据，不再作为新的
规范修改位置。路线图只记录阶段安排，不能自行改写生产规则。
