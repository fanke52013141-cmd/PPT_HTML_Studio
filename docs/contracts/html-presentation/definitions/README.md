## 所有卡片共用的字段约定

表中的“必填”表示不得缺省；“可缺省”只按所写默认处理；P01 字段一律不接收 null，
除非卡片明确允许。未知字段报 INVALID_FIELD，只有根/节点的 `extensions` 可以承载
已登记命名空间；首轮其允许值为 `{}`。不执行其中的脚本、HTML 或 CSS。

- `Id`：宿主分配的 ASCII 稳定标识，模式 `[A-Za-z][A-Za-z0-9._-]{0,95}`。各类型 ID
  在文档内唯一；跨类型可以同名，但所有引用必须带语义类型。数组顺序不是身份。
- `VersionRef`：`{id: Id, version: "主.次.修订"}`，版本不得为 latest、范围或空字符串。
- `revision` / `expectedRevision`：大于等于 1 的安全整数；单次有效源数据变更递增。
- 数值必须有限；整数为安全整数。设计尺寸为画布单位，时间为毫秒；不隐式猜测单位。
- 参数不准以空字符串/0 表示继承；有默认则缺省，无默认则必填。JSON 不允许 NaN/Infinity。
- `contentRef` / `nodeId` / `beatId` / `assetRef` 的引用类型由所在字段决定。
- “实例”指作者源数据，“派生”指排版、参数和时间求解结果，不能从编辑器直接写回源字段。
- 声明所有权：公共定义控制字段语义和硬约束；风格填视觉值；实例选内容与允许参数；
  运行模块生成实际几何和时间。后层不能覆盖前层硬约束。

每张卡的共同兼容策略：本次从尚未有运行格式的 0.3.0 基线增量细化；定义 0.1.0
固定于样例，未声明可读取原图片产物。未来改变字段、目标或默认语义须发新版并记录
数据/行为/视觉/输出四种影响；未知版本拒绝，不按近似结构读取。无现有 HTML 作品需要迁移。

每张卡的共同验收：正常、无效、修改后案例引用边界表；文档一致性可在 P01 检查，
真实测量/播放/视觉/导出分别在 P03/P04/P02/P06 实测。不能把定义审查当运行通过。

## 阶段 1 的决策与后续项

已确定：四类原子、一个概念块、一个两列布局/配方、稳定公开目标、毫秒时间、三类动作、
有界覆盖、资源就绪和分级输出接口。主文档仍是唯一上层规则，具体字段由本目录负责。

P02 决定：实际风格、字体文件/字重、数值参数、插图画风、参考状态、可读性阈值。
P03 决定并实测：实现技术与固定浏览器版本、正式 Schema、测量容差及字体覆盖检测方法。
这些待定项不阻碍字段定义，但阻断对应风格声明 verified 和正式渲染 ready。
示例使用明确标注的中性结构夹具风格；它不代表首个产品风格已选定。

P01 不新增服务、数据库、Agent API 或生产 Prompt；其接入按既有实施卡和计划后续进行。
