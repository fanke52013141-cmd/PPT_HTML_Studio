# 代码美术参考资产定义卡

定义ID：`definition.code-art-reference-asset`；版本0.1.0；2026-10-09。关联 HPS-009/014/022/025/026/028/032/033/037。
归属：[资产形成规范](../framework/12-code-art-reference-assets.md)。状态：设计定义；不是运行API或新Schema。

## 用途与组成

用于将真实代码已呈现的美感传递给生图模型，支持细节、局部组合、完整样页三种尺度；可由多份材料共同组成一个固定参考集。能力测试样例和未审阅美术候选不得自动成为正式参考。

| 字段/记录 | 内容与所有者 |
| --- | --- |
| identity | 稳定asset_id、version、用途、类别；资产登记所有 |
| visual_role | technical_demo / code_art_detail / code_art_composition / code_art_page / design_proposal / illustration 等语义；登记所有 |
| sources | 源码及相应版本/哈希、主题、布局、实例；各源文件所有 |
| effects | 正确效果ID、定义/版本、具体参数和允许组合；效果定义所有 |
| render | 实际截图、画布、浏览器、DPR、字体就绪、取帧状态；派生记录 |
| resources | 字体/图片来源及hash、尺寸、alpha可见边界、锚点、取得/分发说明；资源所有 |
| allocation | code/image/mixed层及对象控制范围；实例与资产职责记录 |
| provenance | 人工设计、真实代码渲染、模型生成/编辑/原像素分割及原素材关系；实际过程记录 |
| files | 仓库相对路径、字节长度、sha256及角色；派生登记 |
| technical_review | 实测范围、结论、失败及未覆盖项；不得扩大成美术认可 |
| visual_review | 用户结论、审过的具体版本、问题与范围；不得由AI自动填通过 |
| usage | 实際任务携带的附件/规则/参数及版本；不存凭据 |
| reuse_scope | 已审布局/内容容量/风格/输出环境及第二内容证据；明确未验证部分 |
| changes | 修改目标、锁定项、纠偏记录、版本替代及失效范围 |

## 约束与交付

截图和源码必须同版本；源输入变化需新修订。系统字体按实际资源记录而不重新分发。图片只能承担已声明职责；混合参考不把插画高光误列为代码效果。代码美术样板本身需视觉审阅，然后才能成为正式生图美术依据。

最少交付源码/可查看样板、对应截图、参数/资源、审阅记录及清单。当前[归档清单](../../../assets/code-art-references/manifest.json)为文档实例，不注册生产能力；其具体JSON字段用于追溯，不宣称为通用已上线模型。

## 兼容与未实施范围

旧E1/E2/P01及生产scene/binding格式不变。自动提取、美术评分、锁定/拖动、参考检索、持久化批准和自动失效未由本卡实现；各能力须在实际实施时定义运行接口及验证。
