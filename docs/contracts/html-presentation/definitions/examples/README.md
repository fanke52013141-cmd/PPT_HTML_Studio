## 样例表达内容与关系

标题是“让画面既精美，又可控制”。左概念说明 HTML 控制文字、布局和动画；右概念
说明独立插图负责视觉表现。contrast 表示二者职责差异，第三语块讲述组合，不能把它
解释成孰优孰劣或具有比例的数值比较。图片不承载必须 OCR 才能读出的文字。

标题/正文通过 contentRef 保持唯一显示文字来源；讲稿以自己的 text 表述并关联同一
知识点。页面 slots 指稳定 nodeId，动作指 nodeId+part，没有 CSS 选择器或临时 DOM ID。
概念内部 Text/Image/Group/Vector 由组件组装，作者场景不重复保存内部实现节点。

## 时间与动作

语块区间：HTML 介绍 [0,4000)，插图介绍 [4000,8000)，组合解释 [8000,12000) ms。
页面共 13000 ms，末尾 1000 ms 停留。没有实际音频；这些是人工测试时间。

| 动作 | 起点 | 过渡/绘制结束 | 效果结束 / 保持行为 |
| --- | --- | --- | --- |
| HTML 概念出现 | 0 | 400 | 13000，保持可见 |
| 插图概念出现 | 4000 | 4400 | 13000，保持可见 |
| HTML 概念强调 | 8000 | 8200 | 12000，恢复基础 |
| 插图概念强调 | 8000 | 8200 | 12000，恢复基础 |
| HTML 正文短语勾画 | 8500 | 9300 | 12000，移除笔画 |

锚点引用正文修订 1，quote=“文字、布局和动画”，码点范围 [0,8)。换文字后必须重新
检查锚点；仅改变字体则范围仍对应相同文字，但需重新测量多行几何。

图片型分步 PPTX 拟取 400、4400、9300、13000 ms；最后时间是显式页末静态状态。
9300 ms 快照有强调和完整勾画，13000 ms 最终页不含临时强调/笔画；若想保留笔画，
必须修改 endPolicy，不能导出器擅自忽略移除规则。

## 替换内容的复用设计

同一结构可替换为“同步学习/异步学习”，只改内容、讲稿、资源引用及相关锚点，不改
公共概念块类型。换风格仍保留原 nodeId/part；素材兼容与几何需复验。
第二种风格的真实复用、实际长正文容量、关键帧画面均在 P05/P03/P04 验收，当前无截图结论。

## P01 可验证与不能验证的项目

可验证：JSON 可解析、类型/引用的文档一致性、ID/版本、必讲覆盖引用、码点范围、
相对资源/哈希、语块与动作算术、链接和状态标记。
不能验证：实际文字分行/缺字、浏览器加载、目标像素位置、动作 seek、画面美感、
编码与 PPTX 打开兼容。这些检查保持待执行，不以本样例通过替代运行实现。
