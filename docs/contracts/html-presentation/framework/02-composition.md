# 页面、嵌套区域与讲解的组合机制

## HPS-020：组合保持语义、身份与约束

组合不是任意粘 HTML。每层通过声明的输入/输出及公开目标连接；区域分配、关系表达、
时间绑定分别求解，再组成固定渲染输入。运行代码尚未实现，以下约束用于后续定义。

## 1. 从旧样板向通用布局扩展

P01 `layout.two-column@0.1.0` 是“标题＋两个概念块”的有限布局，保留原 ID/版本/行为。
不直接把 title 改为可选或允许任意组件，否则旧默认和类型检查会被悄悄改变。

新增候选设计为：

- `page.regions`：声明页面区域，标题可选，主体必需；footer/side-note 等按配方声明。
- `layout.split`：在一个区域中横向或纵向分配子区域，与概念、流程、图片等具体语义无关。
- `layout.stack`、`layout.grid`、`layout.overlay`、`layout.anchored`：其他公共空间策略。
- `recipe.two-concept-contrast` 的未来新版本选择上述区域与布局，另行约束标题/概念数量。

新名称是分类/设计候选，还没有可执行 Schema。具体类型升级时走 HPS-015/021，保留旧读取器
或生成明确的新修订。P01 样例仍采用原布局，不能宣称已支持任意区域嵌套。

## 2. 区域树与最小组合接口

RegionDefinition 的后续字段至少包括：regionId、required/optional、contentSlot、layoutRef、
children、constraints、safeInsets、clip、readingOrder。区域 ID 独立于内容节点 ID；同一内容
换位置时不换 nodeId。实例引用组件，公共布局按所声明 sizing 接口接收它。

| 接口 | 输入 | 输出 / 不变量 |
| --- | --- | --- |
| measure | 内容、已加载字体/素材、可用区域、风格约束 | min/preferred/max 尺寸、溢出原因；不改正文 |
| arrange | 分配区域、测量结果、作者约束 | 子区域与几何，完全记录坐标链 |
| exposeTargets | 实例身份、公开部件/子项、当前几何 | 稳定目标映射；不泄漏 DOM 次序作为身份 |
| evaluate | 固定源修订、时间、基础几何 | 可见度/状态/标注；不隐式重排 |
| describeOutput | 实际对象与效果、目标格式 | 原生/转图/不支持及影响对象 |

组合树禁止循环、多父和重复挂载；需要同一内容显示两次时创建不同 nodeId，共享 contentRef。
一个 region 可以包含 layout 子区域或一个组件；混合形式必须通过显式子区域表示。
根分配画布安全区，子区域不得占用外部安全区；临时隐藏保持布局占位。

尺寸求解先确定父级可用空间，再测量/分配子级；内容自适应父尺寸与百分比子尺寸出现
循环依赖时报 CONSTRAINT_CONFLICT。算法必须有有限迭代/超时与具体诊断，不能无限缩字号。
深度、节点数、复杂关系边数设为运行资源预算；预算由实现能力声明，不能伪装为审美规范。

## 3. 可选标题的语义

无标题是“未创建标题区域”，不是创建空文字绕过必填校验，也不是将 required 标题隐藏。
布局不拥有“必须讲标题”的内容规则；配方/内容计划决定是否有必须呈现的页题。
有标题时 hTitle 由字体实测；无标题时相应 gap 同时消失，主体使用释放空间。
侧标题、主体内标题属于不同配方/区域选择，不强制只有一个顶部标题。

## 4. 逻辑图与几何布局的边界

流程组件拥有 stepId/edgeId/condition；图排布算法输出节点坐标与连接路径。页面布局仅
给流程图一个区域。图拥挤先判断路径/标签避让与容量，再选择登记变体或规划拆页。
不能为了排列整齐删边、反转箭头、合并不同条件或将循环改成线性流程。
树图、表格、图表分别保留父子、行列、系列数据语义；这些接口不能被 Group.children 取代。

## 5. 单页和跨页讲解

NarrativePlan 后续最小字段：planId、patternRef、stageId、contentRefs/relationRefs、
stageOrder、pageAssignments、beatRefs、targetBindings、coverage。阶段身份独立于页号与时间。

例：“总分总”可是一页四个阶段，也可五页：总述→三个分项→归纳。拆页后阶段 ID 保留，
页面/节点映射与音频区间明确重编；跨页同一知识点使用 contentRef，不复用同一个 nodeId。
一段音频分配到多页时记录片段区间，不能每页重播整段。全片偏移由文档合成唯一拥有。

无标题左右对比、上文下流程、左解释右侧再上下分区等例见覆盖矩阵。矩阵描述可构造性，
不是运行测试通过；目前所有新组合都仍需要具体卡与样板实现。

## 6. 组合失效与降级

父区域比例变化：重新测量受影响子树与标注，语块内容/音频通常复用。
关系内容变化：图语义和排布重算，关联讲解检查；不能只更新画面文字。
风格变化：验证组件/变体/资源覆盖并重排；锁定冲突保留作者值并返回诊断。
输出不支持：按明确策略局部转图或阻断；组合中有一个不支持对象不能默默删掉它。
