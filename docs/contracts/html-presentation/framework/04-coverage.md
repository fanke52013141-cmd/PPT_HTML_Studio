## 状态与分批顺序

只有 COV-01 在 P01 的有限结构中已有具体定义，仍未运行。其余各例已完成分类，但至少有一项
字段/组件/布局/动作待定义。所有案例的预览/输出/视觉状态都是未验证。通用框架能够容纳需求
与当前软件能够生成需求是两回事。

第一批：可选页面区域、横纵切分和嵌套，覆盖 COV-02—09；同时补列表与讲解阶段。
第二批：步骤/分支/循环/层级等关系组件与公开子目标，覆盖 COV-10—16。
第三批：对比表、时间线、指标与图表，覆盖 COV-17—22。
第四批：科普内容驱动的图示标注、公式/代码/地图/媒体/模拟及竖屏，按真实课程选择，
不因目录出现就全部挤入首版。首版具体范围仍按实施计划，用样板证据调整优先级。

## 压力维度

各案例另组合：短/长/极长文字；无图/单图/多图；短语重复/emoji/中英混排；有无标题；
横竖比例；图/字体缺失；人工锁定；长标签和密集连线；初始/中间/最终状态；跳转回退；
图片型/原生输出要求。不要穷举笛卡尔积：每项能力至少一个正常/边界/失败/修改案例，
高风险交叉（长中文×窄列、嵌套×旋转×标注、换图×锚点、跨页×音频）单独覆盖。

## 扩展机制验收

无标题对比→区域/配方；分支流程→新语义组件；手绘风→参数/素材/公共变体；
科学模拟→专用状态与渲染协议。四例都能找到所有者、保留公共目标和声明输出缺口。
本轮完成分类演练，正式 Schema、兼容迁移与实现验证按 HPS-021 后续进行。
