# 视觉生产：职责分工、验收模板与内容容量

本文件为契约 0.6.0 的设计规则。关联 HPS-002/003/007/009/013/014/020/022。
尚无运行校验器、生产模板注册表或自动素材流程；下述字段是定义卡要求，不是已实现 API。

## HPS-023：按视觉职责与控制粒度分配实现方式

不能按“整页 HTML 或整页图片”二选一。先确定知识含义、视觉焦点、必须可编辑的内容和
最小动画单元，再逐项分配实现方式。HTML 是最终组装与控制载体，不要求它手绘所有视觉。

| 内容职责 | 默认方式 | 原因及边界 |
| --- | --- | --- |
| 标题、术语、解释、单位、数值、来源 | HTML 文字 | 准确、可改、可测量、可关联讲稿；不得烘焙进生成插画 |
| 数据图表、精确流程/拓扑、因果箭头、标注线 | 结构化数据驱动 HTML/SVG | 数据和连接关系须可核验；不让生图模型决定数值、方向或节点数量 |
| 写实对象、柔和 3D 科普插画、场景、材质、氛围 | 生图或已许可素材 | 承担主要视觉吸引力；科学准确性和美术质量分别审阅 |
| 科学剖面、复杂装置、机制示意 | 混合 | 经科学核对的底图 + HTML/SVG 标签和必要关系；精确几何应取自可靠矢量/模型，不能只靠生图 |
| 简单图标 | 同一套矢量图标库 | 统一线宽、视角与视觉重量；不逐页随机生成同一含义的图标 |
| 特定立体图标/装饰物 | 成套生图素材 | 共享视角、光源、材质与尺度，登记资产；不能与任意扁平图标随意混用 |
| 排版、留白、色块、分隔、基础容器、渐变 | HTML/CSS | 服从验收模板；不为填满空白自动增加卡片/徽章/胶囊 |
| 背景纹理/氛围图 | 可选生图 + HTML 文字层 | 指定安静文字区、对比度和裁切范围；背景不得抢占知识焦点 |
| 整页生成图 | 仅参考图或明确的扁平输出 | 不伪称元素可编辑、可独立出现；需要控制的正文仍需分层重建 |

选择顺序：必须准确或动态编辑→代码/可靠结构化素材；需要独立动作→独立节点/资产；
依赖材质与复杂造型→图像资产；两者兼有→混合。不允许为遵守“纯 HTML”而用简陋图形
替代应有的高质量插画，也不允许为漂亮而把必须控制的知识整体压成图片。

### 素材槽位与生成任务书

先画版式并确定槽位，再生成适配槽位的图，不能生成完才随意塞入。每个任务书至少记录：

- 内容：对象、动作/状态、必要细节、科学禁错点、非写实示意说明、禁止出现的文字/数字。
- 美术：引用风格版本与参考，视角、光向、材质、配色角色、复杂度、统一系列要求。
- 构图：槽位比例、像素尺寸、主体占比范围、主体包围框、留白方向、禁入区、允许裁切范围。
- 层级：透明底或场景底；对象是否需独立出现、勾画或遮挡；目标/锚点和前后遮挡关系。
- 交付：资源 ID/版本、文件与来源、尺寸/透明通道、内容和美术审阅状态、适用模板。

图片中的物体不会因为有锚点而自动独立。独立显隐需要独立透明资产或明确遮罩；
只有勾画/指示可以使用图内锚点。换图后必须重验主体位置、锚点、裁切与遮挡。
生成不可保证一次成功，必须允许重试、人工选图、上传替换和固定已验收资源，避免每次
导出重新生图。生成任务书不是生产 Prompt；实现 Prompt 时继续遵守仓库优化规则。

## HPS-024：生产使用经过视觉验收的页面模板

布局算法负责能否排下；页面模板负责如何排得好看。通用左右布局不等于一个美术模板。
必须在两者之间建立“验收模板”：由公共组件/布局/配方组装，并绑定特定风格的视觉证据。
模板定义可以复用，换风格后视觉验收不自动继承。模板中不增加风格专属业务逻辑。

| 层次 | 公共部分 | 风格/实例部分 |
| --- | --- | --- |
| 语义与原子 | 文字、图片、分组、目标、知识关系、动作接口 | 实际知识、讲稿和资源引用 |
| 布局能力 | 分区、对齐、测量、容量诊断、裁切机制 | 选定分区与受限参数 |
| 模板结构 | 槽位、数量、输入类型、知识关系、控制目标 | 各风格认可的构图参数与参考帧 |
| 风格 | 公共 token 与素材契约的字段 | 字体、色彩、线条、容器、插画语言及禁用组合 |
| 页面实例 | 使用同一生产协议 | 选模板、填内容、选/生素材、关联讲稿 |

固定：区域比例、视觉主次、文字层级、对齐/换行策略、间距、素材构图、内容容量、
动画安全区与关键状态。不固定：具体标题、知识内容、素材主题及已声明范围内的变体。
“固定”不必是所有坐标绝对定位，可为带约束的布局；但不能让生产模型自由改 CSS。

模板定义卡必须含以下内容，缺项只允许 draft：

| 项目 | 必填说明 |
| --- | --- |
| 身份与状态 | ID/版本、依赖布局/组件/风格版本、作者与审阅证据；draft→visual-review→approved→deprecated |
| 使用条件 | 学习任务、语义关系、画布/观看尺寸、支持的内容量；明确不适用情况 |
| 槽位 | 稳定 ID、类型、数量、必填/可选、对应公开目标，不能以任意 HTML 字符串替代 |
| 版式 | 区域比例、基线、间距、标题整体盒、允许换行、留白与主视觉区域、容器使用规则 |
| 容量 | 各槽位字数预估、实际最大行数/高度、信息点数、最低字号；字符预算不能替代测量 |
| 资产 | 生图/矢量/图片选择、比例、主体范围、透明底、裁切/留白/锚点要求 |
| 变体 | 允许调整的枚举与范围；无标题/无图/字幕/数字人须有独立验证，不能随意隐藏后算兼容 |
| 时间 | 初始、逐步、最终状态构图及稳定几何；避免为填空导致动画中整体跳版 |
| 溢出策略 | 换已验收模板、分页或返回规划；不得无限缩字号、截字或静默删必需知识 |
| 验证 | 标准页、换主题页、容量边界、关键状态、实际观看截图；视觉审阅与结构检测分别记录 |
| 输出 | HTML/视频/PPTX 各自支持状态、局部栅格化与编辑限制；未测不能承诺 |

设计阶段允许探索新构图；生产阶段只能选择已验收且运行支持的模板和变体。若无匹配模板，
返回“模板覆盖不足”，进入设计扩展流程，而非临时自由排版。approved 仅表示声明范围内
视觉通过；运行支持、导出通过是独立状态，生产需要同时满足。

模板数按真实讲解任务逐步扩展，不承诺十几种覆盖一切。先完成少量精品模板，经过
替换内容证明复用，再扩充组合。原子复用降低实现成本，模板复用稳定美术质量。

## HPS-025：内容容量与美术质量分别设门槛

讲稿不是屏幕正文。规划必须分开：讲稿全文、屏幕必需知识、屏幕辅助内容、仅口述内容；
每个知识点保留来源/讲稿关联，注明为何上屏或不上屏。定义、限定条件、单位、比较基准
等必需内容不得为美观静默删除。改写与分页不能改变含义；不能满足时返回规划处理。

每页应有明确的主要讲解目的和视觉焦点。一个标题作为一个排版单元；装饰编号、品牌、
英文翻译、栏目名不默认全部上屏。正文、插图和箭头各自承担不同信息，避免重复解释。
一页信息点数按模板预算定义；不存在适用于所有页的“固定三点”或“永远两行”。

验证分四层，任何一层都不能代替下一层：

1. 内容正确：知识、数据、单位、关系及必要限定准确；讲稿和画面对应。
2. 工程有效：字体/素材就绪、无越界/遮挡、目标有效、输出状态如实。
3. 视觉成立：焦点明确、阅读顺序自然、留白有意、图文比例协调、插画质量达标、装饰克制。
4. 讲解成立：初始/中间/最终画面均可读，无大片意外空洞或注意力争抢；字幕/数字人不遮挡。

视觉验收必须保存实际截图、审阅人、结论与问题。自动测量是必要条件，不是美感评分器。
应在目标观看尺寸检查；缩略图检查主次，正常观看检查文字，状态对照检查节奏。
尚无视觉审阅证据不得发布模板。规则缺陷修契约，组合缺陷修模板，资产缺陷换资产，
内容超量回规划；不要只给单例增加负边距或不断缩字号。

## 可执行的设计与生产流程

设计流程：参考拆解→选择真实内容与屏幕摘要→画完整构图→按槽位制图→HTML 混合试制→
视觉审阅→回收公共组件和模板参数→替换内容/容量/状态验证→登记限定支持范围。
S04 未通过不得当成 S05/S08 已完成。参考整页可以是图片，但最终验收对象必须是实际混合页面。

生产流程：知识规划→按关系与容量选模板→填槽位/产出素材任务→复用或生成资产→受约束渲染→
内容/工程/视觉/讲解验收→消费既有音频时间轴→视频或已声明等级的 PPTX。
语音合成、时间轴服务和数字人继续复用现有方案，本规则只约束页面预留与目标映射。

## 兼容与验证责任

现有 P01 定义/夹具、0.5.0 分类目录保留创建版本；本次不改运行数据或图片路线。
既有样稿保留作审阅证据，不自动升级为模板。已有手工编辑要保留，模板/素材升级需显式
选择并重新排版验收。未来静态内核需实现容量和模板选择约束；美术审阅仍独立记录。
当前可检查规则引用、模板定义完整性和审阅状态，不能宣称运行拦截已经生效。
