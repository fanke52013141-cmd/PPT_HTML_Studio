# 平面效果组件与参考图谱契约

契约包：0.8.0；日期：2026-10-07。状态：现行设计规则；本次定义模板交付与候选清单，不代表组件库或自动门禁已实现。

继承 [视觉生产规则](07-visual-production.md) 与 [视觉生成契约](08-visual-generation-contract.md)。本轮优先建设 CSS、SVG、Canvas 2D；HTML承担结构，JavaScript承担参数与时间控制。图片资产继续用于插画和复杂美术细节。实时3D、WebGL/WebGPU、CSS三维效果不纳入本轮模板建设，后续按扩展流程定义。

## HPS-031：统一效果组件，按能力选择实现

必须建设统一效果库，不能为了覆盖三个技术名称而重复制作三份相同组件。组件按视觉用途和控制语义分类，CSS/SVG/Canvas是实现属性。一个组件可混合实现，但必须指定主实现、子对象、层级和坐标归属。

| 实现 | 首选职责 | 边界 |
| --- | --- | --- |
| HTML＋CSS | 文字、容器、标签、底纹、渐变、阴影、二维揭示与变换 | 不承担未经定义的复杂插画和物理材质；正文保持可编辑 |
| SVG | 图标、路径、箭头、手绘轮廓、关系线、精确图形、描边与形变 | 形变需要兼容路径和对应点定义，不能承诺任意形状互变 |
| Canvas 2D | 多对象运动、粒子、笔触轨迹、二维波形与场景绘制 | 不自带逐对象DOM；必须提供对象ID到几何/命中目标的映射与文字语义描述 |

简单箭头优先SVG，不因已有Canvas就重复实现。知识文字和精确数值默认HTML/SVG；Canvas承载这些内容时必须说明必要性、字体就绪、可访问替代描述和几何接口。纯装饰Canvas应明确标为装饰。

公共语义（箭头端点、标签文字、轨迹进度）不随风格复制；色彩、线宽、笔触、阴影、纹理由风格参数和受约束变体决定。增加无法由参数表达的行为时走新能力定义，不能把主题代码当另一套业务组件。

## HPS-032：效果模板、组件、图谱和页面配方分别交付

这里的“效果模板”是对组件外观和行为的一组可复用约束，不是整页布局模板。

| 层级 | 定义 | 例子 |
| --- | --- | --- |
| 组件 | 可执行、具公开参数和目标的实现 | 箭头、标签、粒子流 |
| 效果模板 | 组件的参数范围、允许组合、运动方式与限制 | 手绘弯箭头、纸片标签、定向流动 |
| 风格配置 | 颜色、字体、笔触等共享值 | 手绘科普主题 |
| 效果图谱 | 展示N个效果的图片及其ID索引 | 同主题箭头/标签/纹理参考板 |
| 场景配方 | 槽位、布局、容量与知识关系 | 输入—处理—输出场景 |

每个可进入生产的效果模板至少交付：

1. 稳定ID、版本、类别、用途、主实现、依赖、所有者与支持状态。
2. 可运行组件及调用示例；参数类型、单位、默认值、范围、非法输入诊断。
3. 公共内容参数与风格参数的区分；允许变体及明确不支持的效果。
4. 几何与控制定义：主体边界、视觉溢出（阴影/笔触）、锚点、层级、裁切、可动子对象、缩放规则与最小可读尺寸。
5. 静态预览、代表状态、动态预览及效果图谱位置；全部关联同一组件/风格版本和参数。
6. 时间输入、动作参数、出现/停留/退出、打断与重播、与其他效果组合的冲突规则。
7. 内容长度/对象数量/尺寸预算、字体资源、依赖资产、浏览器/分辨率/DPR及性能验收环境。
8. 视觉、运行、输出证据与限制；静态截图不能替代运动或参数边界检查。

参考图可以先设计，再实现组件。此时必须标“候选效果”，不能宣称已有实现。只有实现且验证后的图谱才可作为生图任务的已支持能力参考。正式图谱从同版本代码导出，或逐项与实际渲染验证一致；不要求每次生产重新画一张图谱。

生命周期：候选→已定义→已实现→已验证→生产批准→弃用。运行验证与视觉批准分别记录；用户对单个实例的认可不自动批准整个模板参数空间。文档中的这些状态不自动注册E1/E2能力。

## HPS-033：图谱约束生图，逐元素核对还原

图谱按主题和用途分板，标明组件ID/版本、风格版本、效果名称、参数示例与支持状态；一张图不必穷尽全部效果。生成任务只附当前场景相关图板和简洁能力说明，保留更高分辨率单项预览可供检查。

图谱展示外观，结构化清单负责精确引用。生成设计图前须为对象指定组件/效果模板或独立资产任务；生图模型可以在允许范围内组合，但其输出仍为视觉提案，不自动产生运行组件。

### 面向AI的一图参考交付

对外统一称“效果库”。代码组件及参数说明是其实现底座；每次提交给生图AI的主要载体是带简短注释的效果库参考图。内部“图谱”指该效果库的视觉导出，不另建一套效果定义。

每个效果格至少标注：稳定效果编号、简短名称、一句话用途、实现类别（CSS/SVG/Canvas 2D或混合），并展示实际效果。必要的限制就近标注，例如“装饰粒子，不代表数据数量”。注释是模型理解效果的说明，不是最终画面需要复刻的文字；图板必须明确这一点。

例如：`FX-ARROW-01｜手绘弯箭头｜连接步骤、表达方向｜SVG`。动态效果用起始/中间/结束小帧、方向箭头及简短动作词表达，不能仅凭静态终态宣称已传达完整运动。具体讲稿时间、精确路径或当前数值仍来自场景定义。

图板头部统一标效果库版本、风格版本和可用范围；底部统一标“按编号选用；样例文字与说明标签不进入成片；复杂插画另按资产任务处理”。默认发一张与本次场景相关的效果库总览图；可在同一图中以文字/容器/关系/运动分区，保持外观与用途说明可读。生产参考图只包含已验证且批准在当前范围使用的效果，候选项独立放入探索图板。

提示词必须保留实现分工的二次约束，不能因为图板已标注就省略。每次明确所引用效果库/风格版本、对象或对象组、效果编号、实现类别（CSS、SVG、Canvas 2D、图片资产或混合）及关键边界；无需重复全部美术细节。图片负责展示外观，文字再次约束实现归属，两者必须与同一设计定义一致。编号解析、版本固定、参数校验仍由结构化清单承担；图片中文字不能成为唯一机器契约。图板注释必须与组件定义同源维护，组件变更时同步重新导出，避免图和代码各自演进。

二次约束必须说明：代码层只采用所引用效果的已验证外观，不自行增加未支持的材质、笔触或光影；图片资产独立生成，不烘焙代码文字/数据/关系线；混合对象展开各层及其控制边界。生成完整设计参考时可以展示代码元素，但那是构图示意，不改变其最终实现归属。SVG/CSS/Canvas标签和效果编号是生产说明，不得画进最终场景。Canvas的过程效果仍需关键帧和运动计划，静态设计图不能证明动画可行。

提示词中的这份分工摘要须从设计定义与效果清单派生，不手工维护另一份相互矛盾的清单。图板与文字出现冲突时先修正版本/引用再生成，不能让模型自行裁决；生成后仍按对象逐项检查，二次约束不等于保证模型遵守。本条是生产提示词的内容要求；实际接入或修改生产提示词时，仍按项目Prompt优化与验证流程实施。

“一张图”是默认交付目标，不是牺牲可读性的硬限制。效果增加到缩小后无法辨认时，保留一张清晰总览，并按本次需要附局部详图；不得把整个库塞进一张不可读的大拼图，也不能为省提示词省去内容事实、关键约束或动态时间定义。

生成后对文字、容器、图标、连接线、底纹、光晕、辅助物体及过程元素逐项登记。每项必须落到组件实现、独立资产或经记录的设计修订。模型新增的装饰也必须核对；不能因为漏提图标、缺少材质实现就静默删除。

无法还原的效果必须选择：补定义并验证实现、生成适当独立资产、或修改设计。重要材质/阴影的归属要明确，防止图片与代码重复叠加。生成图片的文字/数据不得覆盖权威内容。

验收比较构图、重心、比例、层次、笔触/材质、细节密度、可读性和关键状态连续性，不要求无意义的逐像素复制。实际画面明显单薄或失去关键细节即退回，不以参考图精美或运行正常替代视觉通过。

## HPS-034：平面动效统一时间、几何与输出

组件状态必须由显式场景时间与参数决定；允许缓存，但任意跳转、重播或导出不能依赖之前播放了多少帧。随机笔触/粒子固定种子，物理近似需要解析求值、固定步长重算或可恢复快照，禁止无种子的逐帧随机。

CSS动画须可定位到指定时间并可暂停；不能使用与课程时钟失去同步的永久循环。SVG绘制进度与Canvas轨迹同样服从统一时间。首帧、跨段、暂停、重播和结束均需有定义，区分“对象出现”和“对象表达知识过程”。

所有后端使用统一逻辑画布坐标；Canvas显示尺寸与像素缓冲区尺寸分别处理DPR，清屏、状态隔离、裁切、透明合成与图层顺序必须可复现。Canvas里的公开对象必须能按稳定ID返回几何；CSS/SVG的几何也不能把阴影误当可点击主体。

文字/资产就绪后才可播放或导出，缺失资源明确诊断。可读性与内容真实优先于粒子数量；每模板记录性能预算和实测环境，超限应拒绝或采用显式降级，不静默丢弃讲解对象。预览提供暂停和减少非必要运动的方案；正式视频按固定时间导出。

HTML预览、视频、PPTX分别声明支持：Canvas可按帧合成为视频；进入PPTX可栅格化，必须声明不可编辑与不保留动态，不默认承诺原生可编辑。输出固定组件、资产、字体和风格修订。更改实现或参数范围需重验受影响图谱、实例和输出，保留旧版本作品。

## HPS-033 / HPS-034 补充：参考图复用与字幕安全区

效果库参考图按组件版本、主题修订和选用效果集缓存复用，不要求每部视频、每页重新制作。只有实现、可见参数或效果集合改变才重新渲染图板；生成任务记录实际使用的版本/输入快照。图板是代码效果的说明，不是每页必须生成的设计稿。新构图或复杂过程可做设计参考与关键帧；已审阅布局在容量范围内换内容可直接组装并验收。不能省略对象分工、运动定义和最终视觉检查。

16:9首批默认逻辑画布1600×900，内容区为y=0—800，底部y=800—900固定为字幕区；1920×1080等比对应底部120像素。字幕区空字幕时仍保留。标题、图标、插画、SVG、Canvas、装饰、阴影及运动轨迹不得进入；字幕自身可由专用HTML文字层实现。内容裁切仅为兜底，布局必须主动避让，不可用裁切掩盖缺失对象。

字幕默认32px逻辑字号，当前实例支持20—44px，左右内距80px、上下10px、最多两行。字号只改变字幕，不移动内容或扩大区域；超容量应拆分字幕/调整字号并重新验收，禁止溢出和默默截断。整部作品在排版前固定区域尺寸，调整区域尺寸须重新验收布局。导出记录字号与区域；播放器临时字号不等于持久化导出设置。

场景生成提示和关键帧必须要求底部字幕区留白；独立资产图和效果图板不是场景，不需套用这一画面分区。既有设计参考图保留原始输入与时间，不伪称已遵守新增约束。本轮在蒸发独立实验落实，不宣称E1/E2或既有课程批量迁移完成。
