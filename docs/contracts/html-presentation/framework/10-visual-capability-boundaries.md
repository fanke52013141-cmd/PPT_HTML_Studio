# 视觉能力边界表与风格准入规则

契约0.9.0；2026-10-07；HPS-035—037。用户所称“视觉能力编辑表”在本项目统一命名为“视觉能力边界表”。本规则约束新HTML路线的风格选择、效果建设、提示词、资产生产及验收。只允许代码主导和少量独立图片辅助两类方案。

## HPS-035：风格白名单与禁止范围

核心要求：CSS、SVG、Canvas承担主要信息表达、布局、关系与运动；生图用于少量无法经济地用代码表现的主体插画。允许范围不等于能力已经实现，实际使用还须查组件证据。

### 允许风格

| 编号 | 允许方向 | 适合内容 | 代码承担 | 图片可承担 | 必须避免 |
| --- | --- | --- | --- | --- | --- |
| V01 | 简洁现代 | 概念、定义、课程解释 | 字阶、留白、形状、强调、动画 | 可选单一主体插画 | 为每个词生成装饰图 |
| V02 | 编辑式图文 | 观点、课程封面、要点讲解 | 标题/正文层级、图文比例、编号、引用 | 主题图片/照片 | 整页排版烘焙为图片 |
| V03 | 几何扁平 | 原理、分类、流程、抽象对象 | 几何主体、色块、标签、状态、连接 | 可选难以简化的主体 | 每个节点变成单独生图 |
| V04 | 信息图与线条图解 | 对比、时间线、关系、数据 | 真实文字、数值、轴、图例、连接与强调 | 辅助实物/人物 | 生成图中的数字作为图表来源 |
| V05 | 柔和科普插画 | 科学、教育、实物解释 | 规整组件、标签、注释、过程运动 | 少量高质量科学插画 | 插画吞并可变文字或关系 |
| V06 | 简洁卡通插画 | 情境解释、轻叙事 | 对话文字、步骤、对象进出、标注 | 少量静态角色/实物 | 连续角色表演和大量姿态帧 |
| V07 | 轻立体图文 | 产品、空间概念、封面 | 排版、普通阴影/渐变、有限二维变换 | 少量固定视角立体插画 | 真三维视角或光照连续变化 |
| V08 | 摄影图文 | 实物、案例、自然现象 | 图文组织、可控标注、对比与镜头裁切 | 少量现成或生成照片 | 所有知识内容都在照片里 |

这些方向可以组合，但组合仍受同一资产预算和代码控制要求约束。“柔和”“卡通”“轻立体”只描述外观，不能用来绕过禁止项。

### 当前严禁采用的路线

| 禁止项 | 判定依据 | 范围内替代 |
| --- | --- | --- |
| 手绘水彩、彩铅、油画、毛笔等作为整套主风格 | 美感依赖自然笔触、颜料、纸张材料和大量绘画对象；当前没有稳定交付能力 | 规则几何/清晰线条配少量普通插画 |
| 素材密集拼贴、贴纸手账、逐元素图像拼装 | 标签、图标、背景、文字、箭头都需要图片资产 | 可执行卡片/标签/图标组件 |
| 整页图片加遮罩、截图切块动画作为新HTML路线 | 文字、数据与关系不能独立修改，HTML只负责图片显隐 | 独立对象与代码表达 |
| 连续角色表演、逐帧生图动画 | 依赖大量姿态/关键帧图片且一致性成本高 | 少量静态角色配讲解与有限移动 |
| 真实流体、烟雾、复杂物理模拟 | 要求物理真实性或大量逐帧纹理 | 明确标为示意的有限粒子/波形，先实现再验收 |
| 自由视角三维、电影级光影、任意自然形变 | 超出当前二维渲染与资产能力 | 固定视角插画、有限二维运动 |

“严禁”是当前产品范围的硬约束，不是对浏览器理论能力的判断。不得在单个制作任务中偷偷破例；如未来改变范围，须先修改本规则、说明成本并提供完整视觉和运行证据。现有原图片后端不受此处HTML范围收缩影响。

简单SVG曲线或清晰描线本身不在禁止范围；禁止的是把它们命名为已支持的水彩/彩铅风格，并承诺复现绘画质感。少量图片也不能让被禁止的整套风格自动获得准入。

## HPS-036：代码主导与资产预算

### 必须由代码承担

课程标题、正文、字幕、可变标签、数据、单位、图例、步骤编号、逻辑连接、状态强调以及相关时间控制，必须保持独立语义对象。规则图标优先复用SVG库。不能把这些内容生成为图片以规避排版与组件建设。

关键检验：修改一句标题、一个数字、一个步骤顺序或一条箭头，应该能直接更新代码数据，不要求重新生图。关闭主体插画后，页面的知识骨架仍须可读；这不表示实物观察类课程的图片可以删除，也不按图片占屏面积判断代码贡献。

### 首版预算默认值

以下是工程初始预算，不是对模型能力的测量结论；如实际需求不适配，应修改页面组织或正式修订预算，不能临时忽略。

- 内容页默认0—1个独立插画主体；确有双对象对比或组合需要时，上限2个。超过上限先拆页、改用代码图解或复用图标。
- 一个资产板含多个独立主体，按主体数量计数；不能把十张素材拼进一张图片来绕过上限。自然完整的单幅照片不逐个统计画面内物体。
- 通用标签、箭头、色块、阴影、基础背景、简单图标不得逐页生图；从组件与已有资产中选取。
- 在课程规划时建立唯一资产清单。同一语义且风格适配的主体优先复用；相同对象不因页码变化自动重生。禁止“每页必须生图”的流程。
- 原有素材/照片同样接受依赖程度检查；减少生成调用但继续大量图片拼接，也不符合此规则。
- 效果库参考图按组件版本与主题修订渲染一次并复用。新布局可以生成完整设计参考；成熟布局换内容默认直接组装，不逐页生成设计稿。
- 设计参考图只用于审美对照，不能作为最终整页背景交付。需要动作的对象须在生成前声明独立资产或代码归属。

预算统计对象是最终作品的素材依赖；生成调用次数另记，包括失败重试、设计稿与资产。优化调用次数不能替代对最终可编辑性与控制能力的检查。

## HPS-037：能力状态、准入与验收

### 能力状态表

| 能力 | 当前证据 | 可承诺范围 |
| --- | --- | --- |
| 文字排版、标签、基础形状、普通色彩与阴影 | 已有独立效果库与课程样例 | 限已测字号/尺寸；不能自动保证任意长文本 |
| SVG箭头、圈注、有限图标 | 已有固定曲线、太阳、星/叶等样例 | 指定变体；非完整图标库和任意路径路由 |
| Canvas确定性粒子流 | 已有固定种子上升粒子验证 | 有限轨迹与数量，非流体仿真 |
| 时间定位、播放/暂停、逐步揭示、有限二维变换 | E1及独立实验有证据 | 各自格式声明范围，不混同通用后端 |
| 少量透明主体插画组合 | 已有多轮独立插画试作 | 素材逐项验收；生图不能保证首轮正确 |
| 编辑式/对比/数据等风格化页面 | 分类方向允许，覆盖程度各异 | 先逐模板补证据，不宣称全部已可生产 |
| 彩铅水彩样板 | 技术运行通过，用户明确认为视觉差距大 | 视觉未通过，退出当前建设范围，仅留历史证据 |

### 每个新风格必须填写的准入卡

1. 风格名称与所属V01—V08方向；不得只给抽象美术形容词。
2. 代表页面的用途、内容容量、布局和字幕区。
3. 需要的代码效果ID、实现状态与真实效果图；未实现项单独标识。
4. 图片主体清单、每页数量、复用方式、是否需要拆分运动。
5. 文字/数据/关系的可编辑性和全部对象的出现顺序、运动状态。
6. 已知不支持项、缩放/字体限制、导出差异。
7. 一张完整页面的参考与实际还原对照，以及真实播放证据。
8. 用户视觉结论与技术结论分别记录；视觉未通过不得发布为正式模板。

### 生产前检查

- 风格在白名单内，且没有触发禁止项。
- 关键效果已有实现证据；不得先生成超出实现范围的精美参考，再通过简化丢失美感。
- 素材数量符合预算，字幕区、文字和关系可独立控制。
- 使用完整页面检查构图、插画配合、留白与字体；单个组件好看不等于整页好看。
- 使用短/长内容检查容量；用关键帧与播放检查运动及遮挡；视频按实际导出检查。
- 如果失败，应先判断是实现缺失、布局问题还是超出风格范围。不得以增加更多生图资产作为默认补救。

## 生效、兼容与迁移

本规则优先于旧文档中的手绘优先方向、无上限素材建议与尚未实现的候选能力描述。历史参考图、旧样板和旧输出保留，不自动重绘。新任务先执行本范围审查；未完成的手绘风格扩展停止。既有合格的时间控制、字幕区、组件接口和测试经验继续复用。

此文为设计与人工审查规范，尚未增加自动预算校验器、Schema字段或生产Prompt实现。契约索引不是运行注册表；E1/E2/P01数据格式保持原版本。
