# 设计到HTML的视觉还原协议

契约0.9.0补充；2026-10-07；细化HPS-026—030、033—037。目标是建立稳定的还原方法，不能以逐页手工修补替代规则。适用已准入的代码主导、少量图片辅助风格。

## 1. 三种一致性必须分开

| 一致性 | 定义 | 验收 |
| --- | --- | --- |
| 语义一致 | 同一对象、文字、数值、关系、讲解目标及出现顺序 | ID和内容对应，没有丢掉图标/解释/过程对象 |
| 视觉一致 | 构图、可见尺寸、位置、字体、层级、线条、颜色及素材接近已批准目标 | 同尺寸关键帧和局部对照，不只检查无溢出 |
| 像素一致 | 同一像素颜色与抗锯齿结果 | 只用于同一运行版本、同字体、同资源、同环境的确定性检查 |

生图模型可能重绘字体、材质、插画细节；仅凭一张生成图无法可靠恢复它使用的字体、矢量路径和原始分层。不能承诺任意生图逐像素转换成可编辑HTML。当前规则科普风可以追求高视觉一致性。像素一致不应替代语义或审美判断。

## 2. 当前链路的具体缺口

设计图包含由模型重新解释的插画和文字；运行页使用原资产和本机字体。两者虽共享内容，却没有共用精确布局与字阶定义。插画外框含透明留白，圈注又用独立页面坐标；改变资产尺寸后，关系线不自动跟随。结果出现主体大小、编号形态、标注位置和字形差异。

症结不能归结为“HTML天生不好看”或单一风格失败。需要把AI提出的视觉方案收敛为明确可执行的设计，再据此渲染与验收。

## 3. 一份视觉定义，贯穿生成和渲染

下表为需要补齐的设计记录，不是已上线的新Schema。实现时使用专用版本，不偷偷加入既有E1/E2格式。

| 定义 | 最少记录 | 作用 |
| --- | --- | --- |
| 画布 | 逻辑宽高、比例、内容区、字幕区 | 生成参考、页面与导出统一坐标 |
| 布局 | 区域矩形、相对关系、对齐基线、净空、文字容量 | 保留构图，不凭截图重新猜位置 |
| 字体 | 实际字体资源/版本、字重、字号、行高、字距、换行规则 | 避免同字号但字形/宽度差异 |
| 样式 | 命名颜色、圆角、描边、阴影、渐变、效果变体ID | 对应真实效果图板中的可执行样式 |
| 资产 | 固定文件/哈希、自然尺寸、可见主体边界、缩放方式、锚点 | 保持主体与标注关系，不能只看透明外框 |
| 对象 | 稳定ID、内容、实现后端、层级、归属关系 | 建立一对一或明确的一对多对应 |
| 运动 | 初态/终态、进度、时间、变换归属、过程对象 | 静态对上后仍能正确运动 |
| 验收 | 目标帧、允许差异、对应项、失败原因 | 把美感损失和实现缺项暴露出来 |

区域矩形给出约束与目标位置，并不要求所有页面同布局；新构图可以先探索，批准后才形成受约束模板。

## 4. 改进后的流程

### A. 生成前：给模型可实现的选择

先选择风格白名单和页面任务，确定讲稿、对象清单、关键帧、图片预算。准备实际代码效果图板和布局区域参考：标题区、图文区域、字幕留白、主体数量。效果图板按版本缓存；布局区域参考可由代码绘制，不需要额外生图。

提示词仍明确逐对象实现归属：哪个是可变文字、哪个对应已实现效果、哪个是独立插画。字体/线宽/阴影等必须引用已验证变体；不能只说“好看、精致、科技风”。模型可能不完全遵守，生成输出仍须审查。

有可用资产时先固定它，尽量让设计参考使用该资产。模型如果重绘原资产，必须记录差异；不能把重绘后的玻璃边缘当成原资产可精确命中的锚点。

### B. 生成后：先核对，再冻结设计

生成图是美术提案，不能直接成为可编辑对象的数据源。逐对象核对：内容是否完整，是否新增不可实现效果，是否偷偷改变资产，是否进入字幕区。按图板判断样式是否有对应实现。

发现新的美术表现时，只能选择：在当前范围内实现并补真实效果证据、采用已有明确变体并重新审阅，或退回设计。禁止还原时静默简化、遗漏图标、删掉关键层次，却继续声称原设计的美感已保留。

在这一步将选定构图转录为上表的精确视觉定义，记录人工视觉调整。生成图的坐标是建议，冻结后的视觉定义才是构建依据。固定资源和字体后，渲染一张实际终态：它与设计参考一起审阅，形成“已批准的可执行视觉目标”。

### C. 静态还原：先建立完整终态

先在统一尺寸画布上渲染完整页面，确认真实文字和素材，而后制作动画。共用字体、颜色、组件变体、几何定义，不允许实现者另挑相近值。

图片使用原始比例；可见主体框与透明画布框分别记录。代码可通过contain缩放计算显示位置，无需修改或抠除原图像素。一个杯子可同时有杯壁、水面、底座等锚点；锚点定义为原资产坐标，替换资产后必须重定义。

### D. 动态还原：关系随对象运动

关系线、圈注和标签引用目标ID/锚点；坐标从对象布局及当前变换计算，不重复填写一组容易失效的绝对坐标。对象进入、缩放或镜头变化时，标注必须跟随；文字标签的位置可独立布局，引线将两者连接。

文字/主体/标注可以有不同出现时刻，但共同服从作品时钟。生成终态里没有的过渡对象也要登记，不能在组装时临时补图片。关键帧分别核对初态、讲解中段和终态。

### E. 对照验收：按差异类型处理

同画布尺寸导出设计参考与实际终态，提供并排、半透明叠加或滑动对照。先检查语义，再检查视觉，最后检查运动。

| 检查 | 方法 | 失败处理 |
| --- | --- | --- |
| 主体位置/尺寸 | 比较可见边界、视觉中心和布局区域 | 修正几何定义或资产缩放，不改内容凑位置 |
| 标注关系 | 检查锚点是否命中真实目标、引线是否连接 | 修正锚点定义/变换计算；避免标到空白或另一对象 |
| 字体/换行 | 核对实际字体、基线、文字宽高和行数 | 固定字体或正式选择回退，重新审阅 |
| 标签/卡片/图标 | 对应效果ID、圆角、笔画、阴影、色彩 | 使用正确变体；缺项先补实现，不静默降级 |
| 留白/层级 | 完整页面与小屏观看 | 修改布局配方，并记录审阅后的新目标 |
| 动画 | 指定时间取帧和实际播放 | 检查对象归属、时间与几何变换 |

几何的初始验收建议：标注中心映射误差≤1逻辑像素；规则图形宽高比遵守定义；文字行数与冻结目标一致。此类技术指标用于定位错误，不等于整体美感合格。整页不设未经证明的“相似度95%”承诺。

## 5. 如何减少工作量

一旦可执行视觉目标通过审阅，保存布局配方、效果变体和内容预算。后续相同任务类型在容量内换内容直接渲染；更换字体、主体比例、关系或超容量内容时重新验收相关部分。复用库和模板承担大部分工作，生图只补少量真正需要的主体。

新效果图板只在版本改变时导出；新设计参考只在探索构图或重大视觉变化时生成。资产和模板均保留固定修订。整个流程避免“每页先任意生图，再临时猜着复刻”。
