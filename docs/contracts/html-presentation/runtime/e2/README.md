# E2 受约束配方定义卡 0.1.0

关联 HPS-002/003/007/009/013/024—030。E2 配方是编译前的作者输入，格式 hps.e2.recipe 0.1.0；派生为现有 hps.e1.scene 0.1.0 / 契约 0.7.1。旧输入、P01 和 E1 渲染器语义不变。

## 身份、归属与约束

公共配方逻辑提供双概念槽位及开放运动场景；风格值沿用 science-study 0.1.0。实例只能给内容、资源和预设路径，不能覆盖坐标、CSS、层级或任意动作。标题最多 18 个 Unicode 码点、副标题 38、每个概念术语 6、关系 12、解释 28；完整讲稿单独保存，屏幕不塞入全文。计数只是预检查，最终仍由浏览器实际排版门禁负责。

双概念固定 1600×900、左右两个插图槽、两个术语/关系/解释槽、一个标题/副标题；12 秒，0–6 秒解释左侧，6–12 秒解释右侧，终态保留两概念。资产先于对应解释出现。所有知识文字由 DOM 绘制，图片只承载对象外观。没有卡片边框，不自动增加标签。开放运动复用 E1 纸飞机舞台；预设 flight/drift，主对象替换须保留 frame-center 锚点，动作绑定对象 ID 而非资源 ID。

## 资产任务及质量

本轮修订 cloud-small 为独立单图：柔和 3D 云朵、珊瑚/薰衣草淡色、透明底、不含文字和背景；主体在中央 70% 范围，四边至少 10% 透明留边，无白色锯齿、溢出和零散像素。保留原版本；新版本有哈希、真实 alpha 包围框、裁切画框中心锚点、来源与质量审阅。旧资产板及缺陷作为对照，不再只以“有 alpha”判定合格。

固定槽位提取工具只裁切明确矩形，不自动抠图。质量审计记录 alpha>0 与 alpha>=16 两种范围、边界接触、主体占比、亮/暗底对照；自动指标不能代替审美或科学审阅。不合格资产不得自动成为生产已认可资源。

## 诊断、证据与兼容

未知字段/版本/配方拒绝；超量指出内容字段；缺资产及缺锚点指出槽位。布局和资源修改后重验所有关键状态。遮挡检查报告可见包围框重叠，属于保守提示，不能等同像素遮挡。自动校验通过只允许设计探索；每个配方分别保持 pending-user-review，用户审阅后才可提升。

定义→实现→验证分别登记于 E2 交付记录。测试同配方两组真实课程文案与资源替换、相同时间重复求值、长标题/缺图/未知字段拒绝；E1 原有测试继续通过。不接数据库、音频、数字人或 PPTX，不改变现有应用。

槽位实现：双概念标题框 (100,65,1400,100)，副标题 (104,175,1390,55)；插图 x=195/935、y=255、450 方形；文字槽 x=130/870，术语 y=700、关系 y=760、解释 y=815。资源身份从 assets 文件名派生，槽位身份为 left/right，显示对象为 left/right.illustration，三者独立；文件改名会产生新身份，当前工具不是持久资源库。资源锚点为画框中心，不声称是主体语义中心。

配方基底使用 catalog.basisSha256 锁定 E1 原实例字节；基底变化先修订/审阅配方，不能同版本默默改变坐标或节奏。所有配方输入先编译通过，再更新派生文件；磁盘写入事务仍待应用接入。
