# 三步讲解配方定义卡 0.1.0

关联 HPS-002/003/007/013/024—030。新增 recipe.hero-steps@0.1.0，不改变旧配方语义，仍以 hps.e2.recipe@0.1.0 输入，派生 E1@0.1.0。新字段 steps/heroAsset 仅该配方允许；其他配方不能默默接受。

## 槽位及职责

固定 1600×900：标题 (100,65,1400,100)、副标题 (104,175,1390,55)；左侧 hero 插图 (70,260,560,560)；右侧恰好三个步骤，x=730，y=285/455/625。步骤号与术语同行，HTML 精确文字承担顺序、计数及 Token ID；细节行 y=355/525/695。底部总结 (100,805,1400,55)。生成图片只含安静的科普书本外观，不包含文字/数字/关系图，不作为 tokenizer 输出依据。

标题最多18、副标题38；三个步骤项包含 label(18码点)、detail(30)、narration(完整讲稿，1000)、summary(上屏总结，38)。heroAsset 为独立透明 PNG，frame-center 锚点，版本/哈希/真实 alpha 范围沿用资源契约。三个槽固定，不接受第四步，不增卡片、不自由改变坐标。实际宽度仍由浏览器门禁裁决。

## 时间、质量与兼容

三个 6 秒手工时间段，总18秒；每段术语先出现、说明后出现，终态保留三步。插图从开场静态可见，不用装饰运动干扰知识。每段的完整讲稿与上屏摘要分开，暂定时间不代表真实旁白时长。关键帧 0/2500/8500/14500/18000。

原 E2 两配方的作者输入、节点和时间行为不变。新配方为设计探索，pending-user-review；完成实际字体/排版/重复时间检查和关键帧审阅后才可讨论视觉批准。Token 概念课程及生活课复用此配方作为验证，不允许为每个主题复制代码。

资源任务：一张柔和3D打开的科普书本，暖白纸页、淡珊瑚封面、蓝灰轻阴影，空白无文字；中央65–70%主体、四边至少10%透明留边、不触边、不烘焙步骤。不沿用不相关的水/云图来充当计算机知识插图。生成原图/提示/哈希/透明审计及科学用途均保存。
