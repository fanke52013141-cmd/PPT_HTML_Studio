## 归属与组合

| 层 | 负责 | 不得拥有 |
| --- | --- | --- |
| 公共能力 | 文字、编号、标签、图片 contain、箭头、锚点标注；容量检测；作品时钟；固定字幕轨 | 课程正文、杯子专用逻辑、科普色值 |
| 公共布局包 | 槽位坐标、宽高、最大行数、对齐、层次、安全区；本轮左右两种单主体三步布局 | 文本、图片文件、配色、播放时刻 |
| 风格包 | 角色配色；字体族/环境约束、字号、字重、行高、字距；标签/编号圆角；描边宽度；阴影数值；插画搭配规范；兼容布局引用 | 任意 CSS/JS、对象坐标、正文、锚点、讲解顺序 |
| 实例 | 对象 ID/类型/槽位/文字角色、文字与强调片段、资产版本、布局/风格引用、入场时间和位移、字幕语块 | 自定义组件实现、任意样式覆盖 |
| 资产登记 | 文件哈希、尺寸、透明边界、原图归一化锚点、版本与来源 | 独立猜测的页面标注坐标 |
| 派生结果 | 槽位排版、实际文本边界、contain 映射、当前锚点、SVG 路径与截图 | 作为另一份手工维护的源定义 |

风格是**已注册外观属性和兼容选择的集合**，不是一份页面 HTML。布局比例和间距可在完整体系中由风格推荐，本轮执行坐标属于布局包；主题不能暗中挪动对象。字号会影响排版，换主题后仍需容量检查。动作缓动本轮统一 smoothstep，顺序与幅度归实例；风格动作默认值尚未实现。风格的素材规范是生产约束，程序不能自动判断插画审美。

## 已注册对象

`text`（CSS，可分段强调）、`badge`（CSS，步骤编号）、`label`（CSS）、`image`（栅格独立主体）、`arrow`（SVG）、`annotation`（SVG 圈注/引线）。一个槽位只能被一个对象占用；对象 ID 唯一。角色、槽位、主题和资产引用必须存在；未知字段拒绝。没有生图替代文字或关系图层的退路。

图片预算为每场景一个主体、最多一个图片对象；主体图可复用，本轮零新增生图。annotation 的 targetId 必须指向 image，anchorId 指向该资产；圈与引线从当前图片变换计算。radius 为逻辑画布半径。仅平移入场，不宣称支持旋转、复杂路径、缩放群组或物理模拟。

语义规划进入生图前须校验标注引用：`targetId` 只能使用显式图片对象 ID、图片槽位或已登记素材 ID，`anchorId` 必须与目标图片槽位的焦点一致，`labelId` 必须对应显式文字对象 ID 或槽位。焦点名不能代替图片目标；不得因场景中只有一张图片而推断目标。校验失败进入规划修复，不消耗设计图调用。

每个对象必须有一条 enter 动作（startMs、durationMs、offsetX/Y），从透明/偏移变为终态；时刻可随机跳转、重播。偏移也须留在安全区。字幕语块不重叠，允许空档；末帧采用最后一个结束于作品时长的语块。字幕区 1600×100，固定 y=800；字体 20—44（默认32），超容量阻断，不缩小正文补救。

## 字体与验收

本轮字体明确 Microsoft YaHei，平台约束 Windows；不分发商业字体，不承诺跨平台字体像素一致。缺字体报错。终态先测每个文字槽位和所有字幕语块；超行、越区或遮挡编号/正文必须退回定义。实际审美仍由用户审阅，几何检查不等于设计批准。

至少验证：同一组件替换两份内容/资产，两种布局；仅换主题不改变内容与锚点；恶意文字按文字显示；无效定义不替换当前页面；图片移动、画布缩放后标注仍精确；播放/暂停/跳转确定；固定字幕区与字号容量；旧 E1/E2 回归。
