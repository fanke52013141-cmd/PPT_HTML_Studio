# 项目标注工作台与配对执行器 0.1.0

2026-10-25，HPS-007/009/013/015—018/023—030/037。基于已封存dataset、标注草稿/复核和固定配对评分工具实现产品入口。

标注：同项目读取或创建evaluation/datasets；创建仅引用该项目已保存scene与已验证当前设计PNG。原图和scene字节冻结，标注版本单独递增；草稿保存、独立复核/驳回、封存均核对dataset/case/revision及源hash。对象/part身份固定，逐行实际文字、像素框、容器和未找到/不确定可编辑。评测标签不是生产视觉批准；开发/留出课程隔离保持。旧标注版本保留，复核人须与标注人不同；同意封存才更新dataset gold hash。未复核草稿禁止进入实验。

执行：复用原HtmlWorkflowJobs执行器、LocalJob状态/取消CAS、项目冻结text/planning模型、原JSON传输及网关治理。before/after只选择已登记的同Schema定位片段0.5.0/0.5.1和冻结项目模型角色，不接受任意Prompt、endpoint或密钥。复用原定位输入投影，传输仅原图+准确对象/part身份，不发送gold、HTML几何或人工标注。冻结数据、模型摘要、原Prompt字节与源hash，AB/BA交替、固定重复次数、有限模型/真实HTTP调用和总时间预算。每次真实HTTP有意图与返回/unknown回执；未知不自动重发、不以换模型/任务清零；取消后不进入下一调用。已知完整结果可复用，失败/unknown/not_run全部保留分母。超时/断流、结构无效与取消分别记录；usage/cost未知null，不编造费用。

Web与Agent同构请求模型、能力注册、MCP/CLI/SDK同步；项目界面仅用原API层，工作台沙箱消息绑定窗口/会话/nonce与页面生命周期。路径限制在本项目evaluation目录。原作者、配音、图像生产及批准状态不改写，不触发生产失效链。

验证：真实浏览器拖框、逐行区域/容器、草稿/复核/版本冲突；跨账号/项目与越界路径拒绝；执行冻结、顺序、预算、取消、unknown、重复提交/完整回执恢复；已发送输入不含gold/几何，真实HTTP计数覆盖原格式回退/修复。离线替身测试不签发真实模型准确率或人工视觉批准。本轮开发不调用付费供应商。

标注者与复核者姓名为操作者声明，同时留存实际登录账号用于审计；系统只强制不同的声明姓名及显式复核，不声称完成不同真人或不同账号的身份认证。复核通过表示评测标签已封存，不表示生产画面批准。实验范围为原图定位前后对比，工程/像素/语义/声音签收继续独立。
