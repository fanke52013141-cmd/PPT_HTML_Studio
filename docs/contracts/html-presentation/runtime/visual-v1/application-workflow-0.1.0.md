# 应用生产与验收补充合同 0.1.0

2026-10-08。适用：guided + HTML + 16:9。运行格式仍为 scene 0.3.0、theme/layout 0.2.0、template/asset 0.1.0；不混用 E1/E2 作者格式。关联 HPS-019—037，Agent API 1.12.0。

## 分层与唯一职责

| 层 | 定义与执行归属 | 内容 |
|---|---|---|
| 公共能力 | visual/compiler、renderer、资源工具 | 严格格式、文字测量、图标、卡片、图像 contain、SVG 关系、纯时间动作、字幕、安全区和资源校验 |
| 风格属性 | visual/themes/soft-science.json | 色板、排版、间距、圆角、边线、阴影、渐变、组件外观及布局兼容性；不持有课程内容或单独播放器 |
| 受约束模板 | visual/templates + layouts | 槽位类型、数量、容量、几何及适用结构；模型必须选择已注册版本，不能重造任意布局 |
| 内容实例 | scene、plan、motion binding | 文案、资产引用、对象 ID、讲稿 ID、出现/强调/离场和手工偏移 |
| 派生结果 | prepare、audio binder、review/export | 实际测量、锚点映射、语块时间、截图和编码；不得混入作者场景的额外字段 |

当前科普效果图谱登记七个 CSS/SVG 效果。Canvas 2D 属于允许建设的能力，当前图谱没有登记 Canvas 效果，不得因此虚构一个可执行效果。公开能力只能以注册表为准。

## 生产流程

1. 从当前分镜契约读取一个 slide 和 narration_beats。LLM 只输出注册模板、内容槽位、对象、语块动作与图片需求；计划最多修复一次，失败保留诊断。
2. 组装 design brief，冻结效果注册版本、字幕留白和资产预算。当前生产入口每页最多一个新主体。
3. 有图片需求时：复用带 ID、backend、用途标注的真实效果图谱；向配置中的图片服务发送真实附件，生成设计参考，再生成独立透明主体。纯代码页面直接使用受约束模板，不为每页重复生图。
4. 图片请求缓存绑定需求、参考图字节与生成参数。检查 PNG、像素预算、透明度、边界和 hash；不以白底冒充透明资产。无法满足约束时明确失败。
5. 代码展开节点/动作，输出严格 scene 和独立 binding。模型不输出自由 HTML、CSS、JS 或最终像素坐标。
6. 通过共享播放器实际加载项目资源、测量、截图。过程模板再保存初态、中间态、终态三张实际关键帧及其 hash；这些是 HTML 执行结果，不声称模型已生成三张设计图。
7. 在项目锁下检查修订号后保存；普通异常会恢复原场景、绑定、计划、修订和资源清单。失败候选保留供查看；并发修改返回冲突，不覆盖用户编辑。
8. 用户检查实际画面后批准。Web/Agent 共用批准服务，必须批准已保存的当前场景。通过自动静态检查不等于人工审美通过。
9. 已确认音频按稳定 beat_id 绑定动作；同一总时长下，句子开始时间变化必须改变对应动作。拆分段沿用原 beat_id 合并窗口。新生产场景不得使用比例缩放替代句子关联；无 binding 的旧实验保留兼容行为。
10. 导出检查每页当前批准及音频状态。视频复用原数字人合成入口；PPTX 走原持久任务、产物登记、查询和下载流程。

## 文件合同

| 文件 | 归属与最小字段 |
|---|---|
| planning/html_visual/scene-{slide}.json | 当前作者场景；不允许场景 ID 与文件 slide ID 不一致 |
| revision.json | 项目修订号；相同内容保存是 no-op，旧修订拒绝写入 |
| resources.json | 项目资产登记：assets 数组，id/version/file/sha256/size/alpha_bbox/anchors；路径必须在本项目 run 内，内容不可执行 |
| binding-{slide}.json | hps.html.motion_binding 0.1.0；mode=beat_ids，actions 按 objectId:action 索引，值为 beatId/edge/offsetMs |
| candidates/{slide}/ | plan、brief、设计参考、freeze、过程关键帧与 hash；候选不自动获得批准 |
| review/、approval-{slide}.json | 实际报告/截图与批准；绑定当前场景及解析后的输入摘要 |
| presentations/*.pptx + 原侧车 JSON | 产物、当前输入指纹及快照页映射；删除沿用原产物服务 |

默认 focus 是主体包围盒中心，明确标记为通用中心，不能声称是水面等科学语义锚点。具有这类语义要求时必须检查或调整资产锚点后再批准。存储允许草稿；渲染/批准负责严格质量门。

## 一致性与任务

批准和产物指纹统一包含实际场景、已用主题/布局/模板、播放器、资源包/图标/效果注册表、已用图片字节、字体字节、动作 binding。同名定义或图片发生变化同样失效；无关项目资产不影响该页。作品指纹按当前分镜顺序计算。

任务有独立类型与持久记录，生产实际使用 html_plan_generate。查询、停止由 Web/API/MCP/CLI 同步提供。成功/取消使用数据库条件更新，迟到成功不能覆盖取消；启动恢复为 interrupted，显式重新提交才重试，最多三次。停止是阶段边界协作式停止，不宣称撤回已提交的远端请求。普通错误回滚与进程崩溃恢复不是同一种保证；进程异常后需审查保留候选和任务。

视频编码必须实际探测 1600×900、指定帧率、H.264 + AAC、yuv420p、bt709 三项标签和时长。末帧保持及音频补齐必须显式执行；不能靠容器时间或一条写死的校验记录代替检查。快照 PPTX 为整页图片，不承诺原生动画和逐对象可编辑。
