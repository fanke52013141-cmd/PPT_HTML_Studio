# 候选画布与保存版本恢复 0.1.0

HPS-007/009/010/013—018，契约0.9.103，2026-10-20。定义先于实现；验证记录另列。

## 定义卡

- B原作者、A外部候选、W人工工作草稿保持分离。独立工作画布复用原共享播放器及Moveable/Selecto，不增加renderer；选择B/A只读，W才可操作。主正式页不因工作草稿变化。
- 工作画布使用原preview解析资源/音频时间；容量失败只可用原diagnose展示，明确未通过，不能获得保存资格。Schema/资源错误不伪装可编辑画面。一个多对象手势为一个原子操作列表，仍按原scope/schema重放；禁止静默丢弃越权对象。
- 中文属性标签映射原注册字段和part，显示对象内容摘要；高级技术详情可展开。数值仍为绝对值，不静默裁剪。
- 服务持久最近50步undo/redo；每次更新/撤销/重做均增加work_revision并作废check。跨刷新恢复；乐观锁、来源、保护和切页迟到响应检查保留。
- 正式editor实际改变保存时，同一原子写事务记录保存前后scene/binding快照（不包含媒体），按页面revision唯一命名。no-op不新增。仅本能力启用后经过editor的保存可恢复；不伪造更早历史。
- 恢复版本先取回服务器快照进入当前编辑器草稿，用户预览后显式保存为新revision。只恢复页面参数/绑定，不回退项目revision、保护记录、资源文件或批准。当前原文/结构/资源/音频已不兼容则原校验阻断。保护只增不删，历史图不作为当前批准。
- 人工历史与恢复仅Web；外部Agent无人工写入口。无数据库迁移、provider/TTS调用。历史JSON限2MB/单个，工作记录历史有界。

## 验收

隔离测试覆盖多对象事务/范围拒绝、跨刷新undo/redo、旧work_revision、无效草稿/检查作废、保存快照/no-op/写失败回滚、版本路径与完整性/旧内容冲突。真实浏览器核验候选拖动缩放、中文字段、B/A/W只读切换、刷新恢复及版本恢复预览/显式保存。工程通过不等于用户视觉批准。
