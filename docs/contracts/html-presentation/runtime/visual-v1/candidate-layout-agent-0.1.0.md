# 未保存候选排版 Agent 0.1.0

受影响规则：HPS-001、011、013、023—025、028。该能力属于现有 HTML 生产服务，不新增公共 API、任务存储或图片后端能力。

输入为生产编译后的未保存 scene、binding、人工修改记录、当前资源及实际浏览器失败报告。仅 CONTENT_CAPACITY_EXCEEDED 可进入排版修复。诊断渲染使用同一编译器、字体、资源与 DOM，只收集容量错误而不终止；诊断截图永远不构成通过或批准，资源/Schema 错误仍终止。

LangGraph 管理 evaluate → decide → apply 的有界循环。现有 JSON 多模态适配器提供模型决策；不声称提供者原生 tool_calls 已验证。模型输出 patch 或 stop，patch 仅包含现有 set_presentation / set_text_style 操作，字段、范围和人工保护复用编辑器。不得删改正文、身份、图片、绑定、动作或改写项目源码。最大三次模型决策，模型不能批准自己的结果。

每轮场景、截图、测量、Prompt、响应、操作错误和最终状态留在候选目录，非作者事实源。状态由现有生产任务持有；这些文件是审计记录，不承诺进程崩溃后 LangGraph 断点恢复。模型失败、停止或超限保持旧作品、资源和 revision。

只有原严格 review_scene 通过才保存。保存前沿用项目锁、revision、定义身份和人工字段保护；资源临时写入仍在同一事务回滚范围。修复期间生产持有既有项目锁，因此不会并行覆盖人工编辑，但同项目编辑可能等待最多三轮。循环每个边界检查停止信号；不新增取消语义。静态通过不等于动态、审美、音频或输出验收。
