# A05 HTML 课程制作调度 0.1.0

2026-10-14；HPS-006/009/010/011/013/014/017/028/030。普通一键入口和 Agent API 共用既有项目、制作服务及 `LocalJob`，不新增任务表、供应商旁路或图片后端行为。

## 调度顺序

同一个项目级一键任务按以下阶段推进：文章、模型和媒体工具预检查；生成或复用权威分镜及语义来源；生成或复用旁白；逐页生成设计参考；停在既有设计确认界面；用已接受设计参考生产 HTML 场景并运行工程 QA；用原 TTS 服务生成音频及真实语块时间轴；停在既有音频界面等待用户试听确认；基于真实语块时间生成三帧证据并独立审阅每页语义；停在现有页面批准界面等待作品人工批准；检查所有门禁后调用原视频导出服务。

阶段 ID 继续沿用应用一键任务已有 ID，避免改变图像工作流、状态路由和恢复协议。HTML 页面任务的业务状态由项目状态中的 `html_course` 表达；UI 可显示 HTML 专属阶段名称，但不能把它解释成图像 Mask 或图像生图任务。

## 任务与恢复

项目一键状态是整课进度来源。逐页 HTML 生成和语义审阅继续写入既有 `LocalJob`：生成沿用 `html_plan_generate`，独立语义审阅使用 `html_review`。它们共用现有并发执行器、快照、生产阶段回执、幂等键、尝试围栏和恢复检查，不建立第二个并行任务库。

课程输入身份记录文章和权威分镜摘要、页面来源修订、冻结的文字/图片模型摘要及原始运行请求。页面记录子任务 ID、阶段、快照、状态、错误、设计候选身份、语义报告和复用理由。继续任务时再次校验当前文章、分镜、页面场景、依赖快照、音频时间线、模型身份和语义输入；有变化时停止混合使用。中断恢复应回到原 `LocalJob` 与原输入。

页面 ID 使用项目已有 `validate_slide_id` 规则（允许下划线、点和连字符）；场景对象 ID 和动作 ID 继续使用更严格的注册对象规则。JSON Schema 将页面 `slideId` 与对象 `id` 分开校验，生成校验器随源规则重建。页面输入/批准指纹和生成/导出快照须一并固定 `schema.json` 与实际生成校验器字节。

供应商请求状态未知时先对账原请求，不能通过新页面任务或新一轮语义审阅绕过恢复门禁。能恢复的失败任务仅在原快照和输入仍相符时以原任务身份有限重试。服务重启将活动任务交给既有恢复机制处理；刷新或重开项目读取已保存的一键状态与子任务。

## 人工门禁与导出

设计图先由原 HTML 面板显示，用户确认后才运行页面复刻。工程检查完成不代表设计获批。技术 TTS 确认不代表用户听审；有效确认记录必须是 `user_reviewed`，且仍绑定当前全页音频制品。独立语义 QA 消费实际绑定时间和有效证据；待审、低置信或失败都会阻断后续人工批准和导出。语义通过不能代替逐页“批准本页”。继续任务和正式导出前都会重新计算音频、语义和人工批准门禁。

课程只有在原渲染服务产出带下载地址的视频后才标记完成。导出诊断继续由正式渲染服务产生，不使用 `scripts/accept_*`、fixture 修补或 Codex 注入的中间响应代替产品流程。

## 状态与成本

`html_course` 保存运行状态、当前阶段/消息、历史事件、授权项目和账户范围、原请求、文章/分镜/模型快照、逐页子任务与复用理由、视频结果及错误。Agent `pipeline.status` 在既有响应中增加 `workflow_type` 和可选 `course`；图像任务保持 `legacy_image` 默认值。

供应商没有回报金额时，成本 `amount` 和 `currency` 必须为空，并明确显示 `provider_cost_not_reported`。可累计生成/语义 `LocalJob` 已落盘的返回阶段回执数，但不能将其称为完整请求数量或费用；TTS 与视频成本也继续标记未回报。重开任务按任务 ID 更新回执记录，不能重复计数或估价。

## 验证边界

自动化测试验证来源与版本门禁、未知请求不重发、人工音频确认、嵌套项目状态和 Agent 合同同步。它们不证明付费模型实际质量、真实供应商恢复、课程视觉审美、用户试听/批准或端到端课程导出；这些属于 A06 的真实课程验收。
