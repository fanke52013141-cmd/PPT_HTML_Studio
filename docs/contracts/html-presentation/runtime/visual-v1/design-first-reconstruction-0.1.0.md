# 整页设计先行与受控还原 0.1.0

2026-10-13，HPS-011/013/015/017/023—030/035—037。本增量替代 application-production0.3 中纯代码与全部复用素材页跳过设计参考的规则。

用户明确的目标链路：**组件库＋生图模型生成的图片 → Agent处理 → 代码组件＋图片还原**。组件库同时提供设计参考和可执行能力；Agent实际读取设计图，分配可编辑代码对象与独立图片素材并完成还原。当前受控静态操作是此目标的已实现子集，不代表多素材拆分已完成。

模型等待策略以质量为先：不因等待较长自动关闭或降低思考；延长请求等待并保留任务状态、未知结果与恢复门禁。历史关闭思考实测不构成生产配置。等待上限与实际思考策略应随请求记录，不能把供应商默认等同于已确认开启思考。

| 定义 | 规则 |
|---|---|
| 正式生产 | 新生产任务先生成整页设计参考，纯文字页也执行；已有有效设计候选按原身份确认后复用。缺图片连接明确停止 |
| 参考输入 | 准确当前页内容、标准组件截图、当前风格和注册结构/容量。不得生成任意新业务组件或把整页图片当正文 |
| 设计停点 | 首次返回 design_review，不生成作者 HTML；用户确认实际候选 key 后进入还原。试听/研究候选不写人工批准 |
| 还原模型 | 首轮收到设计图与结构化的当前对象、槽位、实际测量、公开部位及允许覆盖；修复时再附失败候选截图。初版双图调用180秒超时留存unknown，新单图策略不宣称已实测通过。模型仅返回注册静态操作或 unsupported |
| 权限 | 不改文字、身份、模板、主题、素材引用、关系、讲稿、动作或绑定；不输出 CSS/HTML。新结构或缺失能力回到规划/能力定义 |
| 有界执行 | 最多两次还原决策；结构/容量失败可反馈一次。网络或未知供应商结果不作为结构错误补发。原任务阶段记录保存实际请求、图片哈希和响应 |
| 实际消费 | 合法操作经原编辑服务产生候选，由共享浏览器实测；通过后才参与保存，失败回滚。人工覆盖保持保护 |
| 验收 | 展示真实设计图与 HTML 截图，原文/资源/动作未改分别核对。浏览器通过不等于设计相似度、美感或语义批准；这些需用户审阅和后续独立 QA |
| 恢复 | 还原审计目录由输入身份确定，附件字节参与阶段缓存；新增源模块和 Prompt 纳入快照。旧来源变化时重验，不升级历史批准 |
| 兼容 | 无变体时保持作者版本；注册变体显式scene0.6→0.7，绑定仍0.2；旧已保存页面可继续读取。新任务行为收紧，无数据库迁移；旧未完成任务仍执行原恢复和未知结果门禁 |

首版受控还原的能力为现有对象的基础位置、尺寸及公开文字字阶、字重、行高、对齐；颜色和组件造型归主题与注册组件。遇到设计图要求超范围的造型、构图或自由素材，明确 unsupported，不宣称已忠实复刻。

## 实测发现后的注册呈现增量

内置生图的纯文字页采用了描边卡片、图标圆底和编号徽章；旧 text 槽位无法仅靠位置字号实现。新增 scene0.7 的 presentation.variant/icon，由 `presentation-variants.json` 注册：plain、text-card-outline（C02）、text-card-soft（C03）、header-badge、summary-panel。适用节点类型、固定内边距、图标尺寸与参考来源明确；色彩仍消费主题 token，不新增自由 CSS。

三枚通用 SVG 图标 speech/document/coins 登记到原图标表，作为可选装饰，不自动证明语义。set_variant 只接明确已注册变体/图标，不改节点种类、原文或动作。scene0.6 经受控操作显式升级0.7；旧版本拒绝新字段。绑定仍为0.2，初态/稳定动作保留。summary-panel 将 term 按实例原文展示，避免默认流程措辞进入非过程页面；输入→输出关系仍来自原计划，语义另验。

## 真实失败推动的提示词修正

最终Prompt0.4提供程序计算的逐对象当前坐标/尺寸上限、修复当前状态说明及中文行高提示。继续同一Pro、单图、关闭思考，一次12.587秒返回合法操作，真实共享组件静态检查通过；复用16.776秒真实配音，逐句播放器及30fps所有输出帧/动作边界遮挡安全检查通过。原文/ID/作者动作未手改，审美/设计相似度/语义/音频签收仍待用户，完整证据见后续交接文档。实验是隔离研究候选，未在真实用户项目写设计批准或正式导出。

0.2单参考图＋关闭思考实测两次返回，分别11.158/9.629秒；首轮安全区失败，修复轮part字段错误，未产生合格HTML。0.3补充代码坐标与图片坐标的区别、安全区及逐对象原动作位移预算、顶层part示例、变体图标适用范围。实际请求/回应全部保留；耗时变化同时涉及图片数与思考参数，不能归因于某一个因素。
