# 设计图与计划对应 0.1.0

关联 HPS-010/011/013/015–018/023–030/037；契约包 0.9.108。原 API1.59.0 和计划0.2.0保持。

## 输入与对应关系

`html_reference_package.py` 是设计生图输入的唯一所有者。请求级 Prompt 升级为普通0.3.1、语义0.4.1；不是设计理解运行 Skill 的版本变化。

从冻结 `slots` 派生 `screenTextSources`，逐路径登记屏幕文字：header编号/标题，text完整runs，label/badge正文，card标题/正文，figure已有tag/note，summary已有heading/from/to/term/takeaway，chart轴标题/单位。身份、素材ID、讲稿、视觉意图、风格与检索title不是新增屏幕文案。runs按原顺序组合；同文不同字段各呈现一次，不能全局去重。chart刻度只按已有数值派生。

生成器须完整呈现已登记字段，不能把正文拆成额外标签，不能自行添加小标题、改述、重复结论或引导箭头。未定义的heading/tag/note保持缺席；只表现计划已有arrow/annotation及summary固有关系。装饰图标不承载文字或额外关系。历史已验证参考包在修订时从其冻结slots重新派生清单，不修改历史包字节或校验身份。

## 错误归属与停止

计划缺少讲稿所需概念、对象或关系：回规划；设计图自行增加计划外文案/关系：回设计生成。两者均不由局部静态操作补写作者。必要文字不能按装饰忽略，理解/还原/审核的保守阻断保持。清单只是输入约束，不是OCR或视觉对应已通过的证明。

## 验证与新对照

单测覆盖文字字段、同文多来源、runs聚合、元数据排除及原语义分工；原生产测试验证设计检查点和后续门禁。实际生成后须看图核对全部来源/多余文字/多余关系，并单列设计对应、工程、模型审核、人工视觉、音频与输出状态。

新对照冻结同一计划、修正图、模型和预算；Legacy/Pi独立隔离，记录实际调用/用量/终态/原始回执。原unknown不复发、不改写；新图和新Prompt是新试验输入。候选及实验选图不构成人工视觉批准。
