# 编辑器音频新鲜度 0.1.0

HPS-007/009/010/011/013—017/023—025/037。沿用原音频产物指纹；editor.read/preview返回audio_revision，preview/save可选expected_audio_revision。提供时不匹配返回409 AUDIO_REVISION_CONFLICT；省略兼容旧调用，操作期间仍检查音频产物未变。来源为原tts_artifacts.artifact_hashes，不在scene/binding写入派生时间。

正式编辑器在预览/保存/开始音频播放时校验指纹；变化暂停、轨道只读并保留草稿。显式“刷新配音与时序”只更新当前音频指纹、重新校验草稿/绑定并重载原音频，不自动重绑或丢弃编辑；场景revision冲突仍走原冲突流程。原句不匹配时拒绝刷新候选，不写作者数据。

音频指纹包含实际音频/时间轴/文字/metadata/字幕字节，即使时长相同也识别替换。载入带指纹cache key的音频后，继续内容/媒体时长区分及单时钟。关闭/迟到请求不恢复已销毁UI。此为操作时校验，不声明对外部文件的实时监控或跨进程无锁原子读取。

真实现有旁白只复制到隔离目录做播放/seek验证，不生成新TTS、不改原run、不自动批准。真实素材验证与合成“换音频/换时间轴”回归分别记录，后者不冒充真实重新配音。
