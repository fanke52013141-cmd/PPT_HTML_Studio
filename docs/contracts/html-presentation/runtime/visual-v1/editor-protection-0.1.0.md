# 人工编辑保护与保存边界 0.1.0

细化HPS-007/009/010/011/013—017/023—025/037，承接原场景编辑/修正契约。无新公开API或作者格式。

- 人工保存按稳定对象/actionId登记实际改动的叶字段；首次增加可选presentation/binding容器，不应锁住未改动的兄弟字段。已有父级保护记录继续保守生效，不静默改写历史保护范围。
- AI候选校验与最终save_editor(origin=ai)使用同一保护函数，比较当前作品到候选的实际差异；父子路径重叠均拒绝，包括删除容器绕过子字段保护。候选未触及保护字段且其它校验通过时允许保存，不把AI新增字段登记成人工保护。
- human来源允许用户明确修改原人工字段并累积保护。来源合法性在no-op之前检查，不能以同值请求绕过来源检查。公开编辑器/Agent手工编辑语义不变；AI生成修正继续原repair入口，不新增可由客户端自报的origin参数。
- 过期revision、保护冲突或非法来源在任何持久化之前拒绝；作品、binding、revision、人工记录、批准、音频及重建记录保持。有效保存/同值保存继续原子回滚与最小重建，不新增TTS/生图/批准副作用。
- 工程隔离通过与真实课程/视觉/输出批准分开；本卡不自动完成P3整体签收。
