# 正式动作时间轴定义卡 0.1.0

细化 HPS-007/009/010/011/013—017/023—025/037，承接布局编辑与原动作绑定契约。

- React Timeline Editor 仅提供已有动作条/只读讲稿/外部游标，不调用其engine.play或执行效果。复用原播放器；有效音频以audio.currentTime驱动画面及游标，无有效音频时明确作者预览，绑定动作条只读。
- preview附加只读timing：原binder验证的语块窗口、作者offset/duration与实际起点/时长和裁短原因。派生时间不保存为作者数据，不新增scene/binding字段；Web/Agent响应同步登记。
- 动作身份为actionId，旧版兼容targetId:type。选中动作联动原对象属性；已有属性中的显式语块重绑继续原服务，时间轴不自动跨句。
- 拖动改变绑定offsetMs，左右resize改变作者durationMs和必要的相对offset；保持edge、beatId、原句hash及动作身份/类型/顺序。越句、过短、重叠/顺序错误先由本地适配拒绝或原preview校验拒绝，失败恢复轨道/草稿，不增加undo。一次手势一次原子历史。实际裁短条显示有效时长，保留未修改的作者时长，修改时长才回写新duration。
- 播放/暂停/重播/逐帧/游标seek共用同一时钟。进入布局/校验候选/关闭/换页暂停音频及播放器，取消RAF/监听并销毁React根，拒绝迟到请求；音频加载失败明确停止，不能静默冒充音频同步。
- 保存继续expected_revision、no-op、人工保护和最小重建，不调用TTS、生图或自动批准。新增/删除/改动作类型回原规划；音频状态/时间轴不一致拒绝联播，正式输出仍走原批准门禁。
- 仅构建的timeline独立bundle/CSS/notice/source manifest进入tooling快照闭包。第三方许可证分歧继续如实登记，构建记录不代表发行许可认证。

工程、合成音频浏览器、真实旁白与视频输出分别验收；合成静音通过不等于真实配音/课程签收。P1剩余压力覆盖独立记录。
