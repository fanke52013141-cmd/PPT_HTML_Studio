# 编辑式三栏重建定义卡

2026-10-08；关联 HPS-005、007、013、015、017、023–030、035–037。用户已认可实际 Token 整页生图设计参考；本卡先定义还原所需最小能力，再实施。图片设计通过不代替 HTML、资产边缘及输出验收。

## 版本与归属

新 `hps.visual.scene` 0.4.0 增加通用 `shape` 原子；0.3.0 保持原节点词汇和含义，未知版本拒绝。0.1/0.2 适配仍仅到 0.3，不静默升到新形状格式。theme/layout 仍用既有 0.2.0 属性，template 仍 0.1.0，不修改 P01/E1/E2。

shape 必填 id/slot/type=shape/kind=rect或ellipse/fill=已定义色彩角色；rect 可有 radius(0–60)，默认0，ellipse不接受radius。没有自由CSS、脚本、URL、坐标或课程内容。布局拥有包围盒和层次，主题拥有实际颜色，实例选择色彩角色和最小独立目标；渲染使用CSS，纯时间enter/emphasize/exit沿用原机制。0.3节点不能使用shape，返回明确版本错误。装饰只作为辅助对象，不替代文本、语义关系或图片锚点。

## 模板、主题和对象

`editorial-three-columns-v1@0.1.0` / `editorial-three-columns-v1@0.2.0`：上部左标题/定义、右概念图，下部三知识列。分类沿用 explanation-cards（三个解释单元），实例以 text/shape/arrow/image 基元组成，不复制 Token 专用业务组件。新主题 `amber-editorial@0.2.0` 复用已登记外观字段；字号和色彩角色独立于内容。

画布1600×900，y≥800字幕独立；各列正文最多3行，标题最多2行，最低正文26px；不缩字号吞长文。原模板必填槽保持不变。新模板不要求旧 annotation/anchor-label/summary，明确新结构替代，不把缺失对象藏在透明像素或空白文本中。

实现清单：header、headline、intro、三列标题/正文与编号均HTML文字；标题下短线、三列分隔线、编号圆底、纸张和抽象单元为shape；关系箭头SVG；subject为唯一PNG。图示标签“文本/Token”来自权威定义，不依赖生图OCR。纸张/单元明确抽象示意，不宣称真实切分数目。文字/单位/关系可编辑，图片预算仍1。

可编辑性指当前场景JSON及既有保存入口，不声称新增所见即所得编辑器或任意CSS编辑。初版按手工权威场景构建；自动LLM规划不得选未支持对象词汇的模板，需单独接入后验收。

## 动作与资源

稳定 header/headline/intro/subject/card-1/card-2/card-3 IDs 保留。新增子对象分别绑定同一已有语块；前三段在原 card-1/2/3 时刻出现，几何固定，无重排跳版。不新合成音频；复用用户认可的原MP3、字幕时间轴。抽象图形首段出现，末态稳定。文字容量、随机seek像素与字幕安全区独立检查。

灯泡从已确认的设计参考单独提取，保留完整轮廓和可追溯裁切/处理参数，不将整页当图片背景。当前参考为不透明暖白，边界颜色处理只移除与裁切边界连通的近背景，不把此处理叫多模态AI分割；保留主体内封闭白色高光。提取图须展示并检查残留/裁边，待最终HTML视觉审阅；不得仅依据整页认可伪造独立边缘批准。
