## 执行2.1.1勘误：能力、证据与停止结果

契约0.9.102/API1.55.1。任务/结果JSON仍为0.2.0；本节修正2.1文字歧义，不放宽既有门槛。

1. 开始前先读取本任务`constraints.json.required_abilities`（与`task.context.execution`一致），逐项声明真实能力。
   `decision-input.json`同源展示能力门槛和严格模式。摘要不能覆盖任务、原文或人工保护；声明互相矛盾时停止并请求澄清，不能自行挑选较宽松解释。
2. 必需能力为true而实际为false时，结果必须为`needs_input`（缺能力/环境/材料）或`unsupported`（当前协议不能表达），且`operations=[]`。
   `proposed`不是绕过门槛的草稿状态；`not_run/unknown`也不能覆盖必需能力。不得为通过校验虚改能力、任务条件或task_id。
3. 要求`can_view_images=true`的候选，必须实际查看有关原图并将`baseline_visual_review`记为`self_checked`，引用实际文件/时刻和观察。
   有看图能力但尚未看图不能提交该候选；仅填true、读坐标、OCR或像素计算都不等于完成原图理解。系统只检查声明和证据记录完整性，不能证明模型真的看懂。
4. 文件模式缺`can_access_original_preview`时，原DOM容量、指定遮挡、`candidate_visual_review`可为`not_run/unknown`，由交接方原系统接续。
   这不免除必需的原图理解或官方预检；仅有before不能声称after已看。静态无音轨不声明音画同步。
5. “纯参数候选可交接验证缺口”仅适用于本任务明确未要求图像理解、且目标本身无需视觉判断的情形；仍须满足其余必需能力、预检和验收。
   若goal要求视觉保真而结构化门槛却未要求看图，应停止说明冲突，由签发方重新定义任务。无视觉Agent模式不能通过事后降级本任务来启用。
6. 合法停止结果仍交`result.json/report.md/verification.json`，说明所缺能力/材料、未运行项和下一步；无需伪造通过的`preflight.json`或after图。
   系统可记录停止原因，不产生采用资格、候选保存或人工工作区。已通过参数工程诊断不能代替正式交付，不计外部自主成功。
7. `manifest.json`及存在的`trial-manifest.json`用于本轮材料hash/字节核验，必须读取，不是旧答案；后者只补充本轮试验材料，不能覆盖原任务身份。
   冷启动禁止参考旧结果/主机修复答案，不禁止核验本轮清单。未核验不得声称输入身份已检查。
8. 报告分开记录外部状态、原系统工程结果、人工接手和最终批准。所选可行参数不是唯一可行域，未证明不得写“只有此区间可解”；单页且模型/工具能力不同不宣称输入单因素效果。

规范/运行源码/能力版本变化后必须重新导出新任务，旧任务和原失败证据保持历史；不补写旧ZIP、迁移旧批准或把旧结果改ID后采用。

## 人工工作区

仅通过任务身份、必需能力和验收记录完整性验证的静态proposed交付可创建独立工作区：B原场景、A原AI候选、W人工操作应用到A后的草稿。needs_input/unsupported及能力/身份拒绝不在此范围。工作记录按任务/result_hash与工作版本持久在run内，不写作者。AI候选重放始终source=ai并核对既有保护；人工修改只允许原scope/operation_schema里的静态操作，不接受外部source、完整任意scene或扩scope。

每次人工更新为基于A的完整替换操作列表；服务重放，核对工作乐观版本、源身份与当前revision。允许容量/边界失败的受限数据留作工作草稿，正式保存仍重验全部compiler/原播放器/字号/指定遮挡。Schema、身份、资源或旧人工保护冲突不提供可采用回执。诊断图固定diagnosticOnly=true/passed=false，不能充当通过证据。

工作检查回执绑定任务/result_hash/人工操作/工作版本/当前源身份。修改立即作废回执；过期/切页/迟到响应不覆盖当前工作。保存由用户显式操作，先再次source=ai重放原候选，再应用显式人工事务。最终叶保护=已有保护∪人工事务实际触及且最终与B不同的叶字段；AI未被人工触及的字段不因用户保存而变为人工保护。

混合保存复用save_editor的原锁、原子异常回滚及失效；增加内部已验证mixed来源路径，不接受外部自行声明mixed或protection_paths。旧AI/human入口保持；工作区保存不提升视觉/语义批准。持久工作草稿不等于已保存作品版本恢复；P2检查点、依赖组局部采用、辅助搜索不在本期。

## 页面与接口

网页提供任务条件、问题定位、原始交付、人工参数表、撤销/重做、重置为A、恢复工作草稿、检查与独立保存。错误不自动截断数值，不缩字，不改motion。上述合格交付的原系统工程检查失败可留工作副本，保存禁用；能力不足或停止结果不能借此进入工作区。外部Agent注册work_read只读能力可读反馈/工作状态，人工创建/编辑/检查/保存仅Web交互入口，不为外部自动执行者赋予人工来源。

所有接口复用项目/account权限与项目工件锁。工作状态与源身份不匹配409；工作数据有界、静态操作最多20、路径不可由用户输入。无DB迁移、provider/TTS调用，无正式输出或批准写入。
