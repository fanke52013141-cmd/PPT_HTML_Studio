# S05 正式快照导出定义卡 0.1.0

2026-10-12；HPS-008/009/010/011/012/014/015/017/030。只适用于 HTML 后端；不改变图片后端、原音频服务、scene 或人工批准格式。

| 项目 | 规则 |
|---|---|
| 身份 | hps.html.course_export 0.1.0；整课 manifest 固定有序页快照、源指纹、源码工具、可选数字人配置/实际视频。hash 覆盖 manifest 和文件；复验所有页快照 |
| 门禁 | PPTX 要求原页面/资源/视觉批准有效；视频还要求全课音频确认、动作 binding 有效。诊断 preview 不成为正式批准 |
| 冻结 | 正式任务先冻结整课，再启动浏览器。页面使用 S01 本地字体/素材/播放器，不读取 live resources，不允许 HTTP 图片依赖；PPTX 默认不含字幕。数字人输入显式冻结，单视频上限 1 GiB，缺失/超限阻断 |
| 隔离 | export-work 下每次独立目录；异常只清理自己分配的目录，不扫描共享 render_work；原进程锁/并发约束保留 |
| 分段复用 | 页内局部时间；实际消费的场景/绑定/音频/时间轴/字体/素材/播放器/工具散列、Chromium 二进制/Playwright/Node 身份、编码与 fps 进入键。全局 revision/顺序及未引用素材不加入单页键。命中仍验证 hash、流格式、帧数、时长及完整解码；只有已验证分段入库；已成功任务复用还核对当前源、工具、运行身份、最终 hash 与完整解码，不凭文件存在返回成功 |
| 时间 | max(ceil(scene_ms × fps/1000), ceil(audio_seconds × fps)) 决定帧数；尾帧保持，不截断旁白；全片偏移由各页整数帧累计。重排/删页仅按新 manifest 拼接 |
| 视频候选 | staging 编码、ffprobe 和 FFmpeg 完整双流解码；最后数字人合成后重新验证最终文件，验证失败不能发布。验证报告并不等于画面审美批准 |
| PPTX 候选 | 冻结 PNG 完整读取/尺寸检查，PPTX ZIP CRC、页数及逐页实际嵌入图片比对，通过后移入 presentations。能力仍为 image_only_snapshot，不承诺原生逐对象编辑 |
| 发布 | artifact_records 继续为作品记录来源；同项目作者锁下比较冻结指纹与当前输入并登记。迟到的旧结果可保存为历史作品，不 complete stage 8、不解决当前影响、不替换 out.mp4；只有当前交付可替换默认视频 |
| 兼容 | 显式 allow_legacy_unbound 仅留旧工程测试/探索入口；生产默认严格快照路径。无数据库迁移、新公共能力或第二任务状态源。新 evidence 是 metadata 中的兼容扩展 |

定义、实现和验证分别记录于 S05 handoff。真实生产课程的视觉/音画签收仍由用户完成；静态工程和编解码通过不得冒充该签收。
