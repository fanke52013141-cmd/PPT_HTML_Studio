| 能力 | 输入与结构 | 所有权、限制与验收 |
|---|---|---|
| figure-frame-top | figure的原tag/note；注册描边容器，tag在顶部内侧、note可选 | theme提供颜色/圆角；固定组件内边距，不改变图片对象、素材及内容；最小360×240，标题区域容量须通过 |
| annotation-dashed | 原targetId/anchorId/labelId/radius；虚线圆圈与带箭头引线 | 只允许set_variant改变外观；不接受位置/尺寸/字体/icon覆盖；终点继续由原图锚点和标签边界派生，不承诺水平线。进度控制已绘线长，随机seek无状态；旧实线保持 |

scene0.7增加上述注册枚举，annotation仅接受variant字段；旧版本/旧变体不改变。原人工叶路径/祖先保护、revision、绑定和严格几何/语义审核继续生效。原TTS文件不因此重新合成；renderer/定义变化使当前HTML视觉、语义报告及视频需要重验，旧快照和批准不重签。Web/Agent/CLI复用原set_variant，能力版本与说明同步；没有新业务操作或自由CSS。
