HPS-007/009/010/013/015—018/023—025，包0.9.112，2026-10-20。定义先于实现；内部候选能力，无新公开HTTP/Agent Schema。

- 输入为当前scene/binding/人工保护、固定scope、原registered全页动态报告。只处理线性箭头穿文字，且scope内对象是受影响文字或原箭头端点对象。不增删节点、不修改文字/样式/字号/端点身份/动作/音频，不修改规则或允许对。
- 纯数值预筛仅预测主线/文字矩形变化及邻居距离，不是另一个验收器；尺寸改变可能引起文字重排，箭头头部/运动等必须原浏览器复验。保留失败、预测偏差和无合法解。
- 搜索只含单对象有限平移、卡片有限尺寸和其组合。位置变化绝对量每轴≤96px，尺寸在原测量的75%—115%内；公共工具限制仍由原candidate/保护/编译器决定。不以缩字号解决，不枚举自由CSS/新路由。
- 优先预测无穿字、改动较小和邻居间距损失较小的候选；固定最多6个原sampled预览，再对通过者中至多3个作原30fps全输出/动作边界检查。全量失败不得称成功；候选不保存或批准。已通过原页不改；证据或能力不足返回needs_revision。
- 候选来源固定于revision/音频/原运行代码；调用原candidate/preview/evidence完成保护和检查，不直接写作者。输出原candidate_key/request可走原显式save复验。源码加入生成闭包，行为变更按原快照失效规则处理。
- 评测区分真实原页、真实内容的受控扰动和无故障对照；分别记录通过率、总耗时、检查次数、改动、文字换行和启发式间距指标。指标不是人工审美批准，不能把衍生样本当独立课程或将旧模型单样本当严格速度因果对照。
