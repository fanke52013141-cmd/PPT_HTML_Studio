# HTML 工作区流程与界面归属 0.1.0

2026-10-15 同页同步增量（HPS-010/013/015/017）：可见设计/页面工作区每五秒及重新可见/候选变化通知时只读读取当前任务、候选与页面状态。新候选在同页更新，保留草稿说明与已展开设置；旧请求迟到不能覆盖新操作或新项目。读取失败时禁用提交及页面确认，恢复读取后按当前事实重算。任务与设计响应身份不一致时等待下次一致读取；本地提交不被后台同步覆盖。仅刷新不触发生成、编辑保存或批准。

本轮实现、隔离验证与待验收项见[六步界面集成交接](../../../../plans/html-backend-development/handoff-six-step-ui-2026-10-15.md)。

2026-10-15 六步呈现适配（HPS-010/013/023—025）：应用工作区按新 Codex/Stitch 候选采用统一橙色、紧凑标题、分镜双栏、设计预览/确认栏、音频试听/核验分栏及数字人预览优先布局。规范尺寸和来源见 `docs/ui-spec.md` 的 HTML 六步增量；CSS 限于 `body.html-workspace`，音频模块只增加呈现容器。控件 ID、请求、时钟、任务恢复、页面/项目生命周期、各阶段独立确认和图片路线保持。不把生成稿中的额外图标、通用波形编辑、任意动作或虚构指标加入产品。定义为兼容呈现调整；工程证据见六步界面集成交接，真实课程与人工视觉验收单独记录。

2026-10-14；HPS-010/013/015/017/023—030。用户要求纠正旧图片流程与HTML界面的混杂，取消HTML独立勾画步骤。替代旧“八个可见位保持不变”对HTML后端的要求；图片后端原流程保持。

| 可见步骤 | 解决的问题 | 结果与下一步 |
|---|---|---|
| 导入文章 | 本次要讲什么 | 原始内容进入分镜 |
| 分镜规划 | 分成几页、每句对应什么画面和动作 | 权威讲稿/画面意图，进入设计 |
| 设计图生成 | 页面构图、风格、层级是否合适 | 先生成整页设计图，用户确认实际候选后才还原 |
| HTML 还原与动画 | 如何把设计图变成可编辑/可控制的画面 | 按设计生成独立配图，以代码对象和图片还原；检查/编辑/确认实际画面 |
| 配音与同步 | 每句何时播放、动画与字幕是否对齐 | 实际音频绑定后逐句检查与签收 |
| 数字人讲解（可选） | 是否加入讲解人像 | 复用原数字人模块，不计必做进度 |
| 作品输出 | 当前签收内容能否导出 | 原正式输出与当前性门禁 |

整页设计图是构图参考，不是最终整页图片背景；独立图片素材是还原中确需图片表示的主体。页面对象是可控制的文字、图形、图表、箭头及图片，供动作引用。圈画/高亮等表达在分镜中规划、在HTML还原与动画中实现，按真实配音时间绑定；生成设计图不代表动画或配音同步已完成。只支持已注册动作，不把旧笔迹模块隐藏宣称为新增HTML画笔能力。

没有另加“数据素材”步骤；内容数据属于分镜事实，数据图表属于注册页面对象。页面名称用于定位页面；现有模板/计划标题字段保留，不因此扩充为所有页面必须有大标题的产品规则。任意无标题模板尚须按原公共能力定义/注册，当前UI改动不承诺已实现。

实现归属：static/flow.js负责HTML可见目录（内部键1/2/3/5/6/9/8）及图片目录隔离；workspace_navigation.js负责真实分开的3/5路由，5不再重定向3；html_review_panel.js复用一个生产/恢复上下文，在3展示设计操作、5展示实际页面/编辑/审核。离开HTML时恢复图片/Mask工具原样式。html_workflow.css仅作用于HTML工作区，运行散列与底层细节折叠为运行记录。素材板作为还原中的可选入口，逐句QA作为音频后核验入口，不在设计图阶段展示未执行检查。

迁移/兼容：无DB、API、scene或批准格式变更；旧内部勾画位置10在HTML项目映射到输出或配音，不进入旧图片勾画工作区。隐藏UI不删除历史数据、不改导出权限或作者动作。标题/生成Prompt未改，既有设计和unknown回执保持；确认按钮仍提交原design_candidate_key，不创建手写scene或自动签收。

验收：两工作区路由/按钮/旧工具隐藏、HTML无独立勾画、连续显示编号、后端切换恢复、纯只读导航无模型POST、未保存设计候选不因查看页面被批准、生产上下文跨3/5移动保持，均以实际DOM检查。工程/语义/听审/用户签收仍分开；本轮没有新付费模型请求或正式视频。

同步试听实现约束（2026-10-15）：配音页复用编辑预览服务取得真实音频绑定场景，必须返回 audio_timeline 时钟且当前音频未过期才联播；以 audio.currentTime 驱动共享播放器 seek，禁止独立画面播放时钟或估算语句时间。逐句定位使用绑定场景字幕的 startMs。切换页面/项目/步骤停止音频并废弃迟到响应。音频确认不等于语义签收；当前全课同步阶段完成前停留配音页并提示缺项。预览服务不保存作者场景、不请求生成、不批准。
