# 未保存候选的人工评审 0.1.0

2026-10-15 兼容增量（HPS-011/013/015/017/023—025）：检查入口允许原任务为 failed 或 interrupted；恰有一个不可查 JSON 请求处于 intent 或 unknown，且不能同时存在其他未决阶段。intent 只表示未收到结果，不追认为失败或成功。active/cancelled、旧输入/attempt/人工修改等原保护保持。可读取有完整证据的候选不等于允许再次请求；原任务及阶段账本不改。

排版审计按最终成功 result 的实际轮数（最多三轮）定位，而非固定第一轮。设计分配后的容量修复通过原受限编辑 API 重演每轮 set_presentation/set_text_style，核对最终场景/绑定与归档；仅登记文件不能提供可接受来源。素材使用原始资源清单合并并验证冲突，不将转换后的运行时资源当原始清单。临时资源及报告在成功/异常时均恢复，截图必须与归档一致；失败不开放接受。人工决定仍只是独立证据，不保存作者页面或授予视觉批准。Agent manual_candidate/decision 1.1，API 1.31.0。

HPS-011/013/015/017/023—025；2026-10-14。此入口只处理设计还原模型结果无法查证时，已经形成且留有实际截图的未保存候选。它不恢复、重发或改写原供应商请求，也不把静态检查视为设计还原通过。

`GET html-review/{slide}/manual-candidate/{job}`仅在原生产 LocalJob 已失败、恰有一个不可查询的 JSON `unknown` 阶段、输入快照/讲稿/revision 仍为当前、编译/设计理解/素材阶段均有有效返回时开放。服务从该任务阶段回执验证编译场景和真实素材字节，重演登记的版式及设计理解操作，核对审计场景、设计原图、实际截图与静态报告，生成绑定原任务ID、快照ID、未知阶段、场景/设计/截图/素材散列的候选 key。资源只在项目锁内暂存供本地校验，随后恢复；GET 不写作者场景或批准。

服务用当前注册渲染器重演候选并核对归档截图字节；实际严格工程检查若失败，只开放驳回，不允许人工接受绕过容量或资源门禁。UI 并排展示原设计和该候选的实际渲染，明确标示 `model_fidelity=unknown`、工程结果与首个问题。人工评审者须针对具体对象、位置、可读性等填写至少八字依据，显式选择接受或驳回；POST 携候选 key 重验当前全部来源，形成不可覆盖的独立决定记录。相同决定与依据幂等；不同决定返回冲突。决定与原任务状态并存，`author_saved=false`，不等于已批准正式视觉、已保存 HTML、A04 逐句语义通过或整课完成。后续作者提交须另设有工程重验、人工修改保护、失效处理和原子提交的入口，不得直接把本决定当场景文件。

此人工停点是模型对照审核超时后的可追溯人工证据，不伪造模型 pass。输入/代码/图片发生变化、截图丢失或来源不唯一时关闭入口；不能换任务ID、绕过 unknown 或用新的付费请求代替原结果。原失败任务及阶段账本保持不变。
