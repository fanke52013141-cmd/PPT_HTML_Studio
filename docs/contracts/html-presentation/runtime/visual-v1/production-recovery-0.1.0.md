# S02 生产快照与阶段恢复 0.1.0

2026-10-12；HPS-010/011/014/015/017。增量定义卡；作者格式、审批、音频门禁不变。

| 项目 | 定义与实现边界 |
|---|---|
| 输入 | 生产提交先建 generation 快照；snapshot_id 加入提交身份并保存到 LocalJob.input。执行器从已校验快照读取 contract/options，不使用调用方可变对象 |
| 模型 | 凭据只在内存；公开配置摘要参与提交身份，快照保存 provider/model/config_digest。重提时重新解析连接，配置变化形成新任务；不执行快照中的 Python |
| 依赖 | 每个恢复/发布安全边界重验快照字节、当前 revision、已固定代码/定义/参考图和所用已有素材散列；变化阻断而非混用新旧输入 |
| 阶段 | plan、brief、design、逐素材、compile、review 记录散列产物；LocalJob.payload.production_stages 是唯一持久阶段账本，stage 为当前阶段展示 |
| 外部边界 | 请求摘要及附件实际散列组成阶段 key；先提交 intent，再请求，结果写文件后以 CAS 登记 returned；捕获异常登记 unknown。不持久化凭据或原请求 Prompt 到 job 载荷 |
| 恢复 | 同输入失败/中断任务由显式重新提交继续同一行、attempt+1；returned 模型响应经散列/格式验证后复用，再做计划归一化、编译和真实检查。检查截图和最终批准不跳过 |
| 不确定 | intent/unknown 阻止同任务重新提交；结果文件删除/损坏也阻断重复模型请求。首版不提供供应商查询或强制重新请求按钮，不承诺恰好调用一次 |
| 预算 | 跨 attempt 保留全部请求记录，最多 12 个外部适配器边界请求；原 3 次任务尝试上限及各模型适配器内部原有有界策略保留。此计数不是底层 HTTP 请求计费统计 |
| 迟到保护 | 阶段登记、状态完成使用 attempt/status/payload CAS；检查失败回滚作者文件。取消的快照任务不可通过相同输入隐式恢复；旧无快照任务保留旧生命周期但执行器拒绝生成 |
| 兼容 | 现有 Web/Agent 生产和任务端点共享执行器；任务读取新增 snapshot_id/stages 字段；无需数据库 migration，不引入第二状态库，不改图片后端 |
| 检查与批准 | 工程测试不代表审美、真实供应商、动态、音频或正式导出通过；设计确认停点和作者人工保护保留 |

已实现：快照生产接线、边界响应复用、阶段证据、安全阻断。确定性阶段重做以恢复语义/容量校验，没有将旧审阅通过当作新作品批准。

未实现：供应商状态查询/幂等键、授权后重新请求界面、错误分类后的自动网络重试、底层 HTTP 累计预算、作者保存成功后进程退出的自动对账。最后一种窗口会因 revision 变化阻断恢复，要求读取现存作者作品核实，不重复覆盖。S03 选择性重建和 S05 正式快照导出另行实施。

验收证据：checks/test_html_production_stages.py 的响应复用、文件删除、未知请求、取消、旧 attempt、坏快照、累计预算；checks/test_html_workflow_acceptance.py 的实际生产编译后失败→显式恢复→真实静态检查，以及调用方输入修改隔离。
