# 正文与容器独立评估 0.1.0

关联HPS-010/011/013–017/023–025/037，契约0.9.74。承接reference-text-regions-0.1.0，不以最终选定框正确代替所有层完整。

独立定位0.4.0要求container_presence=present/absent/uncertain。located的不确定容器判断阻止签发结果；present必须有容器框，absent必须无框。not_found必须absent、无文字/容器框，无可见转录；ambiguous可诚实不确定但不得有框。程序只能核对这些声明相互一致，不能从声明证明图上背景存在或不存在。

运行Prompt要求独立查看实际浅色底条/边框/模块底板，即使region_scope仅取正文也不能省略背景。纯白画布不算独立容器。正文逐行框、最终框按scope选择和像素/包含关系保持，不自由补坐标、用OCR假装核验或绕开旧批准规则。新请求严格要求新字段，旧0.3归档可继续按原合同读取，不能将缺字段误升级为显式absence。

固定案例追加独立正文包围盒及容器存在/边界标注checks/fixtures/reference-layers-page2.json，在新模型请求前保存；原selected-region gold、原图和原阈值不变。文本包围盒及每个有容器目标分别按IoU≥0.6与覆盖≥0.9评估，标题无独立容器作absence负例，原不存在对象负例保持。每一层和整轮联合通过率分开报告；正文定位通过不能抵销容器遗漏，正文文字框几何通过也不等于逐字OCR正确。

同一新增标注同时用于旧0.3原始结果和新0.4三次独立请求。旧响应缺显式presence时仅按实际返回框统计遗留框存在性，不宣称旧模型做过显式absence判断。基准不传入定位模型，不在生产逻辑中写入本页ID/坐标。范围、身份、容器召回、泛化和接回审核的效果仍独立验收，定位暂不自动接入正式审核。

0.4.1按状态限定identity_evidence：located/ambiguous必须具体且非空；not_found可省略/null/空串，因为没有已识别对象身份可描述，但absence、无任何框和无转录约束保持。程序不补写任何身份依据，不宽容其它状态的缺字段或不确定容器。真实0.4.0原记录中缺此字段的一份仍保留rejected，0.4.1回放单独留档，不冒称新的提供者验证。固定三份原响应回放正文17/18、已有容器15/15、联合2/3；标题编号漏框仍失败，详情见[验证记录](../../../../plans/html-backend-development/reference-layer-evaluation-2026-10-17.md)。
