# 文字片段定位与跨版式评估 0.1.0

关联 HPS-010/011/013–017/023–025/037，契约0.9.75。继承正文/容器分层合同，不改渲染、保存及人工验收门禁。

## 定义与实现

定位输入/输出升为0.5.0，运行片段0.5.1（0.5.0首次真实请求因输出结构漂移被拒绝，0.5.1显式限定唯一JSON形状）。原0.4身份投影漏掉header.number，本版保留number，并将有实际文字的内容路径投影为text_parts：number、title、text、runs/N、from/text、to/text、term、takeaway等。路径作为partId，不以文字内容作为唯一键；不带HTML坐标、样式或期望参考坐标。旧协议解析保留，生产新入口不得将旧响应伪装为新片段输出。

每个target的每个part恰好对应一个part_regions项；含状态及逐行regions，每个region只含实际转录和像素框。程序派生text_boxes、visible_text和最终范围，不让模型重复输出这些字段。located对象各片段必须完整定位；缺片段、未知/重复身份、无框、复用相同框、越界、容器冲突或转录与权威内容不一致均拒绝签发。比较只忽略空白，不忽略标点或改写；参考图缺字/错字可以诚实报告未定位，不自动改写权威内容。完整目标未定位时仍列出全部part且无框。

逐片段声明能检出遗漏、数据矛盾，不能证明框对应真实像素、转录由图识别或视觉通过。不能给历史0.4响应补造文字片段；旧编号遗漏记录保持失败。独立定位仍未接入正式审核。

## 验证设计

四个受控中文位图用例：远距离编号/标题、带图标背景来源条、跨行正文、分散关系词/起终点/结论；每个加不存在对象负例。测试代码绘制位图并测量字体墨迹边界，模型调用前封存图像/scene/gold哈希。它们是评估夹具，不是手写生产页面，不代表真实设计还原成功。gold不传模型。

同一图和身份分别请求原0.4.1与新0.5.0，各版式各一次，交替顺序；原臂保留漏number的真实投影缺陷。保持原连接/low/输出额度，最多8次适配器请求、16次HTTP尝试；未知结果或提交前失败停止，不重发。记录原响应、拒绝/未知、时长，失败计入分母。正文包围盒、逐行一一对应、容器、缺失负例与联合指标分别报告，IoU≥0.6及gold覆盖≥0.9不变。新协议另统计片段几何，不能拿新协议声明齐全替代共同视觉指标。

四个受控版式的一次样本不证明真实页泛化或重复调用稳定性。原真实页固定gold不变；真实页后续复验及正式审核接入另验。
