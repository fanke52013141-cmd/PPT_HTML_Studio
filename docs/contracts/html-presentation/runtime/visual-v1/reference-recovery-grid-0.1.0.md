# 定位复核恢复与知识网格 0.1.0

2026-10-25；HPS-007/009—013/015—018/019—025/026—030/037。本增量扩展七项离线优化中的布局及复核能力，公开API/Agent接口和批准边界保持。

## 定义卡

- `knowledge-grid-v1@0.1.0`模板使用同名`0.2.0`布局，结构复用`explanation-cards`。1600×900，内容底800、字幕区100；header、四张card和summary必需，intro可选；卡片按左到右、上到下固定顺序。槽位宽680高180，坐标(58,220)/(825,220)/(58,440)/(825,440)，summary在y700高70。无图片、关系或额外动作能力，所有文字/图标继续原公开组件。
- 新模板使用原neutral-baseline主题，保持theme/version、已有八个兼容布局和全部视觉数值。`compatibleLayouts`是注册容量，不是单页视觉预算；其既有8项上限已占满，本次将该清单容量扩展为32，保留ID校验、唯一性和编译时精确匹配，不放宽布局边界、重叠、文字或人工保护。生成validator/catalog/player由原build同步。
- 多行联动只提供offset提案，原全帧检查通过才返回。图文pair扩展至原注册区域相离且另一轴重叠的image/figure与text/card；两侧单对象候选分别尝试，保留尺寸/内容/语义关系，任何容器或动画冲突仍由原QA拒绝。
- 本地复核页加入对象/部件选择、文字区域表单、容器表单、导入、缩放和原JSON模式。来源文字只供比对，实际转录须由人填写；不自动OCR、不自动确认身份或裁框。来源文本安全嵌入，继续禁用网络资源。
- `html_reference_replay`以修正hash、执行模式和可选传输身份区分回执，独占创建intent后才派发。完成回执逐次核对结果hash及新鲜度后复用；并发、未知/中断和损坏均停止，不自动再次派发。离线响应必须提供响应hash，与configured_transport隔离。复用是复用原记录，不声称当前配置模型重新审核。
- 复核只写证据/回执，作者/音频/审批不变。新模块进入原设计身份和生成快照；新模板以注册目录进入源闭包。没有新作者写入路径或下游invalidation reason。

## 验收

1. 网格计划经原normalize→compile→共享渲染→完整30fps QA；故意加高上行卡片后下行两卡联动，原内容/动作/binding保持；人工保护阻断。
2. 错位图文案例通过完整动态检查；空间不足不强制修复。
3. 真浏览器表单、越界阻断、导入身份、缩放、下载一致性和移动端验证。
4. 相同修正重复/并发只派发一次；unknown和回执损坏不重发；原图/作者/修正文件中途变化仍停止；离线/配置传输不互相复用。
5. 原引擎测试、生产回归、来源快照及统一离线验收。真实模型、跨课程、美学批准与部署分别待验。

本地产物工作台和内部resume函数继续适用，本次未添加产品面板按钮或公开HTTP恢复接口。
