# 文字边缘完整性证据 0.1.0

关联HPS-010/011/013–017/023–025/037，契约0.9.76。继承reference-part-mapping-0.1.0，不改变模型文字/坐标Schema、运行Prompt0.5.1、既有评分阈值、作者内容或批准门禁。

## 定义

在验证合法的逐part文字行框后，独立检查原图像素。`html_text_edge_verification.py`拥有`reference-text-edge/0.1.0`规则；定位服务返回额外`edge_verification`，该字段属于本地诊断证据，不是模型输出或新的视觉能力。

每个目标/partId/region_index对应一个原框和局部观察窗口。按行高决定观察范围（0.35倍行高，4–32像素），不扩大原文字框。局部主色推测背景，RGB距离≥32为强前景，背景近色占比不足0.55则不确定；支持浅/深底与有色文字，不使用图片后端的白底/Mask规则。

仅沿原框边界的强前景做8邻接连通追踪。组件在框内至少3个像素、框外至少2个像素，且无已识别干扰时标`possible_clip`。局部观察窗外仍延续、长细线、实心形状/图标、与其他文字行区域交叠、接近/跨出声明容器、透明/复杂背景、低对比/空白、图像边缘不可观察及计算预算耗尽，均保守标`uncertain`。独立图标/线条不因邻近就归入文字；相连而未识别的装饰仍可能造成疑似警报，不声称图像分类准确。

无跨界证据只能标`no_detected_clip`，不得标完整通过或OCR核实。整字完全在框外且与框内笔画不连通、错误身份、整段漏定位、未达到颜色阈值的淡字等仍有盲区。程序不从输入文字伪造像素证据，也不自动扩框、修改转录/坐标或照搬背景。

## 状态与预算

每个区域记录原框、窗口、局部背景估计、跨界组件墨迹包围框、框外像素数、触及方向、不确定原因。组件包围框是像素证据，不是建议替换框。整轮有`possible_clip`则`needs_review`；否则有不确定或没有可检查区域则`uncertain`；其他为`no_detected_clip`。任何情况`automatic_review_eligible=false`及`identity_verified=false`，quality仍`model_proposed_unverified`。

局部窗口最多500,000像素、单组件最多100,000像素、单区域最多64个边界组件；超限返回不确定，不跳过后宣称通过。现有目标、片段、行数的严格预算保持。新模块加入源闭包，参考图前后hash、scene当前性及原有严格解析保持。本阶段不调用提供者，不新增自动重试或付费修正循环；正式审核尚不消费独立定位证据。

## 验证

先用独立绘制的文字alpha层建立墨迹真值，字体32px微软雅黑，浅/灰/深底/有色四种组合，四边截字及完整/邻近图标线条正反例；再冻结算法，用18/54px微软雅黑与宋体留出集。另含解析、低对比、复杂底色、相连图形、邻近文字、边界和预算反例，不能只报告疑似截字召回而隐藏不确定负例。

复用四版式及真实页原始响应，原图hash一致才诊断，结果另存不回写。保留原IoU≥0.6与覆盖≥0.9评分；新证据不提高那些分数，也不把旧几何通过当像素完整。真实页没有逐区域独立墨迹真值时只报告疑似警报，不声称准确率。
