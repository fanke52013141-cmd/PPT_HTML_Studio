# 参考差异与跨轮问题连续性 0.1.0

关联HPS-010/011/013–017/023–025/037；契约包0.9.69。此卡先定义共用规则，再由理解、还原、审核共用实现；不是对历史失败追溯签发通过。

## 必须保真与允许适配

权威文字、对象身份、语义关系/方向、明确结构特征、可读性、人工保护、真实素材身份与工程门禁始终是阻断要求。minor不代表允许忽略；geometry/typography/semantic_text/semantic_relation/asset_identity/asset_rendering等问题不得转成装饰观察。

仅代码控制的text/header/summary、已有准确文字完整承载含义时，参考图额外的非语义图标和容器边框/圆角/背景造型可按注册能力省略或映射；不补本例专用组件。不把国家标志、人物身份、数据编码、关系箭头、标签或依赖图标表达的含义归为装饰。image/card等不在本批允许适配范围，无法明确区分时仍阻断。缺图标优先省略，不用无关图标替代。

模型须显式标记reference_detail=decorative_icon或surface_chrome；程序还要求requirement=unsupported_presentation、适用节点类型和实际代码文字，审核severity不得major，才记录为reference_observations。原始响应与观察保留；其它缺陷仍进入原路由。理解必须返回完整逐对象分工，只有装饰问题但无分工的unsupported不得被程序补为ready，只允许既有一次完整输出修复。旧输出缺省reference_detail=null，保持原有保守阻断。

## 跨轮核验

下一轮审核携带前轮未解决问题和当前对象的证据变化，不传理解阶段结论或前轮批准作为事实。当前/前轮原图hash必须一致。程序保存每个问题对象的节点hash、实际几何和实际截图区域hash；当前节点、盒子及区域像素均未变化时，前轮问题不得仅凭新一轮pass消失，强制保留到issues。缺少可比截图区域证据时不得自动清除未变节点的问题。区域或节点变化只是允许模型重新核实，不是程序宣称已修复。

不扩大还原两轮/容量三轮预算，不改变模型、low/thinking、等待、工程/人工批准。原unknown不重发、不恢复旧任务、不代替作者保存或视觉批准。
