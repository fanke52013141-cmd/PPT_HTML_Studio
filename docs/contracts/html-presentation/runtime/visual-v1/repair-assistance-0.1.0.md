# 中文修复提示、关联组采用与自主修复评测 0.1.0

HPS-007/009/010/013—018，契约0.9.104/API1.57.0，2026-10-20。定义卡；实施与真实外部评测状态分别记录。

## 中文诊断和联动方案

仅使用当前工作hash绑定的原检查/DOM测量，以及注册layout、原relationship-capacity及保留动作推导提示。实际值、预算、差额、容差和推算依据分别返回；没有实测不声称DOM结论。只能建议原scope/schema内的绝对位置/尺寸操作，不能缩字号、改文案/素材/主题、改motion/binding、安全线或批准。

高度/宽度缺口按同源内部容量对父框的变化率估算，移动范围同时包含原入场端点和强调余量。无可行余量、数据不全或未支持结构时明确停止自动建议，保留人工修复入口；未知问题显示原错误。不保证启发式建议必然可行。

建议必须先用原compiler/DOM/指定遮挡/字号验收预览，显示实际候选和未通过项；预览不改变工作或作者。只有当前工作hash的通过预览才能由用户确认应用到工作草稿，随后原保存仍完整复验。修改、切组、撤销、重做均作废旧建议/预览/检查；多对象联动作为一次事务。

## 关联组

分组由服务器从原AI操作、对象身份、显式引用、指定遮挡对，以及B/A保留动作的几何包络保守推导，稳定hash标识。相同对象的字号/父框/位置不得拆开；几何相交/显式依赖跨对象合组。不得信任外部自报独立组。分组不证明不存在遗漏依赖，任意组合都须完整整页复验，不沿用全量A回执。

B原页、A不可变完整外部候选、W所选AI组+人工操作保持分离。组选择只是工作草稿，不保存作者；不选择某组意味着保留B中对应值。既有人工操作保留并显式提示。历史/工作hash包含组选项；AI已存在保护照旧检查，人工保护只来自人工实际差异，不能把选组误记成人工改值。旧工作记录默认为全选，旧undo列表兼容读取。最多20个原AI操作、50步历史，范围不扩大。

## 固定评测

固定布局、动画、人工保护、缺能力停止四类。外部文件模式使用原签名输入/完整交付/真实系统反馈，最多首轮加一次反馈后二轮；任务和输出原字节hash、模型/工具标识、轮数、耗时、人工介入/改写、误改、未知费用均留档。失败、缺交付、unknown保留在分母；成功停止与完成修改分别统计，不把受保护用例的强行改写当成功。

离线回放只验证评测器和服务门禁，不证明外部Agent自主能力。真实结果必须从外部完整交付导入、原系统重验后计数；用户自述的能力/视觉/费用不升级为系统事实。没有真实回传时自主成功率为null，不能用夹具答案填充。无自动付费请求、无限重试、作者保存或人工批准。
