# 讲稿限定范围与容量诊断 0.1.0

关联 HPS-010/013/015/017/023—025；合同包0.9.57，Agent API1.37.0。

## 定义卡

| 项目 | 定义与边界 |
| --- | --- |
| 来源 | 当前项目完整文章；讲稿使用归一化后每页 narration，不从图片提取替换 |
| 保真目标 | 否定、条件、对象、地区、时间和概率等限定应随保留论点保留；口语化和删去次要论点不应扩大原命题 |
| 本版检查 | 确定性窄规则：原文有“不/没有…所有/全部/任何…的对象”，讲稿同一语句把同一准确对象写为“没有/不存在/并无/无对象”，且没有已识别的反否定或范围限定时报告风险 |
| 证据 | slide_id、源句、讲稿句、准确对象、原因；这是待核对风险，不宣称语义矛盾已被通用证明 |
| 停止 | 生成后/手动保存前、可视化模型调用前、合同合成前检查；409 SCRIPT_QUALIFIER_REVIEW_REQUIRED，不覆盖已有规划，不自动补发或改写 |
| 恢复 | 对照原文编辑保留限定后，使用原保存入口；不通过后续配音或排版偷偷修文案 |
| 容量输入 | 实际DOM测量及有效槽位，而非仅scroll/client整数 |
| 容量输出 | triggers逐项记录dimension、actual、limit、tolerance、unit；effectiveLimits保留当前测量的槽位宽高和行数限制（存在时） |
| 容差 | 现有规则不变：盒宽高为canvas_px，DOM滚动与文字边缘为css_px；均保留原1px容差，行数零容差，不取整后比较 |
| 审核 | 结构未命中不等于限定词全面保真；容量通过不等于视觉/语义/音频或人工批准 |

## 实现与兼容

`storyboard_planning.py`拥有纯风险检测和保真原则，`storyboard_prompt_templates.py`拥有正式Prompt及编辑器预览的同源组合。可编辑自定义正文不重写；公共保真政策按0.1.0注入实际Step2A system输入，Step2B不混入Step2A任务。

`storyboard_service.py`持有请求、状态和写前门禁；保留协作停止检查的优先顺序。模型原始响应仍沿既有审计路径记录，不进行新增付费审阅。旧讲稿文件、原始失败和unknown请求不迁移或覆写；下次使用已存讲稿时依现行门禁复核。

`html_engine/visual/capacity.cjs`提供原容量谓词的解释，renderer.cjs同时用于严格报错与候选诊断，浏览器bundle从源码重建。既有available/measured/typography字段保留，新增证据不扩展修复权限，诊断结果仍不得视为passed。注册变体最小尺寸与其他门禁不降低。

无数据库、scene、binding、作者数据或音频迁移。原API路径不变；新增409与诊断字段为行为增量，pipeline.run/resume能力1.4。旧快照仍受现有当前性检查约束。

## 验证要求及局限

离线覆盖已知限定范围事故、原句保留、反否定、无关对象、跨句限定不能遮掩、写前停止、模型仅调用一次、下游调用前停止；真实浏览器核对诊断字段和严格重验；合并相等scroll/client而槽位高度超限、行数、滚动与浮点容差边界案例。

本版不实现全面语义蕴含、任意同义改写识别、跨句指代、时间/数量/概率的通用检测或事实核查。误报/漏报须保留实例后改进所属规则，不以降低容量阈值或直接代写讲稿解决。真实“遴选考试”原事故保留，未重发付费请求；新增真实模型效果仍待验证。
