# A04 独立语义QA定义卡 0.1.0

2026-10-13；HPS-009/010/011/013/014/017/028/030。新增独立语义报告，不迁移旧作品。

新scene0.6.0的现有review入口消费已保存的当前场景、规划0.3.0、权威分镜、binding0.2.0及真实音频时间轴。缺输入阻断，作者预览/静态终态不能代替真实语块审阅。复用不可变render快照，新增semantic_review目标不要求事先批准，但冻结真实音频文件/时间轴与语义来源；该目标本身不授予批准或允许正式输出。

确定性层重新编译规划核对对象内容、角色、动作身份/目标/语块及原句来源，复用真实binder/共享编译器与动态工程QA。每个语块采集开始/中点/结束帧，保留实际DOM可见状态和动作事件；明确enter开始时透明属合法过渡，语块结束的预期对象须可见。不得删帧/只交终态或依赖模型自称覆盖。

独立多模态评估每次只看一个语块的三张真实PNG、旁白原句、视觉意图、目标/预期状态、实际对象和资产职责。用户材料视为数据。只返回related/omitted/contradictory/uncertain、置信度和引用原句/帧/对象的证据；不能改写讲稿、生成修复、授予人工批准或捏造来源。related且置信度≥0.85才可语义passed；遗漏/矛盾failed，低置信/无法判断pending_review。没有可用评估服务、坏结构或无出处不通过；每个语块只调用一次，不自动循环重试或修复。

Web/Agent共享项目文字模型freeze/partial绑定，记录脱敏provider/model/config_hash等身份；不覆盖用户连接或凭据。单次评估服务请求超时90秒、输出最多2048tokens；strict_response禁用JSON模式格式回退和文字-only JSON修复，错误保留待审（底层供应商/SDK行为仍由既有治理服务负责）。模型不支持多模态不回退成文字评估。related必须引用所有目标在所引帧中的实际可见证据；背景/隐藏目标不能冒充完成。Prompt0.1.0按项目optimize-prompts方法，仅发送本语块及实际可见对象。

engineering、semantic、audio、human分别登记。语义通过只代表辅助模型在冻结证据上通过，不等于用户批准。audio固定pending_review，human固定pending_review，保留原用户音频/作品审批门禁；课程调度和改稿恢复在A05/A06接入。既有局部修复预算和无改善停止机制保持，不增加越权修改能力。

报告绑定快照、检查器/Prompt字节、工程原始报告、每个PNG/状态/请求/响应实际散列，并重新推导覆盖和状态；篡改摘要后仍需核对实际帧/原始评估。批准新场景须有效的engineering+semantic报告，批准状态重算全部输入/证据；报告过期、来源/音频/资产/绑定变化、帧损坏不得沿用。旧版本读取、默认生产路线及人工批准不自动升级。

Web/Agent/MCP/CLI既有review/approve/status能力1.1，AgentAPI1.25.0；无新公共请求字段/能力或DB迁移。Web原截图入口可选beat_index/frame_index，只读取当前有效报告的三帧，页内提供逐句证据和展开图片。辅助评估报告audio/human为pending_review；真实批准由原门禁另存。报告是本机校验记录，不提供抵抗同时重写全部本机文件的数字签名；不能把hash称为防恶意伪造的信任根。

验收包括真实浏览器帧/状态、每句覆盖、原句/动作错配、删帧重算hash、改raw为passed、模型无法判断/缺引用/低置信、报告过期与批准拒绝；正确对照和旧脱节表达分别测试，工程通过不得变成语义通过。工程fixture/模拟评估与真实供应商/课程签收分别报告，仍须按先生成设计图、确认、HTML复刻的正式流程验收。
