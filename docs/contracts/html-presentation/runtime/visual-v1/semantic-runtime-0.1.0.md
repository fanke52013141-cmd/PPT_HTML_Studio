# A03：语义动作运行与真实音频绑定 0.1.0

关联 HPS-007/009/010/011/013/014/028/030。定义先行，实施与实测记录见 A03 交接。

| 定义项 | 规则 |
|---|---|
| 输入 | 经权威讲稿与 A02 校验的 scene_plan 0.2.0；已注册槽位、组件、素材；现有真实音频时间轴 |
| 作者格式 | scene 0.6.0；页面 ID 沿用项目 slide_id 的 80 字符规则，可含下划线，公共对象 ID 仍为原规则。initialVisibleIds 是明确初态，motion 的 actionId 与计划一致，允许同一对象多次不重叠强调 |
| 绑定 | motion_binding 0.2.0；actions 按 actionId 索引，sourceBeats 保存精确原句及 SHA256。每个动作必须绑定，不能按全页时长比例猜测 |
| 时间 | 作者预览仅为临时等分时钟；音频绑定按 beat_id 的实际分段窗口，秒到毫秒只转一次。分段需连续保持语块次序、完整覆盖原句，禁止缺句、串页、重排 |
| 文本比较 | 原句哈希精确校验；字幕拆分的比较只忽略标点与空白，保留所有字母、数字及 Unicode 词字符。不会用模糊匹配或摘要代替原句 |
| 同句动作 | 不同对象并行，起点为本句开始；同一对象按声明顺序以 500ms 间隔执行。默认时长 500ms，人工修改时长仍按语块尾和同对象后续动作裁短；不足 1ms 或偏移越过本句拒绝 |
| 可见性 | initialVisibleIds 在 0ms 完整可见，没有合成入场动作；其他对象入场前透明，入场后保持。新版禁止 exit，不承诺图片内部状态变化 |
| 可编辑性 | 节点保持已有编辑接口。重复动作通过显式 actionId 定位；旧目标+类型仅在唯一时允许。保护、合并与差异采用稳定动作身份 |
| 验收 | 真实原计划不手改，绑定真实音频；共享浏览器求值器检查初态、动作边界、中间态、终态与随机跳转，展示逐句导航与音频播放 |
| 批准 | 未确认音频可用于清楚标记的试听预览；正式导出仍需原音频与视觉批准。结构/几何通过不授予角色或表达含义通过 |
| 兼容 | 旧 scene 0.1—0.5 / binding 0.1 保持；显式 plan_version 0.2 才走新编译，无数据库迁移。新 bundle/source 指纹使旧依赖需重新核验 |

图片锚点、可见性及关系几何仍由共享渲染器求值。预览、帧检查与导出同源。一次真实页面实测不等于 A04 独立语义 QA 或 A05 整课自动编排已实现。
