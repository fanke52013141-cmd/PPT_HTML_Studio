# 分行标签与叠放关系摘要 0.1.0

关联HPS-006/010/011/013–017/023–025/037。先定义两个新增注册变体；旧ID、场景内容、动作与主题保持，scene仍0.7.0，变体目录0.4.0。实现、工程、真实Agent及人工验收分别记录。

| ID | 公共语义与布局 | 容量/边界 |
| --- | --- | --- |
| text-card-stacked | text既有runs在第一个中英文冒号后分为标签/正文两行；保留全部字符及run强调，整text part样式不扩为任意CSS；可选原注册图标 | 最小360×136，左右22/上下18内边距；图标72、间距20；总行数仍用原槽位预算，实际文字宽高逐项校验；无有效冒号拒绝 |
| summary-arrow-overlay | summary既有from→to关系，中间箭头与term药丸叠放，takeaway居中在流程下方；可选heading另占上方一行 | 最小900×170；左右24/上下16；两端各占内部宽度25%，箭头及药丸占中间50%；heading/from/to/term各1行、takeaway最多2行；独立子区和父容器容量均阻断 |

所有文字、关系均由代码控制，色彩使用原主题token。新能力通过现有set_variant受保护操作选择，不增加业务分支、节点或数据库字段，不迁移旧页面。新ID需新版编译器，旧读取器应拒绝。理解/还原/审核的variantFacts必须同步，禁止把已实现能力继续报告为缺失。原required_features早停和同变体事实核验保留。

容量修复输入新增geometryConstraints：当前注册变体的最小尺寸、既有动作min/max位移、在建议尺寸下的安全偏移范围及建议尺寸/偏移。建议宽度保留当前宽度且不小于注册下限；高度扩展不得遗漏入场位移，建议只是输入事实，不自动应用、不越过人工保护。局部运行片段0.3.0，三轮/180秒和严格编译器不变。同案例首次真实测试因模型忽略动画安全区失败，保留原记录后才开展修正后的独立实验。

同设计测试由系统Agent选择变体和操作，不由Codex手写本例HTML。完整返回但失败照实保留，未知不重试，工程通过不等于视觉或人工批准。
