# S04 动态 QA 与无进展停止定义卡 0.1.0

2026-10-12；HPS-009/010/011/013/014/016/017/023—025/030。定义完成，实现与真实验收分别记账。

| 项目 | 定义 |
|---|---|
| 时间范围 | 保留sampled默认有限采样/250ms/最多240时点。新增output_frames：fps=1..60，检查指定范围内每个输出帧时刻、范围起止和动作起止前后/中点；最多7201时点、120秒。超预算拒绝，不静默稀疏采样 |
| 声明 | frame_complete仅表示已检查该fps下所有输出帧及额外边界，continuous_time_verified=false；任意帧之间仍未数学证明。作者时钟与确认音频时钟分别记录 |
| 几何 | 使用实际DOM变换后的矩形/可见性归一化到1600x900画布，包含缩放和动作偏移；文字容量仍由原共享渲染器实测。内容安全区沿用注册布局 |
| 遮挡范围 | explicit保留调用者指定对。registered派生所有非annotation对象对，排除仅来自版本化模板槽位关系与annotation已注册target/label关系；排除项含对象对、规则来源和理由。不能由用户/模型临时传入任意白名单 |
| QA身份 | hps.html.quality_report增量0.2.0，绑定render快照、检查器/core/policy/hash、原始报告和截图实际字节。静态终态与动态范围分开；问题含目标/时间/测量/允许修复分类，但不授予操作权限或批准 |
| 冻结检查 | snapshot动态检查只打开快照内播放器/字体/图片，禁止HTTP资源；先后核对快照及检查器字节。报告过期、截图损坏、覆盖范围不一致不得沿用 |
| 修复停止 | 保持候选最多3轮、保存后最多2轮。重复补丁、重复候选状态或实际同规则测量无改善提前停止为needs_revision，保留请求、失败和原因。测量改善但仍未通过可继续；资源/Schema/人工保护/版本错误不通过扩大权限来修复 |
| 接入 | 原repair evidence/preview/generate/save兼容新增sampling_mode、fps、overlap_policy。旧请求行为保持；候选/保存后共享纯修复进展判断。独立snapshot CLI支持动态检查，原批准/音频/正式输出门禁不改变 |
| S08 | Token五页课程覆盖定义/切分/计费/上下文/使用要点，至少两类内容与不同注册模板；实际模型请求、HTML、人工保护、音频、动态/媒体解码/PPTX打开分项验收。用户视觉与音频批准必须由用户完成；实验review_only产物不登记为正式交付 |

固定工程测试与真实供应商测试分开。合法容器覆盖保留检查记录；单页或有限样本通过不宣称通用美术通过、全时间无碰撞、音画或整课签收。
