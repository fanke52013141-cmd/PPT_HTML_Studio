# 文字边缘人工盲审与计量 0.1.0

关联HPS-010/011/013–017/023–025/037，契约0.9.78。继承文字边缘诊断与审阅页合同。本能力只服务独立离线评估，不改生产模型、诊断阈值、作者内容或批准门禁。

用户已明确不需要将人审作为开发主路径。本工具仅为可选校准，不是生产流程门禁，也不是推进自动修正闭环的前置条件。

## 标注定义

以原图hash、定位结果hash、targetId/partId/region_index、原框和转录构成逐行样本身份。人工标注页不含诊断状态、原因、蓝色墨迹框或预测文件；排序按稳定样本hash，不按警报类别。展示完整原图和比原框更大的上下文窗口，原框仅用来明确被评估对象。

审核者独立核对身份、转录及完整文字墨迹边界，填写原图像素`truth_bounds=[left,top,right,bottom]`，再选择`clipped`或`complete`。真值框与原框相容性严格校验，坐标/标签矛盾不能计分。无法辨认或文字身份不符分别记`unjudgeable`、`identity_mismatch`，不强行转成完整/截字，不混入二分类分母。标签初始为空，禁止默认完整、继承算法标签或把AI视觉检查称作人工真值。

人工导出需填写复核者代号并声明本人盲审，保留该声明而不声称身份被认证或已双人复核。本机文件是显式导出，页面不上传、不改原数据。真实人尚未标注时结果必须为`pending_human_review`，所有无分母比率为null。

## 时间与统计

逐行点击开始才计时，暂停、页面隐藏、失焦时停止；恢复必须再次开始，提交才封存有效毫秒数。时间是自声明人工实际浏览器复核时间，不是程序执行时间、浏览器自动化时间或含页面后台停留的墙钟时间。时间对比必须使用相同样本、相同协议和独立配对基线；单组只给总计/中位数，`time_improvement=null`。

预测`possible_clip`与`no_detected_clip`构成决定样本的TP/FP/FN/TN；`uncertain`独立作为弃权按真值类别计数。输出决定样本精确率/误报率/漏报率及明确分母；另给`alarm_recall`（TP/所有真实截字）和`review_routing_recall`（疑似或不确定/所有真实截字），避免弃权让召回虚高。漏检拆分静默漏检与弃权截字。未标注、人工无法判断、身份不符、预测弃权分别计数，不将任一种缺失当正确。

报告去重原图数、记录数、逐行数；同一原图的三次定位是重复测量，不是三张独立页面。当前样本只涵盖已提出文字区域，整行未定位和整段缺失仍是覆盖盲区。评估新真实页与完整人工区域覆盖需单独采集，不由本页重复推算泛化。

## 实施归属与验收

`html_text_edge_benchmark.py`拥有样本/盲审包生成和严格计分；`scripts/assets/text_edge_labeler.js`拥有离线人工计时、填写与导出；`scripts/benchmark_html_text_edges.py`拥有prepare/score入口。包及导出绑定hash，预测另存，源图片/响应前后hash一致才产出。工具不调用供应商，不导入server，不访问真实数据库。

验证假阳性/假阴性/弃权分母、零标签null、重复/未知身份和hash失配拒绝、标签/真值几何矛盾、非法时长、离线转义/预测隐藏、计时暂停与后台停止。合成测试标签必须标为测试数据，不能充作真实人工结果。浏览器真实渲染、人的盲审和新页泛化分别留证，不得用最小DOM测试替代。
