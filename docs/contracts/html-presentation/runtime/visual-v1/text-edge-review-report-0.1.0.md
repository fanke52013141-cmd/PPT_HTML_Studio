# 文字边缘证据审阅页 0.1.0

关联HPS-010/011/013–017/023–025/037，契约0.9.77。继承reference-text-edges-0.1.0的像素诊断，不改变模型Schema、运行Skill、诊断阈值和批准状态。

## 定义与归属

`html_text_edge_report.py`拥有只读、离线、自包含HTML审阅页。独立定位成功后在同一证据目录生成`text-edges.html`，结果记录报告hash、参考图hash和输入结果hash。CLI可对已保存定位结果生成新目录中的审阅页，不调用提供者，不修改历史文件。原图hash或已保存诊断不一致时拒绝生成；不借旧结果对新图签发证据。

逐区域保留targetId、partId、region_index、原文字转录和原框。显示完整参考图及带局部观察窗口的裁图；红框为原文字框，蓝框为跨边界连通墨迹包围盒。两种框均为证据，后者不是替换建议。画面与坐标使用原图像素，保留裁图原始分辨率，支持放大和状态筛选；不向外部URL加载资源。

`possible_clip`、`uncertain`、`no_detected_clip`分别标为“疑似截字”“无法确定”“未见跨界”；第三种状态明确不证明文字完整。列出原因、跨界方向、框外像素数及窗口，未定位目标单独列出，零区域不能呈现通过。动态文字一律HTML转义。报告无接受、批准、重生成、自动扩框或保存作者内容操作。

## 兼容与验收

定位结果增加`edge_report`派生元数据；旧结果没有该字段时仍可读取。正式审核和工作区批准不消费此报告。源码加入生产源闭包；源码变化使旧生产快照过期，原恢复/来源核验规则保持。运行产物不入Git。

验证覆盖图hash失配、诊断失配、原文件及对象不变、区域身份/转录/框和墨迹坐标对应、恶意文字转义、空区域/未定位、离线资源与默认全部可见。使用同一已保存真实案例离线生成，统计可展示区域和运行耗时；浏览器核对筛选及缩放。展示覆盖不等于识别准确率改善，也不声称人工耗时已降低。逐行独立真值、人工复核修正闭环和真实课程验收仍另测。
