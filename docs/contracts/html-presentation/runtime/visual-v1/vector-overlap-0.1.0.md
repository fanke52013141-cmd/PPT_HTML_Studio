# SVG线条重叠判定 0.1.0

2026-10-20；HPS-009/010/011/013/014/016/017/023—025。补充原动态QA规则，不授予编辑或批准权限。

## 定义卡

| 项目 | 规则 |
| --- | --- |
| 来源 | 原播放器每个时点的实际SVG path、getScreenCTM、计算样式、原scene显式from/to、同帧renderer端点及实际文字Range矩形 |
| 坐标 | 线段、线宽、文字矩形按实际舞台变换归一到1600×900设计坐标，内容安全区仍为0..800 |
| 支持集 | 当前箭头M/L/H/V/Z直线图元（含相对与隐式坐标）；做完整线段/矩形及线段/线段检测，不以稀疏空间抽点代替相交 |
| 线宽 | 按DOM线宽与变换最大尺度派生保守笔画半径，miter按miterlimit扩大，虚线间隙按实线处理；这些保守近似可能多报 |
| 文字 | 可见文字Range按实际分行矩形检测；任何端点对象内的穿字仍报TEMPORAL_OVERLAP，不因关系目标身份豁免 |
| 非端点对象 | 实际线段/笔画包络相交才报；外接矩形相交而线条未经过不报 |
| 端点接触 | 仅原scene显式from/to对象；主线须与同帧renderer端点方向及入场进度一致，引用端点须处于对象矩形内。连续进入该对象的非文字区域可记为合法接触 |
| 箭头头部 | 线段须连接与原from/to一致的当帧主线尖端（原renderer在进度>99%时出现头部）、长度不超过原renderer12×5头部的14px保守上限；若回跨源容器边界，目标点到该边界的距离不得大于该头部线段长度。实际穿字仍阻断，不为其他对象豁免 |
| 箭头之间 | 线段距离与两侧笔画半径之和比较；不自动豁免共享端点 |
| 留证 | 原overlapPairs/overlapExclusions不变；合法接触另存relationContacts（时间、对象对、方法、理由）。问题注明stroke_crosses_text/object/stroke及命中文字矩形；原始帧保存路径、变换、Range |
| 回退 | 未支持曲线、填充、marker、非缩放笔画等继续原保守矩形检查，不能借用端点豁免或静默跳过 |
| 安全区 | 路径边界计入保守线宽包络，不能只检查中心线 |

registered模板策略、人工保护、修复/采样预算、音频时钟均保持。合法接触不是美感批准，本版不宣称通用SVG或像素级碰撞证明。

## 归属与兼容

helper进入生成快照源码闭包及snapshot动态QA的执行前后hash、报告当前性检查。旧报告缺失/不同helper身份时不能当作当前QA。
作者scene/binding、API、数据库、原课程不迁移。合同包0.9.109，Agent API仍1.59.0。
