## 验收证据

| 验收目标 | 实际结果 |
| --- | --- |
| 同一代码消费不同输入 | 两实例构建/渲染通过；输入源不被编译修改，编译快照与 SHA-256 固定 |
| 对象与动作真实可控 | 透明度、曲线路径、二维旋转、过渡轨迹；三语块与关键帧；结束保留/消失符合源定义 |
| 失败诊断与旧画面保护 | 未知版本/字段/能力、悬空引用、同通道冲突、状态不连续、越界时间、容量、资源错误和预算失败被阻断；旧就绪画面保留 |
| 文字与资源替换 | 实际 JSON 编辑/应用按钮通过；不执行注入文字；资源字节/尺寸/alphaBounds 校验 |
| 目标几何 | 90° 旋转图片四角与解析几何一致；文字行测量按画布单位；窄屏缩放后几何稳定；无 Canvas 整框冒充目标 |
| 确定取帧 | 两例各四帧乱序重复像素相同，换例后重新载入首例也相同；暂停/倒放通过 |
| 无声视频 | 两例 10/8 秒、300/240 帧、1280×720、30fps H.264，ffprobe 与完整 ffmpeg 解码通过 |

检查与实际浏览器：[checks.json](../../html_engine/evidence/checks.json)。编译快照、资源审计、截图及视频各自保留证据。
Microsoft YaHei 400/700 的实际平台字体记录来自 CDP；字体 probe 仅用于本地阻断，不证明所有字形覆盖/跨环境一致性。

## 修正与限制

标题 72px 字体在原行高下字形边界超过盒高；实际测量拦截后将行高设 1.4、盒高设 110，保留字号与位置。
图片按完整资源画框 contain；alphaBounds 使用实际任意非零透明通道支撑边界，不把它当主体语义轮廓。已有边缘杂点与留边问题未掩盖，quality 仍为 conditional-experiment。
文字在 DOM，图像/曲线按图层拆成连续 Canvas 组，保持全体节点层序；图层像素预算防止不受控内存开销。
导出使用预览相同快照与 evaluate(t)，临时文件验证后发布新版本；旧输出保留。原图/字幕/生成资产不在取帧时重生。

尚未完成：自动布局/生产模板、Group/Concept、完整 P01 Schema/原动作、句内锚点、公共编辑器、跨页/镜头、现有音频和数字人适配、PPTX、应用保存/任务与 AI 生产。
新渲染页用户审美审阅待进行；motion-02 的认可不自动批准两个新实例或全部模板。
