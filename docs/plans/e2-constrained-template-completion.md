# E2：受约束配方、资产质量与课程复用验证

日期 2026-10-07。状态：限定工程链已实现并验证，视觉验收与资产库批准待用户审阅。依据 HPS-002/003/007/009/013/024—030；[定义卡](../contracts/html-presentation/runtime/e2/README.md)，[输入与操作](../../html_engine/recipes/README.md)。E1 和 P01 原格式未升级。

## 已交付

两个版本化配方：开放对象运动（flight/drift）和双概念解释（sequential）。内容只能填槽，模板派生节点位置、层级和动作；不自由生成 CSS。两个课程片段和一个运动实例进入同一 E1 渲染器、同一时间求值。以插图作为视觉焦点，标题/术语/关系/短解释由 DOM 实现，讲稿保持完整。

课程验证使用有来源的“蒸发与凝结”及其生活应用，是代表性真实知识内容，尚未使用用户提供的完整课程。没有扩张为跨学科主题复用的证明。科学依据：[USGS 蒸发](https://www.usgs.gov/water-science-school/science/evaporation-and-water-cycle)、[USGS 凝结](https://www.usgs.gov/water-science-school/science/condensation-and-water-cycle)。水蒸气通常不可见，小球仅是分子示意，屏幕副标题已提示；冷杯外水滴来自空气中水蒸气。生活例沿用机制插图，衣物实物素材仍可另补。

资产工具保存哈希、实际 alpha 范围、留边、中心锚点和裁切矩形，禁止覆盖已有资产。固定槽位提取有真实运行测试，未自动抠图/识别命名。双概念复用已保存的两张独立透明资产；云朵用 imagegen 修订单图，不强制全部主题使用资产板。

## 资产改进及尚未通过项

小云旧版 nonzero alpha 范围接触边界；v2 1254×1254 没有接触边界。alpha>=16 的主体左右留边约 15.7%/13.2%，比要求“至少 10%”足够，但未完全达到生成提示中四边 15%。极低 alpha 碎点仍扩大包围框，放大轮廓也有少量白色噪点。修订只改善了这一资源，纸飞机/大云仍沿用旧实验资产；不能宣称整套素材已净化。

v2 保留原生成文件、新资源文件和旧版对照，质量均 conditional-experiment。见 [量化记录](../../html_engine/evidence/e2/asset-quality.json) 与 [浅深底对照](../../html_engine/preview/e2-assets.html)。美术认可、科学准确性、文件就绪独立记录。下一轮选图/修边须新版本，不能通过放宽指标让旧缺陷成为 approved。
