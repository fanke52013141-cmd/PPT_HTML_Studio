## 改造目标

沿用原项目外壳和成熟服务，增加显式 HTML 后端。目标闭环：内容 → 讲稿与语义分镜 → 选择受约束布局/效果 → 引用真实效果图进行设计 → 按需生成独立资产 → 冻结共享视觉定义 → 静态审阅 → 对象动作与已有音频绑定 → 同一渲染器预览/导出 → 原数字人合成 → 视频和明确标注能力的 PPTX。

生图模型提供设计与少量复杂主体，不负责重新发明可执行组件。设计参考图不是几何真值；经确认的共享定义、资产锚点和字体才是执行依据。先把美感落到可复用组件，再扩大自动化。

## 必须保持的边界

| 层 | 负责什么 | 不应放入什么 |
|---|---|---|
| 公共能力 | 文本、图标、卡片、关系线、图表、坐标、时间、资源校验、字幕安全区 | 某一课程内容、固定粉色、特定科学插画 |
| 风格包 | 配色、字体层级、间距尺度、圆角/描边/阴影/渐变、图标语言、组件变体、配图策略、动效默认值、布局推荐与组合约束 | 自建业务渲染器、隐藏内容、硬编码三条知识点 |
| 布局/呈现模板 | 槽位、容量、主次、可选标题、图文关系、过程舞台、明确的约束与适用语义 | 任意内容强行塞入同一版式 |
| 内容实例 | 文案、事实来源、选定模板、资产引用、对象/讲稿/动作对应 | 任意 CSS、JavaScript、无注册效果 |
| 派生结果 | 实际文字测量、容器几何、contain 坐标映射、音频绑定时间 | 由模型猜测的像素坐标和时长作为最终事实 |

首发仅 CSS、SVG、Canvas 2D；不建设水彩手绘主风格、WebGL、复杂角色表演。默认每场景 0–1 个生图主体，声明过的双对象模板上限 2 个。复杂纹理作为有限资产，文字、关系、图表、常用图标、可运动对象优先代码实现。

固定逻辑画布 1600×900，内容区 y=0–800，底部 y=800–900 为字幕专用，空字幕时留空；字号 20–44，默认 32。英文栏目、品牌、系列名、来源页脚默认关闭，来源保留在元数据；科学解释正文不因此删除。

沿用已有本地/云端 TTS、音频确认和时间轴、数字人；不重新选型。应用操作界面遵循现有 UI 规范，科普主题只影响作品画面。
