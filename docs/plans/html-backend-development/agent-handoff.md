---

请实施 PPT_HTML_Studio 的 HTML 后端改造。先阅读项目 AGENTS.md 和 `docs/plans/html-backend-development/README.md`，按 tasks.md 的依赖顺序执行，逐项按 acceptance.md 留证，并使用 open-source-map.md 定位固定提交的参考源码。task-ledger.json 是计划清单，不是已完成功能证明。

唯一开发运行目录为 `D:\Program Files (x86)\PPT_HTML_Studio`，桌面快捷方式保持指向此处。不要创建另一套可运行副本，不要重置既有修改。若在其他机器，先执行 A00：远端发布分支可能只有规范和独立 HTML 引擎，必须取得完整原应用基线，不能凭空重建原项目。

目标是将已验证的“受约束设计参考＋少量独立生图资产＋CSS/SVG/Canvas 共享渲染”接入原项目。原 TTS、音频确认与时间轴、数字人沿用；新增显式 visual_backend，旧 image 逻辑保持兼容。科普主题只作用于作品，不改应用 UI 主题。公用能力、主题属性、布局模板、内容实例和派生几何必须分开。先把 style-review 中的真实美感纳入共享渲染器，再接入大规模生产，不能退回每页相同卡片布局或图片拼接。

逐项完成定义卡/版本、实现、测试、证据和受影响契约同步。新增字段同步 Agent 能力，新增失效规则同步影响表；修改生产提示词先读项目 optimize-prompts 技能。不要直接复制 AGPL 代码；按开源映射规定的方法独立实现，引用代码另记录许可。

按 M0→M1→M2→M3→M4 交付。E04 原生可编辑 PPTX 为后续可选，首发仅快照/分步 PPTX并准确标注。每里程碑报告已完成任务、测试命令/退出码、证据、剩余阻塞。视觉未审阅记 pending_review，失败记 failed，外部条件缺失记 blocked，不得自行替用户批准。可以继续不依赖待审视觉的独立工程任务。

完成后更新清单和启动说明，验证同一个桌面快捷方式重启后加载当前代码。只审查并发布本轮明确范围文件至当前仓库 origin，不向原项目 upstream 推送，不把密钥、用户数据和遗留修改混入提交。
