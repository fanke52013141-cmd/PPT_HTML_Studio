| 文件 | 职责 |
| --- | --- |
| `html_course_pipeline.py` | HTML 整课阶段编排、逐页状态、原请求/输入/模型摘要、成本范围、暂停和最终门禁 |

| `html_production_service.py` | 新语义计划、设计停点、实际资产与场景绑定及工程诊断；保存前不运行依赖真实音频的语义审阅 |
| `html_semantic_review.py` | 持久化语义审阅证据、真实时间轴与原模型调用回执 |
| `html_build_snapshot.py` / `html_input_manifest.py` | 固定源代码、Schema、生成校验器、实际资源和审批输入身份 |
| `static/one_click_extension.js` | HTML 专属阶段名称、设计/听审/作品待批准进度 |
| `agent_contract/` / `agent_api/routes.py` | 公共状态中的 `workflow_type` 与 `course` 及生成契约同步 |

不新增任务表或平行队列；页面生产和语义审阅沿用既有执行器、快照、幂等键、尝试围栏、供应商回执及恢复对账。服务重启后读取已保存项目状态并核实原子任务，再从原请求继续。内容、场景、模型、音频、证据或依赖变化不能沿用过期成功/批准。

未知供应商结果先核实原请求，禁止通过新快照或新任务重复发起。供应商未回报费用时金额与币种为空，仅注明 HTML 生成/审阅 LocalJob 的已返回阶段回执数量；不将其解释为完整调用数或总费用。

页面 ID 使用项目存储规则，允许下划线；对象和动作仍用严格注册 ID。生成独立资产绑定到实际场景和资源，不改写权威语义计划散列。未提供多个语义锚点坐标时明确阻断；单锚点主体中心仅为待视觉审查候选。
