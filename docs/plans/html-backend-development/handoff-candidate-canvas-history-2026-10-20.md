# 候选画布、中文属性和保存版本恢复 handoff

2026-10-20，契约0.9.103/API1.56.0，work_read0.2。接续2026-10-19的二次编辑计划；本记录覆盖其“候选画布/持久操作历史/保存版本恢复未实现”的历史状态。

## 本批实现

1. 外部静态交付导入→人工微调→独立工作画布。复用原共享播放器与Moveable/Selecto桥，W可选/拖/缩，B/A只读对照。主正式页保持原样，所有人工事务经原任务scope/Schema/工作版本校验。只允许scope对象进入画布交互层；多对象手势仍整体更新/拒绝。
2. 位置、尺寸、字号、左右标签等中文属性；对象显示内容摘要；高级JSON/诊断折叠。正式编辑器常用字段也映射中文，保留原data-field/API字段。
3. 服务端持久最近50步撤销/重做，刷新/重开后恢复历史。任何修改或撤销均增加工作版本并作废检查。旧工作记录兼容读取，尚无历史时从后续修改开始记录。
4. 所有实际editor保存（含工作区混合保存）在同一原子文件事务中记录保存前/后scene、binding、规划身份和完整性hash。no-op不新增。历史仅从启用后经过该服务的保存开始，不补造更早版本。列表展示最近100个，单个2MB上限；不复制媒体、不回滚项目revision。
5. 正式编辑器“读取保存版本→选择修订→预览恢复所选版本→保存修改”。恢复先进入草稿，可撤销；原文/规划身份变化即拦截，资源、结构、音频及几何由原preview/save检查。旧版兼容场景只提升原已支持的0.3/0.4→0.5和0.6→0.7标记；不迁移内容。保存产生新revision，保留现有人工保护，沿原最小重建/失效与审批流程。

## 所有权和兼容

- html_handoff_workbench.py：工作操作/持久历史及B/A/W原预览数据；工作记录仍在忽略的run内。
- static/html_editor_canvas.js：正式/工作画布生命周期、原播放器诊断、Moveable/Selecto桥。static/html_handoff_workbench.js只做参数/状态/事务，不画第二套正文。
- html_scene_editing.py：保存检查点与完整性/规划身份读取；html_visual_routes.py仅Web只读版本接口，恢复写入仍使用原editor保存。外部Agent没有人工恢复或工作写入口。
- editor_ui/build.mjs将工作UI纳入canvas来源闭包，重建清单；无依赖替换、无DB迁移、不调用模型/生图/TTS。
- 新API/源码使旧签名任务保持历史；应从当前页重导新任务，不改旧task_id或升级旧批准。
