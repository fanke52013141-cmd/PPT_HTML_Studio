# 设计 Agent：理解、素材分工与还原审核交接

日期：2026-10-13。承接 A01–A03 与整页设计先行。契约包 0.9.36、Agent API 1.25.0、produce 能力 1.4.0、Codex 操作 Skill 1.11.0。此文是当前交接入口；组件定义与实现仍须区分，真实模型候选没有通过视觉审核。

## 用户确认的生产顺序

**标准组件库 + 生图模型生成的整页设计图 → Agent 理解对象与素材分工 → 用代码组件和独立图片还原 → 实际截图对照审核 → 必要时有限修复 → 人工审阅与批准 → 复用原快照流程导出。** 组件库和生成图共同约束最终页面；生图图像是设计参考，不成为 HTML 正文背景。准确文字、对象身份、讲稿关系和动作仍以权威数据为准。

## 已交付的实现

- A01 增加显式版本的语义计划与原句来源校验；A02 把语义角色、目标和注册布局容量送入设计上下文；A03 让稳定动作 ID 绑定真实讲稿语块和已有真实音频。每阶段的合同、真实调用与限制分别在 `handoff-a01`、`handoff-a02`、`handoff-a03` 及 `evidence/` 记录。
- 整页设计先行增量要求新页面先有完整参考图并经用户确认，再进入受控还原；参考图以后的操作仍经共享组件编译、受保护编辑和真实浏览器检查。静态组件变体为注册能力，没有开放自由 HTML/CSS。
- `html_design_agent.py` 严格检查每个对象唯一分配，验证代码/图片身份、注册组件和图标适用性、复用/生成素材选择；不允许把代码组件转为位图。
- `html_design_reconstruction.py` 执行设计理解、受控还原、独立截图对照审核及问题路由。合法的模型变体选择先经原编辑 API 实际应用，写入 `allocation-applied.json`，然后才调整布局。理解只收当前页、真实设计图和适用的注册能力，不重复传整篇文章或讲稿。
- 三个受控运行 Skill（理解与分工、还原、独立审核）和既有容量修复 Skill 均由 `config/html_runtime_skills.json` 注册。加载器校验固定阶段、合同、正文和 hash；操作 Skill 说明 Codex 如何调用，运行时片段才是生产模型策略。快照和候选指纹涵盖这些策略及新模块。
- 新对象素材仍经原有素材服务与预算，已有素材可复用；图像审核问题才能进入素材返工。当前不开放一张素材板拆出多个主体，也不开放图内逐元素动画。

## 真实供应商实测

round-2 使用一张实际设计图、同一页权威计划、既有音频和正常思考配置，在隔离验证进程调用 Pro 三次。每次等待上限 600 秒，没有关闭或降低思考：

| 决策 | 实际耗时 | 总 tokens | 推理 tokens | 结果 |
|---|---:|---:|---:|---|
| 设计理解 | 83.404 秒 | 5,578 | 1,946 | 覆盖 6 个对象，给出注册组件选择 |
| 受控还原 | 590.014 秒 | 20,949 | 15,189 | 在 600 秒内返回；实际执行所选组件变体；工程检查通过 |
| 独立视觉审核 | 300.895 秒 | 14,673 | 7,722 | `changes_requested`，发现 7 项差异，阻止保存 |

合计 41,200 tokens、24,857 推理 tokens、模型等待约 974 秒；费用未返回，记为 unknown。第一轮的审核请求没有可确认回复，保持 unknown 且没有重发。审计证据保存在 `evidence/design-agent-smoke-2026-10-13.json`；完整隔离运行与可试听比较页只在本地 `outputs/design-agent-validation-2026-10-13-round-2/`，不属于线上运行产物。

审核指出三张统计卡缺少圆形图标底托、局部字重/换行/留白不匹配、说明文字应左对齐、总结面板需要灰底和分隔、缺长连接箭头、勾选图标造型不一致。模型把一个代码 SVG 的修正建议标成 asset；程序保留原始分类和证据，并依据对象所有权路由到 `capabilities`，没有误调用位图生成。

作者完整性检查确认原句、对象 ID 和动作未被手工改写，实际模型组件选择被程序执行，旧音频被复用；审核终态仍为未通过，`author_saved=false`。实际页面播放覆盖了音频时间轴上的 522 个 30fps 采样帧、0 个几何/遮挡问题、0 个浏览器错误；试听页的 6 帧检查也通过。这些是工程与播放检查，不能抵消上述视觉问题，也不代表逐句语义正确或用户已批准。
