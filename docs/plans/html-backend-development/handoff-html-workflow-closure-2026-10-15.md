## 用户流程与职责

```mermaid
flowchart LR
  A[导入文章] --> B[分镜规划]
  B --> C[生成整页设计图]
  C --> D{人工确认设计}
  D -->|需调整| C
  D -->|确认具体候选| E[独立素材与 HTML 还原]
  E --> F[编辑动画与确认画面]
  F --> G[准备旁白与生成配音]
  G --> H[同步试听与逐句核验]
  H --> I{人工签收}
  I -->|需修改| F
  I -->|签收| J[可选数字人]
  J --> K[按当前输入正式输出]
```

整页设计图解决构图与风格；独立配图是图片素材；文字、图形、箭头和注册关系对象由代码还原。分镜负责每句的表达和动作，配音负责实际时间，人工分别确认设计、画面、音频和核验。无独立 HTML 勾画/数据素材步骤；当前自动主体预算、注册动作与标题模板边界保留，不承诺自由手写、通用图表或任意无标题模板。
