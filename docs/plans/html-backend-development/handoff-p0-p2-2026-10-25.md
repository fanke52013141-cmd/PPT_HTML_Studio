## 使用路径

1. 原图定位未决导致生产失败时，原任务进度保留workbench身份。主面板显示“打开定位复核”，核对原图/当前渲染，下载correction.json后导入并提交修正。
2. 修正走原持久LocalJob、项目冻结文本模型、取消及精确回执。不再次生图/规划。复核pass后可点击“复用原设计继续还原”；只从原快照取设计身份，已知成功任务的复核证据才可续接。恢复已注册静态变化后重跑原静态/完整30fps检查，经原作者保存入口落盘，视觉批准仍待人工。
3. 已保存页的局部修复选择layout_first：只修所选对象容量/遮挡/关联布局。共享未保存求解器，保持文本/关系/动作/人工保护；另有revision、audio、scope和candidate_key守卫。预览通过后仍需显式保存。
4. 新设计可展开“复用当前项目已有素材”，读取已核验清单，明确素材与图片槽位再生成。绑定id/version/sha256，设计确认前后保留同一资源；不生成独立配图、不改来源页、不继承来源页视觉批准。损坏字节、alpha元数据、anchor、跨项目身份、未知槽位均拒绝。
5. 两个新模板为image-text-columns-v1和chart-notes-v1。仅注册兼容主题可用，明确容量与槽位；仍使用原组件和渲染器。无自由CSS、自动分页或整页栅格替代。
