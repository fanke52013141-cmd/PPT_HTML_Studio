# Pi Agent API M0–M3 交付与验证

2026-10-20，契约0.9.105，Agent API1.58.0，输入输出agent-job/1.0，Pi SDK/pi-ai1.3.0。

## 交付范围

M0：正式契约卡、关闭额外字段的请求模型、固定作业响应、四项Agent/MCP/CLI登记及能力矩阵。原外部任务/结果0.2.0和执行2.1.1沿用。

M1：完整Pi Coding Agent SDK独立进程，显式资源加载/内存凭据、项目模型冻结、队列和local_jobs持久化、幂等、取消、中断、预算。模型/工具/候选/墙钟分别限制；单进程并发1，排队计入总时限。启动仅恢复本类型遗留任务为interrupted，不重发未知模型请求。无需数据库迁移。

M2：四个白名单工具连接原材料/PNG/同源便携预检/原生产DOM和动画检查/严格交付导入。模型必须实际取图，并在后续模型请求中提交观察；同一批取图后立即提交不能伪造审阅。最终提交须与最后检查结果一致，通过后才有可采用交付。失败、取消和版本冲突无成功结果，不保存作者或批准。

M3：正式编辑器内“AI自动修改/外部Agent交接”→目标/条件→“开始AI修改”。后台无人交互，页面显示进度、可取消和恢复，成功自动进入原候选展示；保存和人工接管沿原入口。断网提交结果不明时保留幂等键，恢复原任务，避免重复计费。

本批是可试用的功能交付；尚未证明复杂任务成功率达到发布目标。未把全部原生成/修复入口切换到Pi，旧编排保持兼容。新页生成、自动正式保存、文章/分镜/配音等仍按M4–M5实施。

## 所有者和接入

- `html_agent_models.py`：输入/响应；`html_agent_store.py`：既有local_jobs新类型html_pi_agent。
- `html_agent_jobs.py`：私有模型传递、工作线程、源码/基线指纹、时限与预算；`html_agent_execution.py`：封存工具桥和严格交付。
- `agent_runner/runner.mjs`：Pi SDK，禁用默认shell/写文件、用户资源发现、自动供应商重试、自动压缩和缓存预热；不另写Agent循环。
- Web/Agent路由薄适配；`static/html_pi_agent.js`只负责任务UI，原handoff owner展示/保存，不新增播放器。

安装：Node>=22.19.0，在agent_runner执行npm ci --ignore-scripts；随后正常启动本checkout原服务。已在本机Node24.11.0安装依赖，无需Pi全局账号。项目文字连接必须明确supports_images=true，首版为OpenAI兼容聊天协议；不把密钥交给浏览器或写进作业。

POST `/api/projects/{project_id}/html-visual/{slide_id}/agent/jobs`创建；GET同路径`/{job_id}`、`/{job_id}/result`；POST `/{job_id}/cancel`，请求体为`{}`。Agent认证前缀`/api/agent/v1/projects/...`，四能力html_agent.create/read/result/cancel。

默认2轮候选、12次模型调用、24次工具、600秒。每次输出上限min(项目max_tokens,8192)，Pi thinking_level=off；项目原生reasoning_effort不直接传入，实际profile记录在私有作业元数据。源码在启动/交付间变化、或排队期间作者/配音/保护变化，返回stale_input。费用未知null，不用SDK零费率当真实费用。

## 真实模型试验

模型：当前视觉连接glm-5.3-flash，支持实际图片。输入来自真实Token第3页历史生产候选的既有隔离基线，非手写测试页面；只在新的副本和任务数据库执行，原基线哈希复核不变。原页没有真实声音，本次不宣称声音/音画验收。

1. 底栏复杂任务：from/to字号17→至少22，保留takeaway22及图文/动作，并检查底栏与三卡。首个候选包含3个操作，原便携及生产预览通过；随后模型调用阶段失败，没有完成after审阅/严格交付。整单failed/provider_error，8次模型、15次工具、1轮候选、581.938秒，供应商报告458252 tokens，费用null。不自动重发，也不将通过的中间候选改记为成功。发生在增加8192输出上限之前，无法仅凭错误归因框架、输入或供应商。
2. 独立最小布局任务：只把obj-headline.offsetX设为8，其他全部保持。完整无人闭环succeeded，最终恰好1个set_presentation操作，原预检/DOM/有限采样通过，实际原图和after图均被模型查看。6次模型、15次工具、1轮候选、94.769秒，供应商报告294461 tokens，费用null。原基线不变，没有作者保存或人工批准。

两项任务目标和输出预算不同，不作速度/框架效果对照，也不据此计算通用成功率。简单任务上下文用量依然较高；应优先减少重复/无关材料，而非宣称更换框架已经解决成本和复杂修复稳定性。

本地忽略证据：outputs/pi-agent-live-token-m03-20261020/{summary,result}.json（失败及中间检查）；outputs/pi-agent-live-title-m03-20261020/{summary,result}.json（成功及完整ZIP/预览）；后者作业events.jsonl含工具名和时刻，不含密钥/思维链。outputs/pi-agent-validation/{before,after}.png为真实简单任务图，pi-agent-ui.png为隔离实际浏览器UI。
