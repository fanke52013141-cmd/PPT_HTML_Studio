# 讲稿待核对 → 修正 → 继续流程 · 2026-10-16

## 已实现

1. 自动生成或手动编辑触发限定范围风险时，独立保存当前核对候选及原问题归档，绑定原文和正式讲稿摘要。已有正式讲稿、合同、音频保持；重新打开能读取候选，重复生成在模型调用前停止。
2. 原讲稿编辑器显示原文和候选句，核对期间不自动保存，明确点击“保存修正讲稿”。当前review_id、原文和正式讲稿均匹配且风险检查通过后才写正式稿；旧ID、已消费ID和过期候选拒绝。内容可视化/下一步保持门禁，修正不自动发起付费请求。
3. HTML课程进入waiting_for_user/storyboard，checkpoint=script_review，持久化content_review而非unknown或普通失败。重建协调器后仍等待原候选。修正后继续同一父任务，跳过讲稿生成，执行必要的visual/compose；已有当前映射复用，原未知/取消门禁保持。
4. 一键课程首次进入核对停点时读取一次候选，后续轮询不覆盖编辑器；过期候选只显示对照，跨项目迟到保存响应不应用。

所有权保持在storyboard_plan_store、storyboard_service、html_course_runtime/jobs及原前端模块。无新数据库迁移、HTML作者格式或新模型；未手改真实遴选项目或重发其原未知请求。
