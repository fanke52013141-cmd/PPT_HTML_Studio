# 统一审核事实与参考区域定位验证

## 实现与边界

契约0.9.72，运行审核片段1.0.0。html_review_facts.py以逐对象/维度facts为唯一模型输出，模型不再同时维护issues、coverage、总status或关联下标。每个事实只写一次参考/当前观察与差异，程序生成原消费者仍使用的问题、覆盖与状态。普通text的参考对齐只在typography事实中报告一次，程序与准确注册布局/编辑覆盖合同作显式比较，生成有来源的对齐问题；不替程序识别原图，也不编造缺失的视觉事实。

缺/重/额外项、维度错绑、不确定参考、空白证据和混入旧顶层格式都失败关闭；历史validate_fidelity读取保留，不把旧格式升级成新生产的facts。原纯装饰观察、跨轮保留、作者保护、请求预算和人工批准保持。原始facts及派生来源留档，不改原场景、HTML或讲稿。

html_reference_localization.py是独立原图定位阶段，只接受原图和对象内容身份，不给HTML坐标、布局、槽位、动作或候选截图。每次输出对象区域/状态、身份依据、可见文字、原图与scene/身份hash、裁剪和红框图；质量仍标model_proposed_unverified，不自动用于生产审核。没有图不代表找不到对象，框存在不代表身份/完整性正确。
