# 文字边缘评估工具与开发方向调整：2026-10-17

## 用户决定与当前方向

用户明确认为不需要逐行人工审核。人工盲审包改为可选的离线算法校准工具，不作为生产环节、流程门禁或下一轮开发前置条件。开发重点回到系统Agent自动发现、定位、局部修正、复验和有界停止，不要求用户逐页打磨。

人工独立标注的用途是度量真实页的误报/漏报；没有该标注时不伪造真实准确率。可优先采用独立绘制的受控墨迹真值做自动回归，再以真实案例检查流程状态、调用数、修正轮数、耗时和未解决问题。独立AI复核若后续引入，应记为AI判断一致性，不冒充人工真值。

## 本轮已实现的可选工具

- `html_text_edge_benchmark.py`：生成密封逐行样本、隐藏诊断的标注页和分离预测文件，严格核对身份/hash/真值框/标签/时长后计分。
- `scripts/assets/text_edge_labeler.js`：离线拖框、人工声明、明确开始的前台计时及JSON导出；隐藏或失焦暂停，需手动继续。该计时包括盲审、填框与保存，不能冒称普通生产审阅成本。
- `scripts/benchmark_html_text_edges.py`：prepare/score入口，不调用提供者，不访问项目数据库，不改变作者内容或批准状态。
- 契约卡：`runtime/visual-v1/text-edge-human-benchmark-0.1.0.md`，仅约束该可选评估实验。

## 实际验证与限制

4个隔离测试文件86项通过（3.60秒），覆盖盲审包原图去重与转义、原文件不变、预测隐藏、严格hash绑定、计分分母及弃权、非法标签/边界/时长拒绝，以及Node最小DOM下计时排除后台停留、原坐标换算、人工声明/导出规则。JS语法检查和Python编译通过。

准备了同一真实页三份历史定位记录：39个区域、1张独立原图、0次新模型调用、0处原记录修改。盲审包`outputs/text-edge-human-benchmark-20261017`生成0.887秒、HTML 852,427字节。没有人工实际标注，0/39；误报、漏报、人工耗时均为null，状态`pending_human_review`。该包可保留，不要求用户填写。

浏览器工具仍返回`Local browser use is disabled in Work settings`。通过应用展示工具排队打开了标注页；后续环境提供了该文件的当前URL，只能证明页面入口存在，不能证明渲染或交互正确。真实浏览器截图、筛选/缩放/拖框仍未验证，不能用Node最小DOM测试替代。没有可调用的设置修改接口，也未擅自绕过禁用设置。

## 下一轮验收建议

以同一冻结输入自动验证：诊断命中→识别可修正/需停止的原因→原系统Agent生成受控修正候选→原验证器复验→无进展/预算到达停止。先用受控文字真值验证无条件扩框、吸入背景/邻近图标等反例，再考虑真实模型实验；不得直接把诊断墨迹框当正确文字框。对真实页报告流程通过率、调用/修正次数、时延和unknown，不在缺乏独立真值时宣称真实误报/漏报改善。人工校准始终可选。
