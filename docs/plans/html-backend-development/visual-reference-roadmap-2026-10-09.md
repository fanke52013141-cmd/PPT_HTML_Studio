# 视觉参考库收束与后续开发计划

2026-10-09。**本文件为后续执行顺序的唯一入口**，替代此前围绕七页模板、soft-depth 三模板六页和两套独立风格的推进建议。规范仍以 HTML 演示契约为准，旧作品及已批准实验不追溯修改。

## 一、确定采用的方案

中性标准组件 → 选择独立配色角色 → 附统一风格描述/参考 → 加准确内容 → 生成完整设计参考 → 视觉审阅 → 可编辑代码还原与少量独立素材 → 复用已有音频、字幕和动画输出。

标准组件定义比例、层级、几何和关系；配色独立管理主色、辅助、强调、分类、正文与浅色面；统一风格约束整个画面的字体、线条、光照、质感。HTML 是截图工具，不替代交给 AI 的 PNG。代码和图片是实现分工，不是各做一套相互独立的风格。当前只做静态。

## 三、分阶段执行

### P0：收束与仓库发布（本轮）

交付：本计划、当前参考库 README、契约定义卡、源代码与实际 PNG、工程证据、正确 origin 的提交。移出被否定的七页模板、soft-depth 自建模板、旧动态实现与过时指南；保留已认可实例、用户 outputs 和有效静态实现。旧实验只作历史，不再作为当前输入规范。

验收：入口无相互矛盾的现行方案；可从源构建/导出；参考库验证通过；提交不含密钥、运行目录、数据库或依赖缓存。删除受本机审批限制时移至被忽略的 .tmp，本地可恢复但不发布。

### P1：把静态参考做到可用、好看（下一轮先做）

1. 审阅文字层级、卡片、关系线、数据/时间四类关键截图，核对字号、留白、边界、阴影、灰阶层次；按具体问题修改公共源文件。
2. 用同一组组件分别呈现三套配色，检查深色正文可读、颜色角色分明，不把全页染为一种颜色。
3. 盘点真实课程所需缺口。公式/化学式、复杂坐标/误差、嵌套网络、完整图标系列按需求逐项定义，不为了数量先堆组件。
4. 补字体名称、版本、许可和获取方法，验证另一环境无替代字体导致的换行；素材来源/hash 可追溯。

交付：定版参考截图、字体/素材清单、明确的美感问题与处理记录。验收：截图清楚可读，组件结构一致，实际用户视觉结论单独登记；未批准的新截图不标 approved。依赖 P0。

### P2：实现最小参考输入装配器

输入：componentIds、paletteId、unifiedStyleId、准确文案/关系、画布和安全区。输出：仅相关分类 PNG、一张配色 PNG、一张统一风格参考、精简提示词及 manifest。记录文件 hash、版本和选择理由。

统一优先级：准确内容与关系 > 标准组件结构 > 配色角色 > 质感描述；参考板 ID/说明/样例文案不进入生成。未知 ID、冲突、缺少资源时明确失败；避免塞入全库长图。

先核验实际提供者对多参考图及 2K/low 参数的支持，再接现有提供者适配。复用请求状态、脱敏日志和失败恢复；轮询不能重新付费提交。无凭据时只做离线装配，不能伪造模型结果。

交付：装配命令、输入契约、最小验证用例与可检查请求包。验收：同一输入得到相同引用/清单；真实请求确实带入所选参考；不记录密钥。依赖 P1。

### P3：小批对照实验，证实能改善质量和效率

先做一页试点，确认参考输入被模型遵循，再扩至 3 类内容（概念解释、过程关系、数据对比）×2 套配色，共 6 组。每组先一张；失败只针对具体原因重试并计数。

对比旧输入和新输入时保持模型、内容、画布、2K/low 一致。记录文字准确性、关系准确性、角色配色、排版/材质一致性、背景边界、修改次数、请求数、生成耗时、实际编辑耗时、提供者报告费用。质量分别人工审阅，不用几何通过代替美感。

交付：原输入/设计图/评审记录/成本耗时表。验收：无漏字、错关系、错数值，视觉可接受；可说明新方案改善哪一项。未做成对基线之前不宣称节省百分比。依赖 P2。

### P4：少量素材提取与可编辑还原

对通过的设计先复用已有素材，再为确实需要的主体做素材板/拆分。默认每页 0–1 主体，已声明对比最多 2 个；文字、箭头、常用几何、精确数据用代码。保留对象 ID、原图/候选、透明边缘、尺寸、锚点和来源。

拆分后检查身份、细节和边缘；不把模型重新绘制等同于无损提取。多模态识别提供候选与建议，确定性裁切/alpha 检查负责像素结果。失败可重试单对象，不重做全页。

将批准设计映射到可编辑文字/关系/组件。先覆盖一页，再沉淀有明确容量的复用布局；不提前制作另一套风格专属组件。对照设计/还原图，验证改文案、换配色、保存重开及安全区。

交付：批准素材、组件映射、实际还原与差异记录。验收：语义对象可编辑，少量图片独立，内容准确；新通用能力按契约补定义与适配。依赖 P3。

### P5：接入已有生产流程并跑真实小课程

复用现有 TTS、音频确认、字幕、时间轴及数字人服务；将稳定对象绑定到既有语义/时间，不另建同类服务。动态后续优先评估开源实现，选型必须做许可证、固定版本、逐帧确定性、导出兼容验证；本轮不自建动效库。

先跑 3–5 页真实内容：规划 → 参考输入 → 设计审阅 → 资产与代码 → 静态确认 → 音频动作 → 视频/快照 PPTX。检查失败恢复、项目隔离、旧 image 后端回归；实际视频全解码，PPTX 实际打开验证。快照 PPTX 不宣称原生可编辑。

交付：应用接入、真实课程产物、各环节证据和效率报告。验收：工程、模型服务、视觉、课程签收分别通过；部分通过不能称整体完成。依赖 P4。

## 四、当前不做

不再扩展被否定的页面模板库；不做手绘/水彩主风格；不为每个简单元素调用生图；不改已认可作品的布局/音频；不以旧两页实例推断自动还原已经完成；不以增加组件数量替代美感。
