# P01：最小基础定义交付与审查记录

日期：2026-10-07；契约包 0.4.0；定义 0.1.0；拟定场景字段格式 0.1.0。
阶段结论：P01 定义材料完成；实现 not_implemented；验证 partial，仅文档与样例一致性。

## 交付物

入口：[最小定义卡包](../contracts/html-presentation/definitions/README.md)。

- 19 张具体定义卡，分 10 个领域文件；填写用途、字段/默认/范围/所有权/覆盖与影响、
  输出、依赖、目标、布局/外观/时间、编辑、错误、兼容和验收。不适用项说明职责归属。
- 1 份完整单页作者输入：5 个内容单位、1 个对比关系、3 个节点、3 个语块、5 个动作。
- 1 份结构夹具风格、2 个自绘灰度 SVG、1 个 pending 字体需求；不代表首个产品风格。
- 1 份四原子组合片段、1 份预期动作时间表、16 个无效输入夹具、28 项边界验收说明。
- 定义索引关联既有 HPS 规则，规范入口、版本、变更记录与实施计划已同步。

## 已落定的设计决策

| 决策 | 落定方式 | 为什么需要 |
| --- | --- | --- |
| 作者输入与渲染分开 | 场景 JSON 保存内容/意图；几何、时间、HTML 为派生结果 | 支持编辑、版本、复用与不同输出 |
| 公共与风格分开 | 公共语义/目标，风格 tokens/变体/组合，实例内容 | 换风格不复制业务组件 |
| 稳定公开目标 | nodeId+part，文本范围另用带修订锚点 | 换布局不会因 DOM 次序变化失绑 |
| 文字范围单位 | Unicode code point，[start,end)，DOM 显式转 UTF-16 | 兼容已有标注接口，处理中文/emoji |
| 固定时间求值 | 毫秒、有理帧率、显式保持/恢复、同通道冲突 | seek 与取帧一致，避免播放历史依赖 |
| 独立素材 | 资源版本固定；内部锚点不等于独立图层 | 保留美感与控制粒度，不依赖事后切图 |
| 覆盖有界 | 来源顺序固定、白名单与硬约束双检 | 模型/局部编辑不能随意破坏布局规范 |
| 就绪分层 | layout/preview/export 及诊断、检查状态分别记录 | 草稿不被当作可正式导出的作品 |
| 输出诚实分级 | 图片、分步快照、基础原生对象分别验收 | 避免将图片 PPTX 误称可编辑 |

P01 正式采用的是这些字段与行为约定；JSON 样例仍为设计草案实例，正式 Schema/加载器待 P03。

## 检查结果与证据

可机器核对的文档/夹具检查记录在 [p01-definition-checks.json](p01-definition-checks.json)。
该记录来自本轮一次性文档检查，不是产品运行校验器，也不是已实现的测试套件。

| 范围 | 结论 | 限制 |
| --- | --- | --- |
| 文档链接、卡索引、状态、规则/版本 | 文档一致性检查完成，详见 JSON 记录 | 不验证运行支持 |
| 场景/风格/片段/夹具 JSON | 解析与关键字段、引用一致性检查完成 | 正式 JSON Schema 尚未建立 |
| 内容/目标/锚点 | 引用覆盖、公开 part、文字修订/码点切片一致 | 语义准确性仍需实际课程审阅；无 DOM 测量 |
| 素材 | 两 SVG 文件、尺寸声明、SHA256、无外链脚本检查完成 | 非浏览器解码，不是视觉审阅 |
| 语块/动作时间 | 人工区间、触发、保持边界及预期表算术一致 | 没有真实音频、播放内核或取帧 |
| 16 个错误夹具 | 变更路径可应用、JSON 与期望码登记一致 | 没有执行生产校验器，错误诊断是否正确待实现 |
| 字体、排版、美感、seek、MP4/PPTX | 未验证，保持 pending/not_implemented | 应在 P02/P03/P04/P06 验证 |

检查范围内未留未处理的矛盾；不能据此宣称未来所有场景均能正确渲染。
现有应用源码/数据库/API/Prompt 未改，未将既有应用运行回归作为本次定义验收证据。
