## 本轮交付

1. **参考输入到实际 HTML**：D 分类参考图按对象类型进入生产请求；默认 `neutral-baseline` 黑灰白。需要新图片的页面先在完整设计候选停点审阅，确认真实 candidate key 后继续生成独立素材与注册组件 HTML。支持设计修改、单主体返工、已有素材的身份与版本校验复用。无图片的纯代码路径沿用原有生产服务。
2. **可编辑场景与二次修复**：scene 0.5 的受限位置、尺寸和公开文字样式通过共享编译与渲染器，Web、Agent、MCP、CLI 使用同源接口。已保存作品可读取、预览、模型生成修复候选、按 revision 保存和重开；人工字段、对象身份、文字语义和动作绑定继续受保护。时间证据为有限采样。
3. **未保存初稿修复**：规划产物容量失败时，LangGraph 候选排版 Agent 在最多三轮内根据实际渲染诊断做受限 patch；严格重验通过才保存。资源或 Schema 错误不进入排版循环。当前模型决策 Prompt 在 `html_candidate_agent.py`，没有运行时 `SKILL.md` 加载器。
4. **生产 Skill 1.1.0**：`.agents/skills/produce-editable-html/` 记录任务路由、初稿与保存后修复、证据与审美验收、失败教训、六项 Skill 职责建议及 8 个触发/14 个行为回归案例。它是 Codex 操作规范；本轮没有声称它已改变豆包运行时决策。

现行规则入口为 `docs/contracts/html-presentation/README.md`（契约包 0.9.20）；生产、编辑和候选 Agent 定义分别为 `runtime/visual-v1/application-production-0.3.0.md`、`scene-repair-0.1.0.md`、`candidate-layout-agent-0.1.0.md`。静态参考库、运行注册组件及实验目录维持各自边界。
