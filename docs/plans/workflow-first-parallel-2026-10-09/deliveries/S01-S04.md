# S01 / S04 首版：固定输入与版本绑定静态 QA

2026-10-12。在 S00 已发布基线 `a18d99c` 上实施；契约包 0.9.22，定义见 input-snapshot-0.1.0.md。

## 交付内容

1. generation 快照保存准确规划输入、严格生产选项、最小模型身份、实际规划/生产/参考装配源代码、注册定义和分类参考图片；明确提供的素材检查身份、版本和文件哈希。不调用模型，不虚构尚未生成的图片。
2. render 快照保存已保存 scene、revision、当前选中定义、实际图片、共享播放器和字体字节，以及已有编辑/binding/批准/来源记录。默认 html_preview 使用作者时钟；video 输入冻结须先经过原视觉、音频确认和绑定门禁，再调用原 binder。正式输出接线在 S05。
3. 每次冻结在项目锁内拷贝实际文件，前后重新读取内容哈希与 revision；固定文件通过校验后发布内容身份目录。没有硬链接，不依赖 mtime 缓存。重复身份仅在已存文件仍有效时复用。
4. 静态检查读取快照内播放器、图片和字体，产出实际 HTML、终态截图与原始测量；QA 报告绑定快照、检查器/浏览器版本和证据散列。换快照、改报告或改截图均不能沿用原检查。
5. 程序检查与审美、音频和导出分别记状态。QA 对应关系 valid 不等于检查 passed，更不授予用户批准；检查失败或进程异常仍保留有版本依据的失败报告。

新文件：html_build_snapshot.py、html_snapshot_review.py、html_quality_report.py、html_engine/tools/review-snapshot.cjs、scripts/html_snapshot_check.py。没有更换共享渲染器，没有写用户真实项目，也没有新增 Web/Agent 公共接口或数据库迁移。Skill 1.2.0 补入固定输入检查方法与两个行为案例，仍未被运行时 Agent 自动加载。
