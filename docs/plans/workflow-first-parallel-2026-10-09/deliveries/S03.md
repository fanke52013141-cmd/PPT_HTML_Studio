# S03 最小重建计划交付

2026-10-12；契约0.9.25、Agent1.19.0、Skill1.3.0。执行范围与格式见 minimal-rebuild-0.1.0 定义卡。

## 已实现

- html_rebuild_plan.py 无副作用比较 before/after，输出稳定 plan_id、输入散列、逐页重做/复用/原因、项目组合任务及 no_op。共享运行变化按实际共享依赖重验全部页；局部修改与未引用素材不扩大范围。
- html_rebuild_inputs.py 只读采集实际契约/作者/绑定、旁白和 TTS 输入、音频、引用图片、注册定义、运行目录与本机字体字节，锁内检查读前后变化；scripts/html_rebuild_check.py capture/plan 为只读 CLI。
- 原 editor 和 repair 预览提供 dry-run，保存前重算计划并和作者文件同组回滚。保存后的 rebuild-<slide>.json 只在 plan_id/当前作者输入一致时由 editor.read 提供；过期记录仍是历史。
- 原 html_scene_changed 将计划写入 pending_impacts.details；保持 generation/source_version、防迟到完成和同值保存规则。生产任务保存 rebuild 阶段/结果，S02 作者恢复沿用同一影响规则。
- Web/Agent/MCP/CLI 保持请求与现有能力；Agent editor/read、preview、保存响应增加可空 rebuild_plan，公开 API1.19.0，生成文档同步。
- html_input_manifest 读取实际字节摘要，移除 mtime/size 缓存漏洞；字体或图片保持文件大小和时间戳也不能沿用错误批准。

## 验证证据与边界

新增测试15项：目标页标题、旁白、引用/未引用素材、字体、顺序/删除、模型配置、共享运行输入、动作/绑定、确定性/no-op、同大小恢复mtime、三页编辑隔离、真实确认散列、旧计划失效、影响去重及新快照不得绕过未知模型请求。

联合回归130项通过，CLI/MCP传输检查28项通过；派生记录容错补充后33项定向复验通过，实际工作流/任务store15项复验通过，最终最小重建/作者恢复/实际生产31项复验通过（复验有重叠，不合并作独立用例数）。Skill结构、Agent契约生成检查及 git diff --check 通过。所有数据库/运行目录使用 pytest 既有隔离，没有真实模型/配音费用。

一次补验中，源码变动发生在已建立快照的测试任务运行期间，固定输入检查拒绝继续；固定源码后同组15项重跑通过。该阻断作为版本一致性证据保留，不绕过快照哈希。

三页编辑案例将模型/图片/TTS入口设为禁止调用，只改页二标题后其他页字节与音频不变，页二批准失效、页一/三的依赖批准继续有效；重复保存不改重建记录。批准记录与音频为隔离 fixture，用于协议/哈希验证，不代表真实视觉或配音签收。另复用既有真实浏览器修复/生产回归，供应商不调用。

实现没有自动发起模型请求或创建第二调度器。修改引用模板需要注册能力和当前内容预算；计划只说明应重做什么，实际作者修复、TTS、检查、批准、导出仍由原服务负责。还没有跨任务视频片段缓存、全部阶段无人值守重建、新的影响可视化 UI；不能把纯计划或编译通过当作全片、审美或真实供应商验收。
