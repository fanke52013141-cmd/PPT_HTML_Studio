# 2026-10-17 发布备注：审查定位、文字边缘与跨机交接

本批将 `main` 上截至提交前的 HTML Studio 流程优化与文字边缘核验一起发布到项目 `origin`。契约包版本0.9.76。详细改动、测试结论与另一台电脑的继续步骤见[跨机交接](../plans/html-backend-development/handoff-cross-machine-optimization-2026-10-17.md)。

## 本批改动

- 收拢设计理解、参考局部定位、复核事实、任务恢复及呈现能力校验的契约、运行 Skill、代码与隔离回归。
- 参考定位新契约0.5.1逐一对应编号、标题、正文片段及关系标签；本地文字边缘诊断在原图上检查疑似越框墨迹，区分需要复核与不确定。
- 补入四版式固定对照、人工区域gold、同案例失败分析、隔离测试和后续开发停点。

## 验证结论

本批相关隔离回归255项通过。新增核验在受控截字样本80/80标出；40个完整样本中没有误标为疑似截字的结果，但8个不确定，说明仍有人工复核成本。原真实页三次分层联合通过仍只有1/3；新增诊断标记为待复核，不表示已修正或可验收。

具体证据和限制见[文字边缘开发报告](../plans/html-backend-development/reference-text-edges-2026-10-17.md)与[跨版式记录](../plans/html-backend-development/reference-part-mapping-2026-10-17.md)。

## 跨机边界

新增源码、Skill、固定gold、测试和报告均由Git同步。`data/`、`runs/`、`outputs/`、模型凭据、原图像响应和临时测试环境不进仓库；另一台电脑可继续代码开发并重建合成控制组，无法声称复用了本机忽略目录里的真实响应/图片。真实模型测试需在新机器本地配置连接并重新记录调用、未知结果和回执。
