# 后续开发实施卡

实际推进顺序见 [分阶段实施计划](../../plans/html-studio-implementation-plan.md)。本文件维护技术任务与验收边界；一张 DEV 卡可以跨阶段完成。

日期：2026-10-07。P01 的最小定义部分已完成，见
[最小定义卡包](../../contracts/html-presentation/definitions/README.md) 和
[交付记录](../../plans/p01-definition-completion.md)。以下 DEV 卡仍有后续实现与验收内容，
均未整体完成；不能将 P01 文档检查当作运行、视觉或输出验证。
卡片约束来自现有 HPS 契约，字段与 API 须按定义卡完成；具体新文件名在实现时登记，
此处不为了排目录提前创建空业务模块。

## DEV-01：场景与既有分镜的映射

- 涉及：HBA-02、09；HPS-001、005、006、010、018。
- 范围：先定义最小场景、原子、概念块、公开目标、布局/风格/资源引用与语块绑定。
- 现有接点：`storyboard_planning.py` 的纯规范化/compose 与 service/store 的编排职责。
- 产物：定义卡、版本化 Schema、原分镜到新场景的映射例子、受限编辑提案格式。
- 首个例子：两概念、三语块，公开两个概念的 title/body/figure；先手工内容，不接生成器。
- 验收：现有内容与讲稿不丢失；重排/改字保留身份；复制/删除重映射引用；
  未知能力/悬空引用有明确诊断；旧提案不能覆盖新修订；模型不能修改校验约束。
- 未完成前：不铺大量模板或修改现有 Step 2 生产 Prompt。

## DEV-02：一种风格与解析快照

- 涉及：HBA-01、03；HPS-002、003、004、005、009、013。
- 依赖：DEV-01 的参数角色与支持集。
- 范围：公共原子/概念块、左右布局、一种风格与其参考状态；形成参数解析与资源快照。
- 产物：token/变体/组合规则定义、来源解析、可重复生成的 CSS/JS、参考页与字体清单。
- 验收：缺 token/循环引用/非法覆盖被拒；组件语义不含风格硬编码；换长短内容与素材
  后可诊断容量；实际字体已就绪；参考画面审阅通过；切换轻量第二风格不复制业务组件。
- 说明：编译器按最小需要选择，不将 Style Dictionary 安装作为阶段成果。

## DEV-03：独立素材槽位

- 涉及：HBA-04；HPS-003、007、009、011。
- 依赖：DEV-01/02；首轮使用固定素材验证，然后才接现有 provider。
- 范围：用途、比例、透明边界、控制粒度、裁切、来源版本、资源身份和就绪状态。
- 接点：已有 provider/风格参考/并发治理；新的素材任务不得冒充原整页图片产物。
- 验收：两个对象能独立显示；截图 contain 不切掉标签；照片焦点/安全区有效；
  更换比例重算布局；失败保留原有效素材；无法满足的 provider 能力明确诊断。
- 产物：素材定义卡、槽位绑定样例、实际能力映射与最小失效规则。

## DEV-04：HTML 目标几何与动作求值

- 涉及：HBA-06；HPS-004、007、008、009。
- 依赖：DEV-01/02/03 的静态样板。
- 范围：固定画布、整体缩放、DOM/SVG/文字多行几何；reveal、highlight、勾画。
- 接点：`annotation_target_resolver.py` 的目标职责、geometry/timeline 的几何/时间职责；
  接入通过独立测量适配，不在 OCR 模块偷偷分支实现整个 HTML 渲染器。
- 验收：相同时间顺播/seek/倒退/乱序取帧状态一致；普通 reveal 不重排；中文范围与
  父组变换正确；隐藏与交互策略明确；位图内部区域的局限有诊断。
- 产物：目标定义卡、测量结果契约、阶段参考帧和动作边界记录。

## DEV-05：质量门槛与修复记录

- 涉及：HBA-05；HPS-005、007、009、013、017。
- 依赖：DEV-02/04，可与对应样板一起推进。
- 范围：静态结构、字体/资源就绪、排版测量、内容覆盖、对比与视觉审阅。
- 验收：分别报告通过/失败/跳过；缺浏览器不是视觉通过；诊断有对象、规则和修复方向；
  超容量不无限缩字或删内容；特定风格的阈值不变成所有风格的公共禁令。
- 产物：正常/边界样例、检查结果、修复前后画面及审阅结论；样板没有美感结论不能宣布完成。

## DEV-06：消费现有时间结果与输出真实视频

- 涉及：HBA-06、08；HPS-008、009、011、012、014。
- 依赖：DEV-04/05；先测试固定时间与现有音频样例，再接应用任务。
- 接点：`audio_timeline.json`、现有 provider/Qwen/人工时间、揭示绑定与勾画时间调度；
  `video_render_service.py`、`remotion_runner.py` 和当前 Video.tsx 的 PNG 限制。
- 范围：时间结果到公开目标动作的消费接口、HTML 画面适配、资源就绪、捕获与编码。
- 验收：offset/视觉提前量只算一次；旧音频哈希不会错误命中；未解析锚点进入现有诊断/
  校准流程；字幕估算不得冒充实测词锚点；关键帧与预览一致；输出旁白完整、时长符合约定。
- 产物：接入契约、固定修订/环境记录、真实 MP4 与同步结果；不新增音频模型比较。
- 后续：若当前视频路线确有无法解决的画面问题，另立有证据的适配器比较任务；不预先换引擎。

## DEV-07：PPTX 分级输出

- 涉及：HBA-07；HPS-007、009、012、013。
- 依赖：DEV-04/05 的最终状态与几何。
- 接点：现有 PPTX service/job、图片型与揭示快照导出、指纹与 readiness。
- 顺序：HTML 截图到图片型输出 → 分步快照 → 基础对象的原生映射；每种单独验证。
- 产物：对象/属性支持表、坐标换算、逐页/对象降级摘要、真实 PPTX 与目标软件检查结果。
- 验收：中文文本内容与身份保留、可修改文字无旧像素重影、尺寸/裁切/旋转/Z 序符合声明；
  未支持效果不静默丢失；全可编辑策略遇到必要转图时明确阻断；失败页不默认空白成功。
- 母版/图表数据/公式/原生动画：单独后续能力，不由基础对象通过推导为已支持。

## DEV-08：接入任务、失效与 Agent

- 涉及：HBA-08、09；HPS-006、010、011、014、015、016、017。
- 依赖：基础样板与最小输出已验证，沿用现有应用的持久化/服务所有权。
- 产物：新路径登记、业务影响登记、迁移/Agent 同步、输入快照、确认与错误恢复定义。
- 验收：草稿/已确认/已导出修订区分；旧任务完成不覆盖最新编辑；无变化保存不失效；
  单素材/单页重试不会重做全部音频或覆盖人工内容；图片与 HTML 门禁隔离。
- 数字人：只接入现有最终人物视频，验证构图、时间同步与合成；不替换生成或口型方案。
