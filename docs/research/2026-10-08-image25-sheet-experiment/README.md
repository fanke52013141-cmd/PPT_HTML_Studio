## 首次实验

使用用户完整图作为编辑目标，一次拆出灯泡、机器人、奶茶和大脑。固定1024×1024四槽、每槽512×512，透明留白至少64px，不画网格/文字/编号。实际提示词为[prompt.txt](prompt.txt)，提取规范为[spec.template.json](spec.template.json)。参考手绘图仅用于拆分技术验证，不能据此批准HTML手绘主风格。

生图调用需记录真实provider、model、quality、请求/返回尺寸、起止时间、请求次数及提供者实际返回usage；缺失usage时费用标记unknown，不按对象数量估算节省。模型返回PNG后执行：

```powershell
.venv/Scripts/python.exe scripts/check_asset_sheet_experiment.py --image outputs/image25-sheet/sheet-v1.png --spec docs/research/2026-10-08-image25-sheet-experiment/spec.template.json --out outputs/image25-sheet/extraction-v1
```

该脚本调用已有纯提取服务，检查PNG/预算/透明边界/空槽/裁边并输出原始source、实际SHA规范、manifest和独立候选PNG。保留原图RGB和alpha，不能用背景替换补造成功；几何通过仍须逐对象审阅身份/风格/边缘。输出目录必须新建，不覆盖既有证据或注册业务资源。

第一张板先检查是否得到4个可用候选。失败只针对问题对象或排布做一次修正，保留首次失败证据。随后使用相同参考图、模型/质量、目标对象分辨率和验收要求做4次单对象调用。比较总耗时、并行墙钟时间、总usage/费用、通过数、重试数及人工分钟；不能以1次对4次直接宣称效率提升。比较时控制板中对象缩小造成的质量差异。

Decisions候选用于身份匹配、完整性和后续动作选择；本轮尚未调用。精确轮廓由真实alpha及确定性处理负责，不能把模型概率当Mask。错误对象、跨槽、透明度失败或完整性失败先留待审阅，不自动入库。
