用户要求：先生成完整页面设计参考，确认后还原为可编辑 HTML 文字、结构及少量独立素材，复用已认可的声音、字幕和卡片节奏。关联 HPS-023–028、035–037。

本轮仅生成一张设计探索图，2K 2048×1152、low、不透明。沿用先前授权的 ToAPIs / gpt-image-2.5-flare-vip，不新选提供者。唯一主体参考是已批准灯泡 PNG，身份参考不是旧页面构图约束。不直接交付整页图片为生产视频背景，不重新合成音频。

## 设计定义与实现分工

内容来源：已保存 Token 单页场景与真实四句讲稿。主题参考 amber-science@0.2.0；当前模板 explanation-cards-v1@0.1.0、layout science-explanation-v1@0.2.0 用于归属追溯，新构图仅 draft，不能未经定义/运行验证替换生产模板。

| 稳定对象 | 内容/语块 | 最终实现与控制 |
|---|---|---|
| header / headline / intro | 什么是 Token；模型处理文本时使用的基本单位；切分取决于分词器 | HTML 真文字，独立编辑与首段出现 |
| card-1 | 未必是一个完整的词；可以是词的一部分、标点或其他文本片段 | HTML 知识段+代码编号/图标；沿用第二音频语块开始 |
| card-2 | Token 数量不等于字数；中文、英文和符号可能采用不同切分方式 | HTML 知识段；沿用第四字幕语块开始 |
| card-3 | 上下文与用量按 Token 衡量；许多服务按输入和输出 Token 计费 | HTML 知识段；沿用第五字幕语块开始 |
| subject | 已批准黄色灯泡概念插画 | 一张独立 PNG，完整轮廓，沿用已认可主体，不新生成多个小图 |
| figure / summary | 文本 → Token；具体切分由分词器决定 | HTML/CSS/SVG 面板、抽象块、箭头、关系文字；无假造具体分词结果 |
| anchor-label / annotation | 旧“概念配图”无额外知识价值 | 新设计探索中不强制展示；正式还原前需定义显式可选区域/新模板版本，不偷偷删现有必填槽 |

## 画布、层次和关键帧

16:9设计帧代表内容终态；底部约11%是安静字幕安全区，生图不画字幕。暖白底、深灰黑文字、琥珀重点，辅助色只用于灯泡现有细节。目标是编辑式科普信息图：标题显著、右侧主题视觉有分量、左侧三条信息节奏清晰、避免三张完全相同的大空卡片和无意义圈线。

代码表达概念的抽象关系，不引入字母/中文的“真实 Token 切分例子”、精确费用或上下文数值。资产层仅一张灯泡；其余文字、标签、装饰形状、箭头和阴影均留给代码。全页不使用手绘笔触、纸纹或密集拼贴作为主风格。

运动仍引用已有 beat ID，约16.032秒，用户已认可声音/字幕/节奏；只是新视觉设计，正式重建后需重验出现前后构图和容量，不修改原音频或已接受资源。源/Prompt/原始模型输出/实际参数与费用保存于独立证据目录；人审前不变为 approved。

验收：确认完整页面精美度、中文内容、单主体预算、字幕区、可用代码还原的边界。成功生图不能证明 HTML 还原或动态已经完成。用户确认后再形成可运行模板/变体定义卡、登记公共能力和实际还原截图，禁止直接烘焙为整页运行图片。

## 实际生成结果

后续状态（保留下方生成时记录）：用户以“认可”批准整页参考。已按新定义完成HTML还原与带原音频视频，见[还原执行记录](token-editorial-reconstruction-v1.md)。新版HTML及新提取灯泡边缘仍待实际视觉审阅。

一次真实调用成功，模型 gpt-image-2.5-flare-vip，ToAPIs，quality=low；请求及返回均2048×1152，RGB不透明，alpha=255。调用耗时494.41秒，供应商费用0.016504美元；没有重复提交。实际输入2279 tokens（文字771、图像1508），输出157，供应商 task_id 与参数记录在 `outputs/image25-sheet/token-design-reference-v1/evidence.json`，原始输出 `design-reference.png` 未修改。

视觉检查：大标题/定义在左上，单灯泡和抽象文本→单元示意在右上，下方三栏知识点；底部11%保持空白，无旧圈线/概念配图标注、无三张大边框卡片、无品牌页脚。主要标题/定义/限定及三条知识文本目视正确，无具体切分例子或伪造数字。

差异与限制：灯泡被重绘为更直立造型和较大视觉主体，非已接受PNG逐像素保留。关系图没有生成“文本/Token”两个标签，末尾限定未重复显示，但主定义下已有完整分词器限定。HTML重建必须消费原始文字/对象定义补齐关系语义，不能以OCR或缺失图中文字替换权威内容。灯泡先评估已有独立素材匹配程度；若新造型是设计批准的必要部分，单独生成/拆分对应资产并审阅，不声称旧素材已自动批准新像素。
