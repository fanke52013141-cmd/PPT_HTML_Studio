## 如何复用这些分析

1. 开始相关设计前，查找已有调研条目与对应 HPS 规则，避免重复分析。
2. 每个借鉴点保留稳定编号、原报告位置、证据、适用边界、实施位置和验收方法。
3. 区分“采用架构思路”“候选技术”“待核实主张”“不采用原结论”；采用思路不等于安装某个框架。
4. 实验产物与测量结果追加到对应实验卡。没有执行的实验不得填写通过。
5. 需要成为正式规则时，按 HPS-015 修订契约、记录兼容影响，并按 HPS-017 同步验证。
6. 更换选型时追加决策及原因，保留旧结论与原报告。已有作品仍遵循其固定版本。

每份档案建议包含：原文及校验信息、借鉴分析、来源核对、实验计划、机器可读的借鉴清单。
这是一套文档维护约定，目前没有自动执行器。
