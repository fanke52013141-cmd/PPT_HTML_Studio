## 2. 主题与讲稿

沿用现有真实旁白的三个语块：降温散热；标准大气压下纯水冰点0℃；继续放热凝固、凝固过程温度不变。完整输入保存在 [模型请求](decomposition-request.json)。

## 3. 实际文本模型拆解

Doubao Seed配置模型实际完成可视化分工。初次结果使用不合约定的HTML/CSS/SVG后端组合字段，保存原响应并交回同一模型修正一次；没有手工编造模型结果，也没有放宽后端枚举。

最终 [对象与分工](decomposition.json) 为13个对象：11代码、2独立插画。标题、条件、三知识卡、温度刻度、凝固示意曲线、关系箭头及标签归代码；水杯与固态冰归两份图片。选择12个已声明效果ID，三个讲稿语块均有对应对象。

[分工检查](decomposition-validation.json)覆盖对象身份、后端、效果白名单、主题准入、语块覆盖、几何边界、图片独立性及关系目标。该检查不验证所有自然语言科学细节，也不构成美术批准。模型增加的20℃/-10℃是示意刻度，不是讲稿提供的测量数据；正式制作应明确示意身份及是否必要。

## 4. 生图输入分工

实际发送六张图片：前五张是完整代码效果参考；最后一张是用户原始风格图，仅参考配色、亲和度、留白和插画语言。风格图不能赋予新增代码效果权限。每张实际附件、职责、哈希以及参数见 [image-request.json](image-request.json)。

输入文字包含 [固定规则](fixed-generation-rules.txt)、权威对象清单，以及本页选择效果的参数边界；最终发送内容见 [实际提示词](image-prompt.txt)。gpt-image-2.5-sunburst-vip / low / 2K / 16:9。一次真实生图任务，没有因画面不满意自动重试。

## 5. 实际结果与判断

[生成图](generated.png)实际2048×1152。三步知识卡、分离水杯与冰、刻度、温度示意曲线和文字条件均出现，画面与先拆解后分工的逻辑对应。最终图片仍是提案，不是运行场景。

观察到的偏差：标题新增渐变；部分位置与比例改变；图表增加了未单独声明的刻度/横线；插图出现柔和体积与阴影。固定背景仍有颜色波动。无法据此宣称效果编号与参数被逐项严格执行，更不能宣称已完成抠图、素材提取或HTML还原。

本次证明整条前半制作流程可以实际执行，不能证明跨主题视觉稳定性及还原一致性。后续应按同一对象定义构建代码与独立素材，并做分层对照，而不是重新猜排版。本轮无作者场景保存、无设计/视觉/节奏批准。

可以打开 [完整流程演示页面](workflow-demo.html)逐步查看。工具：`html_engine/tools/capability-workflow-board.cjs`、`scripts/demonstrate_capability_workflow.py`、`scripts/build_capability_demo_report.py`。
