# 固定效果集合 → 讲稿拆解 → 实现分工 → 联合参考生图

用户要求的完整流程演示，2026-10-08。关联 HPS-019/022/026/028/031/032/033/035/037。

本轮定义浏览器二维效果演示集合 v0.1.0，按几何、描边、填充、表面合成、文字、组合、数据、Canvas 示意、运动九类组织。每一效果具有稳定ID、实现、参数边界、示例、静态或动态证明及本次风格准入。清单为封闭集合；新增效果需更新定义及真实渲染证据。集合不声称穷尽所有浏览器能力，也不将这些浏览器示例自动登记成应用生产组件。

画布示例由真实 HTML/CSS/SVG/Canvas 绘制并截图，不由生图模型伪造。几何、参数与绘制函数一起保存；运动展示三个确定时刻，兼容路径形变限相同命令结构。粒子/波形属于教学示意，不承诺真实物理仿真；复杂3D、材质和玻璃折射归图片或超范围能力。

表面合成中的模糊、发光、backdrop玻璃、浮雕与混合用于明确“浏览器能做什么”，本次柔和彩色科普风格不准入；主体复杂插画可以作为独立资产。平台能力、主题准入、应用集成及视觉批准分别记录。

拆解输入为主题、一页真实讲稿、固定效果集合与主题规则。调用现有配置的文本模型，输出可视化设计、对象、source_beat_ids、code/image实现分配、效果ID、几何和独立控制要求。代码对象不得引用未知或禁用效果；图片不能承担文字、精确数据和关系线。模型结果通过白名单、讲稿覆盖、对象身份、图片独立性和画布/字幕区检查后才提交生图。

生图输入分三种职责：真实代码效果截图定义可实现表达；用户原始风格图仅提供配色、亲和度和插画语言；固定文字规则规定两者优先级与分工。实际对象清单决定本页内容，不靠图片模型重新发明课程信息。

本轮只演示设计前半流程及实际生图，不替换已有作者场景、不审批设计、不声称完成拆图及HTML还原。
