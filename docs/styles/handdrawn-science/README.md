# 手绘科普风：首个优先建设风格

> 当前状态：用户视觉审阅未通过；手绘水彩已退出当前建设范围。以下保留历史实验，不得用作已批准风格。后续遵守[视觉能力边界表](../../contracts/html-presentation/framework/10-visual-capability-boundaries.md)。

用户选择：先做手绘风格。用户提供的彩铅水彩参考板作为主视觉目标；当前蒸发实验仅作为运行基准，不代表所有内容与布局已验收；原浅色科普参考保留为历史探索，不覆盖旧作品。

## 视觉定义

| 项目 | 第一版约束 |
| --- | --- |
| 背景 | 暖纸色 #fffaf0，大面积留白，字幕区不加纹理 |
| 主体 | 深灰 #343c49 描边与文字；不用纯黑厚重边框 |
| 强调 | 珊瑚红 #d86856 标重点；浅黄 #ffdf87 作纸片；蓝 #8bc7d0 作示意 |
| 字体 | 微软雅黑，标题加粗，正文清晰；手绘感来自图形，不强制难读的手写字 |
| 线条 | 圆端、轻微不规则的二维曲线；通过固定路径或固定种子保持稳定 |
| 阴影 | 纸片可用单向硬投影，避免玻璃、金属和复杂光照 |
| 插画 | 独立透明资产，轮廓简洁，配色与代码一致；不把可变文字和关系箭头画进资产 |
| 动效 | 描线、圈注、标签落位和定向流动服务讲解；统一时间，可暂停、跳转 |

具体支持范围以[效果组件定义](../../../html_engine/effects/handdrawn-v1/DEFINITION.md)为准，不因本任务书扩大参数范围。现有烧杯仍作为运行样例；新插画可以使用参考板中的柔和水彩、彩铅排线与纸感，不再把纯色平涂作为全风格要求。代码效果仍须限定可执行范围，复杂质感使用独立图片资产。

## 公共能力与风格的边界

对象身份、文字内容、语义关系、时间轴、字幕区、几何目标、导出属于公共体系。颜色、描边、纸片投影、插画画风属于本风格。复用现有七类效果实现，主题不另写一套业务组件。

布局按内容选择：单对象过程、左右对比、路径步骤、中心分支、数据解释都是可探索构图，不强制所有页同一结构。目前只有蒸发单对象过程有本风格完整实现证据，其余须单独建立内容容量与审阅样例。

## 生产方式与复用

1. 先定讲解目标、对象清单、运动和字幕，选择已验证布局；新布局先作设计探索。
2. 向生图模型附[效果库参考图](../../../html_engine/effects/handdrawn-v1/atlas.png)，提示词仍列对象对应的CSS、SVG、Canvas或独立资产及字幕安全区。
3. 成熟布局无需每页重新生设计图；相同效果库图按版本复用。新增效果/配色才更新对应图板。资产按语义适配复用，不能只因相似就替换科学对象。
4. 生图负责独立插画；CSS负责文字与纸片，SVG负责箭头/圈注/图标，Canvas负责定向粒子。用同一时间轴组装。
5. 检查知识准确性、视觉层级、字幕留白及运动；设计图好看不等于最终动画获批准。

[查看当前动画](../../../html_engine/experiments/evaporation-01/index.html)；[设计对照](../../../html_engine/experiments/evaporation-01/comparison.html)。字幕字号在播放器调节；当前视频固定导出32px逻辑字号，控件设置不会自动保存到未来导出。

## 主参考更新：彩铅与水彩手绘

[用户原始参考板](references/user-style-reference.png)是当前优先视觉依据，优先于上表早期平涂参数；原图不修改。参考板是风格说明拼图，不是要复刻的课程单页，不能把它的高信息密度直接搬进视频。

- 质感：暖白纸面、轻微铅笔轮廓、彩铅排线、柔和水彩；避免把手绘等同于粗黑描边加纯色填充。
- 色彩：深蓝灰标题，柔粉重点，低饱和浅黄、浅绿、浅蓝、浅紫作辅助。每页选择少量辅助色，不把整张色板同时铺满。
- 插画：有温度的科学主题插画，允许细节与自然笔触；按可运动部件拆分，禁止把字幕、可变标题和数据烘焙进去。
- CSS：排版、留白、纸片布局、基础色块与遮罩；可复用纸张纹理图片，但字幕区保持干净。
- SVG：箭头、圈注、可变图标轮廓和数据图形；轻微不规则固定路径、有限排线可作为新效果开发，未经实现不能宣称已支持。
- Canvas：粒子或过程运动；如采用彩铅笔触，也须有确定性绘制与实际效果图，不能靠生图参考假定已实现。
- 资产：复杂插画、水彩晕染、彩铅纹理、纸胶带等可生成独立资产；与代码对象分开，避免只还原骨架后丢掉质感。
- 字体：圆润标题、清晰正文，优先可加载且授权明确的字体；当前微软雅黑仅为已验证回退，不代表已经达到参考板字体效果。

下一版验收重点是“代码成片是否保留参考中的质感与层级”，并检查纹理是否干扰小屏阅读。当前蒸发实验尚未按这张新参考重制，现有效果图板也尚未升级；后续须先升级少量关键效果并导出真实图板，再用于生成新设计。字幕分区、统一时钟、效果图板按版本复用的公共规则保持有效。

## 首张实做样板与阶段结论

[彩铅水彩12秒样板](../../../html_engine/effects/handdrawn-watercolor-v1/index.html)和[真实效果图板](../../../html_engine/effects/handdrawn-watercolor-v1/atlas.html)已完成。B01标签、B02下划线、B03弯箭头、B04星/叶图标为参数化SVG/HTML组件；B05烧杯为独立透明水彩插画。平静水面资产替代了含气泡的错误候选。底部100px字幕独立，字号20—44px；五个关键帧、实际播放及无声视频经过验证。

本样板证明基础手绘标签可以由前端稳定绘制并换文字，但参考图中的丰富插画、纸张材料感和多种布局尚未在本库覆盖。后续扩展优先新增不同语义插画与2—3种课程布局，再按内容容量验证；当前保持“风格实验通过技术验证、整体视觉待用户审阅”状态。
