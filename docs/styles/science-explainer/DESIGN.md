# 柔和彩色科普：首版设计规则

日期 2026-10-07；style.science-soft@0.1.0；状态 draft，待用户视觉审阅。
关联 HPS-003/005/007/009/013/022。本轮是 P02 独立视觉试制，不是通用场景编译器。

## 色彩与用途

| 角色 | 首版值 | 用法 |
| --- | --- | --- |
| 页面背景 | #F7F6F3 | 暖白底与整体留白 |
| 内容表面 | #FFFFFF | 白卡，隔离知识对象 |
| 主文字 | #405574 | 主标题、概念名、总结 |
| 正文 | #536279 | 完整解释，不使用浅色承载正文 |
| 次级文字 | #68768B | 类别、来源、辅助信息 |
| 重点文字 | #D94870 | 少量关键术语，不能全页都用粉色 |
| 柔和粉/蓝/绿底 | #FFF0F3 / #EDF3FF / #EDF8F1 | 类别容器或标签，搭配深色文字 |
| 边界 | #E3E8F0 | 细分隔，不用它承载必要文字 |

区别“重点语义”和“类别语义”：粉色主要提示知识重点，蓝色区分第二对象，绿底提示
生活例子；不规定凝结永远是蓝色。跨页重复概念的映射需要由文档保持一致。
浅色多用在背景，正文/来源采用深色；颜色之外还有 A/B、名称、文字说明，避免只靠颜色。

## 字体与空间

本机试制使用 Microsoft YaHei 400/700；实际文件哈希见 asset-font-evidence.json，
浏览器实际正文字体见 sample-checks.json。不分发系统字体文件，跨机器加载与离线打包待解决。
最终可改用有明确资源文件和来源的字体，字体改变后重排审阅，不按名称直接继承本次几何。

1920×1080：主标题 54，概念标题 36，正文 28，来源 18；正文行高 1.6。
来源属于设计样稿的独立来源区域，P01 四文字角色 caption=20；18px 来源角色需后续定义，
不能偷偷导入 P01 caption。标题 1—2 行、概念正文目标 2—5 行，以实际测量验收。
左右外边距 72，上 40，两概念间隔 36，卡片圆角 28，内边距 32。固定 16:9，预览等比缩放。

style.draft.json 仅表达 P01 允许的参数子集；sample.css 是设计稿的呈现实现。
完整样稿还包含辅助角色、渐变面板、标签、来源与总结条，这些不是已注册能力。
两者不能被当成完全一致的已运行风格；差异和下一步定义见后节。

## 素材语言

独立透明 SVG，柔和蓝色、少量渐变与轻体积感；图中不焊接文字、来源或数字。
每张资源一个可整体控制的科学示意，不按实际比例绘制。水分子小点只是抽象示意，
不是真实水滴大小或数量。下一步可测试生图插画，但本轮未验证 AI 素材稳定性。
想单独动画小点/杯外水滴时，需要拆分资源或公共矢量组件；整体 SVG 锚点不等于独立图层。

## 支持范围与扩展项

本轮真实可查看：一张两概念对比参考页，初始/第一概念/第二概念/最终四状态、长正文变体。
按钮直接选择设计状态，没有连续时间动画、讲稿音频或 MP4/PPTX。
支持声明仍是 draft 设计范围，不向运行 registry 宣布任何能力已上线。

P03 前逐项定义：来源/眉题文字角色；比较卡与生活例子/总结的语义组合；多类别背景色；
多色文本片段及稳定目标；渐变呈现与输出支持；标题/页脚区域与布局容量。
优先用已有原子和可复用组合表达，不新增“科普专属概念组件”。原 P01 卡不原地改默认。

## 风格定制经验

1. 先做完整正文再调留白。第一轮纵向预算偏大，调整为 540 高卡片、224 高图区，避免页面越界。
2. 浅色适合分区，解释文字必须够深。参考浅灰没有直接用于正文，粉色重点加深。
3. 初始状态保留标题、导语和出处；先讲一侧时保留空位，后续不发生布局跳动。
4. 长正文需要容量策略。本轮长稿取消重复生活例子区并缩减图区，是显式设计变体，
   保留原始正文与原版本；通用内核不能擅自删除 required 内容来换空间。
5. 参考图偏写实插画，本轮用可控 SVG 验证整体排版。写实/生图的视觉丰富度需要另测，
   不以此 SVG 样稿宣称完全复现参考插画风。
6. 视觉规则和运行接口分开推进：样稿发现新角色/组合后补定义，不能把 HTML 当生产契约。
