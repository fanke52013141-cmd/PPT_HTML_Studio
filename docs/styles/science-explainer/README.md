## 科普风特别需要注意的约束

- 区分实物、示意模型与装饰；示意比例/非真实颜色在必要时明确说明。
- 标签、单位、箭头含义、图例和来源清晰；颜色不是区分类别的唯一方式。
- 复杂插图的内容准确性与画风一致性分开验收。换图后资源锚点须重审。
- 先整体后局部时保留定位上下文；镜头聚焦是候选动作，不能先把它写成已实现能力。
- 新术语第一次出现需有解释位置；用直观插图帮助理解，不靠装饰挤掉正文。
- 流程、因果、时间先后不能混用箭头；定性描述不能伪造成有精确比例的数据图。
- 数字人/字幕使用既有合成方案，页面预留区域需单独验证，不临时遮盖关键图例。

## 首轮参考集建议（选实际课程后落定）

以一页概念解释或两概念比较作为主样板，配一个无标题变化例、一个长正文例及初始/
逐步/最终状态。机制流程与图示标注作为下一轮覆盖目标：它们需要先补相应公共能力卡。
“蒸发与沸腾”等可以作为后续选题候选，事实文本在选定内容后核实；当前未采用具体科学结论。

支持矩阵、边界检查、输出限制及经验记录。当前已有首版样稿和有限检查，详见 [P02 试制记录](../../plans/p02-style-sample-completion.md)；用户视觉审阅仍 pending。
