# 暖白琥珀主题定义与准入卡

2026-10-08；主题 `amber-science@0.2.0`，使用既有 hps.visual.theme 0.2.0 字段，关联 HPS-005、023–030、035–037。

用户认可 Token 单页配色与布局并要求继续。批准范围是已展示的这页静态样稿，不扩展为所有主题、所有布局、资产身份/边缘或有声视频已签收。来源为 [配色纠偏卡](../../research/2026-10-08-image25-sheet-experiment/token-palette-review.md) 与 `outputs/image25-sheet/token-palette-v2/theme-draft.json`。

| 项 | 定义 |
|---|---|
| 名称/方向 | 暖白琥珀科普；V05 少量插画，保留卡片、温和渐变和既有图标 |
| 配色角色 | 暖白背景 #FCFAF5，深灰主文字 #29261F，灰褐正文 #625D53，琥珀强调 #A66D14，淡米色容器 |
| 公共能力 | 复用 header/card/figure/summary/text/image/annotation、既有 CSS/SVG 图标与 enter；无新增组件分支 |
| 布局/容量 | 复用登记的布局；1600×900，内容区 y<800，字幕区 y=800–900；字号、槽位及行数沿用既有定义 |
| 图片 | 每页默认 0–1 主体；本样页使用已有灯泡，素材人工接受独立执行 |
| 内容/动作 | 主题只提供外观，不拥有文字、坐标、语义锚点或讲解时刻；卡片 tone 属实例选择 |
| 字体 | Microsoft YaHei，Windows；不新增字体分发保证 |
| 兼容 | 新主题 ID，不改 soft-science / neutral-science pinned 身份；旧场景保持原引用，不迁移数据库或重生音频 |
| 生产默认 | 注册可复用主题，不改变现有编排器默认，也不声称已实现项目主题选择入口 |
| 验证 | 注册/构建、主题切换后的容量/几何与随机 seek；正式音频和导出另验 |
| 用户结论 | Token 单页布局/配色 approved；其他结构、动态效果及导出 pending_review |

本轮仅增登记外观，不新增公共字段或放宽约束。只通过格式相容声明 compatibleLayouts，不将其等同每一种结构已获视觉批准。构建生成 registry/bundle，禁止手改生成物。

实施证据：源已登记并构建，主题切换/测量/几何/seek 检查通过；批准版 Token 快照与用户认可稿像素一致。真实音频、视频预览与独立批准范围见[单页输出记录](../../research/2026-10-08-image25-sheet-experiment/token-delivery-results.md)。动态/音频及完整应用生产闭环仍待完成。
