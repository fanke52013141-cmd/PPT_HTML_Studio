# 生图实验的实际输入输出

本次不修改应用生产 Prompt、数据库设置或模型路由。使用 toapis-image-gen 原有脚本，
保存三份实际发送的实验提示词，输出由本实验消费。按项目 Prompt 规则审查必要输入。

| 请求 | 唯一任务 | 图片输入 | 图片输出/消费者 |
| --- | --- | --- | --- |
| design | 做完整科普页面视觉设计 | 用户视觉参考板 | design.png；人工构图选择与 HTML 还原对照 |
| evaporation | 提取/复现设计里的水碗插画 | 已选 design.png | evaporation.png；左图槽位 |
| condensation | 提取/复现设计里的冷杯插画 | 已选 design.png | condensation.png；右图槽位 |

必要文字输入：准确屏幕文本、科学禁错点、分层职责、风格与构图要求。没有附长篇原文、
音频、内部数据库 ID 或要求模型猜坐标。输出仅图像，不要求模型生成无消费者的 JSON。
坐标、哈希、尺寸、透明度和模板数据由代码/人工观察记录。图像生成支持单一 prompt，
这里不虚构 system/user 两消息；每请求只附本阶段必要参考和任务说明。

失败策略：调用超时/失败不接受空文件；资产必须解码后检查尺寸和透明通道；素材有字、
切边或科学表达错误须修复/重试，不能靠 HTML 遮盖后声称素材合格。选定资产固化版本，
重新打开和截图不再调用模型。供应商任务 ID 可记作来源证据，不保存密钥或临时签名 URL。

实验参数：gpt-image-2-vip，medium，1k；整页 16:9，独立资产 1:1、透明背景。
未进行生产 Prompt 集成，因此没有设置迁移或 Agent/API 合同变化。

实际补充：初次显式 transparent 请求失败；auto 重试产生伪透明 RGB。新增两次 built-in image_gen 背景提取请求，transparent_background=true，消费者改为两个 -alpha.png。最终输出有真实 alpha，细节/边缘仍由视觉检查把关。
