# 双对象科普模板：混合视觉实验定义卡

ID：trial.science-two-objects@0.1.0；契约 0.6.0；定义 draft；实现 experimental；视觉 pending。
这是 P02 独立视觉实验，不是 P03 正式 Scene Schema/模板注册表。不覆盖 P01 固定定义。
所有数字只约束本次实验，须经视觉审阅与替换内容后再考虑提升为生产模板。

| 项目 | 实验范围 |
| --- | --- |
| 任务 | 两个同级概念的方向对比；横屏 16:9、1920×1080 |
| 复用单位 | 文字、图片、分组、关系箭头；无主题专属业务组件 |
| 必需槽位 | 一个标题；两个对象，各有图、概念名、方向、短说明；一个来源/示意说明 |
| 可选槽位 | 一行副标题；缺省不追加品牌、编号、英文或总结卡 |
| 资产 | 两个独立 PNG，优先透明底；contain，完整主体与阴影；禁止烘焙文字和箭头 |
| 内容预算 | 标题最多一行；概念名一行；相变方向一行；每侧说明最多两行；不缩字号/截字 |
| 几何 | 依据设计稿回收并写入 sample.css；两侧同基线，固定图片和文字槽位 |
| 目标 | page.title，left/right.figure/name/relation/body；关系箭头为代码对象 |
| 阶段 | overview：双图定位、标题；left：左说明；both：两侧说明；几何始终不变 |
| 溢出 | 显示诊断并阻断“可用”状态；作者调整内容/选择模板/分页；实验不自动改写 |
| 字体 | 本机微软雅黑，宿主字体不打包；实际加载/字体及可读性记录于 checks.json |
| 实例编辑 | 仅填写既定槽位；不接受任意 HTML/CSS；主实例与同资产的短标题替换验证分开 |
| 输出 | 浏览器样稿及截图；视频/音频同步/原生 PPTX 本次未实现 |
| 验收 | 实际图片解码、alpha、内容/素材/几何/状态检查；用户视觉审阅独立 pending |

边界：只换短标题/说明可以验证局部排版，不能据此声称跨主题模板复用通过。需要换知识
时还要更换符合任务的插画并做科学审阅；本次首先验证设计图到 HTML 的还原链路。
