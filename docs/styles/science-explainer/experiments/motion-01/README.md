# 12 秒对象过程动画：水滴汇集

2026-10-07；trial.water-drop-process@0.1.0。状态：动态实验已制作，工程检查与本机 MP4
取帧/解码通过；用户视觉审阅 pending。不是 P03 通用内核、正式生产模板或物理仿真。

## 打开与操作

[交互动画页面](index.html)：点击播放；拖动时间轴、暂停、切倒放/速度或跳转关键阶段。
首次加载暂停，图片与字体完成后启用控件。无需服务或再次生图；直接打开文件即可观看。
本机视频位于项目 `outputs/motion-01/water-drops.mp4`，12 秒、1280×720、30fps、无声。
视频按仓库输出规则留在本地，不提交 Git；编码/帧数/哈希见 [视频证据](video-evidence.json)。

## 呈现内容与职责

0—2.2 秒定位：精美冷杯位图建立语境，三个独立 SVG 水滴为放大示意。
2.2—5.4 秒靠近：三对象分别沿固定曲线路径向中心移动。
5.4—6.7 秒汇集：小滴淡出、大滴淡入并增长，表达汇集后的状态变化。
7.8—9.8 秒聚焦：镜头推进，世界对象随镜头改变；标题、阶段说明和底部注记留在屏幕上。
9.8—12 秒停留：保留结果供阅读；并非所有时刻都让对象运动。

水滴汇集只作定性示意；这不是水蒸气凝结过程或流体模拟。路径、时长、大小不表达
真实流动/速度/数量/比例。汇集采用叠化符号过渡，不能宣称实现了真实液体形变。
位图仍为独立生成资产，水滴为可复用代码符号；简单几何无需增加生图调用。

本轮代码职责见 [实验定义卡](definition-card.md)、[时间求值](motion.js)、[播放器](player.js)、
[呈现样式](style.css) 和 [资源来源](asset-evidence.json)。没有主题专属业务组件。
实验卡约束本样例，不隐式扩展 P01 三动作或允许新字段进入原 Schema。

## 时间和空间如何保证可控

objectMotion.evaluate(tMs) 是纯函数，返回完整对象位置、可见度、聚焦镜头与阶段文案。
没有随机数、CSS 自运行动画或必须先播放前段的历史状态；0—12000ms 外及非法数值拒绝。
播放器只是选择显示时刻，暂停/拖动/倒放都会重新计算；导出第 i 帧直接求 i×1000/30ms。
世界空间与屏幕空间分开，镜头变换在位图层与 SVG 层各作用一次；HTML 标题与注记不受影响。
cup 对象几何依据其世界矩形，不以整张 Canvas 的 DOM 边界替代；见定义卡的坐标说明。

## 实际遇到的问题与修复

初次同 t 重渲检查发现杯图区出现像素差，状态数值一致；切换 SVG image 后仍存在。
最终用固定画布 Canvas 的 high 采样与 willReadFrequently CPU 上下文绘制位图，消除了
本机乱序取帧差异。此为本浏览器下的实测修复，不推断所有浏览器的具体缓存机制。
SVG 仍负责精确对象与引导线；位图只在专用渲染层重绘，不转成整页图片。
CPU 绘制可能增加成本，本次视频完成证明这个小样本可运行，不代表长片性能已验收。

## 对后续开发的意义

本实验验证了路径位移、示意状态变化、镜头/屏幕层分离、同时间重渲和逐帧输出。
还没有通用 JSON 编译器、动作冲突校验、任意路径编辑或动画模板注册表。后续从这套
已验证小模型回收正式定义，保留旧 P01 版本，再接入已有讲稿时间轴。
新增 2D 角色之前应先确认这个短动画的视觉和节奏；无需更换现有语音或数字人方案。

代码审查：时间计算与 DOM/播放编排分开；只消费固定本地内容，不执行模型生成代码；
动作通道单一写入，资源未就绪不播放；所有输入控件值固定枚举/范围，无新运行依赖。
本次未改业务应用、数据库、生产 Prompt、Agent 或影响登记。正式生产仍按相关契约实施。
