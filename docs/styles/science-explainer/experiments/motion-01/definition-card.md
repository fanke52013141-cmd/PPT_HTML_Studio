# 对象过程动画：实验定义卡

trial.water-drop-process@0.1.0；契约 0.6.0；独立 P02 动态实验，非正式 Scene Schema 或生产动作注册。
创建时定义 draft；实验实现/检查另见 README 和 checks.json。HPS-004/008/009/013/023—025。

| 项 | 实验约定 |
| --- | --- |
| 用途 | 冷杯插画建立语境；三个示意水滴靠近、以淡入淡出表达汇集，最后镜头聚焦 |
| 非目标 | 不做流体仿真，不解释凝结生成机制，不代表真实运动轨迹/速率/数量/比例 |
| 规格 | 1920×1080；12,000ms；导出 30fps，共 360 帧，帧 i 为 i×1000/30ms |
| 所有者 | 冷杯位图复用 hybrid-01 固定资产，以 Canvas 固定 high 采样绘制；水滴/引导线为 SVG；准确标题/说明为 HTML |
| 对象 | cup、drop-a/b/c、merged-drop；对象局部→世界→屏幕；标题/阶段/说明固定于屏幕 |
| 空间 | camera={x,y,z}，screen=(world−camera.xy)×z+(960,540)；z>0，变换仅作用一次 |
| 时间 | evaluate(tMs) 仅接有限 [0,12000]，非法值拒绝；同一 t 始终返回同一完整状态 |
| 路径 | 三条固定三次 Bézier，各自 2200—5400ms 等区间，smoothstep 缓动；不读取播放历史 |
| 汇集 | 5400—6700ms 三小滴 opacity 1→0、大滴 opacity 0→1/scale .7→1；示意过渡，不声称流体形变 |
| 镜头 | 7800—9800ms 中心(960,540)→(1060,555)、z 1→1.15；HUD/字幕不参与镜头变换 |
| 通道 | 小滴 position/opacity，大滴 scale/opacity，世界 camera；独立单一写入，无通道冲突 |
| 语义目标 | cup、drop-a/b/c、merged-drop、page.title、page.caption、page.note；不按 DOM 序号绑定 |
| 讲解阶段 | 0定位，2200靠近，5400汇集，7800聚焦；阶段说明由同一时间源求值 |
| 播放 | requestAnimationFrame 只决定显示哪个 t；pause/seek/reverse 重新求值，导出直接 renderAt(t) |
| 素材就绪 | 字体 ready 与冷杯 decode 完成后才允许播放/导出；失败禁用控件并报告，不输出空图 |
| 容量 | 标题一行、阶段说明一行、示意声明一行；不自动缩小；舞台关键文字在安全区 |
| 检查 | 相同 t 顺序/乱序截图一致，暂停不前进，倒放、边界、目标矩形与位图解码、完整视频 |
| 兼容 | P01 0.1.0 三动作定义保持原义；实验不接管现有音频、数字人或数据库 |

手动时间只用于验证动画，不代表已经与讲稿音频对齐。世界对象允许镜头裁切；关键屏幕
文字必须持续可读。源插画内容未生出新模型资产，几何水滴为可复用 SVG 符号。

位图对象 cup 的世界矩形为 (180,275,550,550)，不是整个 raster canvas；对象几何应由时间矩阵映射该矩形。Canvas 与 SVG 分层使用同一镜头矩阵，各作用一次，不嵌套重复。
