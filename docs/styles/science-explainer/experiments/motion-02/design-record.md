# 短动画设计记录：纸飞机穿过云层

实验 motion-02；契约 0.7.0；场景 1600×900，10 秒。状态：设计探索，不是已发布模板。

本轮先填写对象与运动，再生成资产板/视觉参考并组装实际 HTML。权威输入见 [设计定义](design-definition.json)。它是实验自有格式，不是正式 Scene Schema。

## 内容与屏幕预算

目标：验证独立图片资产与代码控制协作，以及终态不含过渡轨迹时的完整性。画面不讲解飞行物理，不声称轨迹具有科学真实性。
标题“让画面动起来”，副标题“一张资产板，组合出一个完整过程”。只显示当前一句讲解摘要；不额外加入卡片、编号或装饰标签。
旁白仅作为运动映射文本，本轮不生成语音。时间暂定，未来接入已确认的原有音频时间轴后重新映射。

| page.subtitle | HTML 解释文字 | 顶部 104,190,1300,50；屏幕坐标 | 全程固定 |

| trail | SVG 临时轨迹，与飞机同一路径 | 层 20；不生成到图片中 | 1.6 秒出现，8.2 秒完全消失，终态不可见 |

文字、轨迹、终点不烘焙到图片。阴影局限于各图片内部，不画地面投影。两朵云和飞机分别可复用。
资源 ID、对象 ID、板槽位 ID 分开；独立控制边界以三个图片节点和代码节点为准。

## 运动与关键帧

0—1 秒飞机淡入；1.6—7.6 秒沿三次贝塞尔曲线飞行；旋转取路径切线限制在 ±22°。缓动 smoothstep。
曲线控制点：(280,570)、(540,260)、(940,650)、(1270,435)。轨迹逐步显露，7—8.2 秒淡出。
固定镜头，不施加额外缩放；每个属性只有一个状态写入者。以 t 求值，不依赖之前播放历史。
对象与屏幕区均为设计画布坐标；前景云层遮挡属于预期，标题与字幕不得遮挡。

| 帧 | 时间 | 检查目的 |
| --- | --- | --- |
| K0 | 0 秒 | 开场留白和云；飞机不可见 |
| K1 | 3.5 秒 | 飞机、部分轨迹与阅读层级 |
| K2 | 6.5 秒 | 后半程运动、遮挡、终点淡入 |
| K3 | 10 秒 | 飞机停留；轨迹消失；标题摘要仍可读 |

先生成 K1 的视觉参照，其余关键帧通过同一资产的实际渲染核对；不重复生成三个不一致的飞机。

## 资产板与提取计划

2×2 固定槽位：左上飞机、右上大云、左下小云、右下为空。共三个资产，数量依据本例需求。
各对象完整、独立、居中；只占所在槽位中间 70%，禁止跨槽阴影/标注/文字。真实透明背景需实测，不接受棋盘格充当 alpha。
固定矩形提取，保留整槽透明边距，记录源板尺寸/哈希、矩形和输出哈希。飞机中心锚点使用保留的画框中心，不假装已识别机鼻。
若板内容串槽、轮廓断裂、透明失败，先登记失败，再做修复或单独生成。不得通过默默修改对象清单迁就输出。

## 门槛与限制

G1：对象与任务已填，三个图片资源待生成；路径等仅实现为独立实验代码。
G2—G6：待实际生成、提取、组装、关键帧/跳转检查与视频验证。用户审美验收保持 pending。
HTML 和无声视频作为本轮输出；PPTX、音频同步、数字人、跨浏览器及生产注册表不在本轮验证范围。

## 试制修订 0.2.0

原始定义保留为 [v1 输入](design-definition-v1.json)。实际资产保留方形槽位，因此图片显示使用方形框，避免原计划非等比拉伸。代表过程帧改为 4.6 秒。
轨迹和终点仍由代码生成；本例将最初计划的 SVG 实现改为同一 CPU Canvas，以统一图像与矢量的层级和确定时间合成。保留显式对象 ID 与路径/圆几何，不将 Canvas 冒充 DOM 目标定位。
选用修复后的资产板 v2；初图和问题记录不覆盖。此次调整只影响实验定义，未改变公共规范或生产注册表。

最终帧审查发现终点提示被飞机遮住，实验修订 0.3.0 将其中心移到 (1480,400)，半径 25；原 v2 保留。重新执行状态与视频检查，公共契约未改变。
