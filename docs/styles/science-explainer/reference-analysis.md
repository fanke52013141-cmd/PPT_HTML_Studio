# 用户科普风格参考板：视觉拆解与能力映射

输入：用户提供的知识科普 PPT 视觉参考板，1672×941。原图与 SHA256 已保存在
[reference-metadata.json](reference-metadata.json)。此处分析视觉，不采纳图中的气候/能源数值。
用户要求先完善体系再定色系，因此本文件是后续样板的依据，不是已验收的产品风格。

## 1. 风格识别

建议工作名称：**柔和彩色科普**（名称待定）。核心是清晰、亲和、专业，带轻科技感。
观察到的视觉语言：暖白/浅灰底，大面积留白；深蓝灰主文字；粉色重点；柔和蓝、绿、
黄、紫用于区分信息；白色圆角容器、轻边线/阴影；带体积和柔光的科学主题插画。
这里的“轻科技”来自素材、细线轨迹和层次，不依赖大面积深色或复杂发光效果。

参考板是风格总览，不是一张实际课程页：不能把顶部标签、多个页面示例和底部说明
全部复制进一张 slide。实际页分别采用封面、内容解释、数据说明等配方。

## 2. 分层提炼

| 参考观察 | 系统归属 | 后续应形成的约定 |
| --- | --- | --- |
| 深色主标题＋粉色重点词 | 文字风格＋可控文本结构 | 主次层级与重点比例；多色标题需要明确文本变体 |
| 浅底、白卡、柔和多色 | 风格 token | 背景/表面/正文/强调/分类颜色分角色，不按像素随处取色 |
| 左文右科学插画封面 | 配方＋独立素材 | 留给标题的净空、主体重心、裁切边界与文字可编辑 |
| 内容页解释＋若干要点＋右侧图 | 区域/列表/图文组件 | 槽位容量与文字层级，支持换内容 |
| 图中的统计数据小卡 | 指标/注释语义组件 | 数值/单位/来源，不能把数字焊在插图里 |
| 柱图、环图、图例 | 数据图表组件＋数据编码 | 实际数据/轴/系列身份；配色不替代数据验证 |
| 圆角标签和编号步骤 | 公共呈现变体＋步骤语义 | 线条/圆角参数共用，顺序及子项有稳定 ID |
| 地球、宇航员、分子、冰川 | 素材语言 | 按页主题选择真实相关素材，独立可控对象分别产出 |
| 页尾来源/主讲人等 | 页面区域与内容 | 是否必需由内容/配方决定，不由风格擅自省略 |

参考板中的按钮属于风格示例，不要求演示内容必须带按钮，也不替换现有工作台橙色 UI。
图中机构名、图标、文案不作为我们的品牌或知识内容照搬。

## 3. 参考色板与可读性

[reference-palette.json](reference-palette.json) 转录图中 11 个色值标签，未进行自动像素取色。
图中“主色/Primary Blue”标签对应 #E8E8E8，实际为浅灰，存在名称和色值不一致；
未来按背景/分隔用途重新命名，不据这个标签把它当深色主标题。

正文标签 #5F6B7A 与白色的相对亮度对比值约 5.43；次级文字 #9AA3AF 与白色约 2.55。
这些是色值计算，不是整张图的可读性结论。后续主要解释文字优先采用足够深的色值，
次级灰只在适合的非核心场景使用或加深。浅粉/浅黄/浅蓝更适合作底色、分区、数据填充，
不能直接推导它们适合在白底上承载小号正文。真实字体、字号和播放尺寸须一起验收。

最终色系将区分：背景/表面、标题/正文/次级文字、主要强调、分类/图表色、连接线和标注。
并非每一页都使用全部颜色；分类色与语义对象的对应关系要跨页保持一致。

## 4. 字体、素材和动作

字体参考：图中建议思源黑体 Bold/Regular，以及 DIN 或思源黑体数字。我们尚未选择实际
字体文件与字重，不把字体名称当作字体已加载。后续验证中文、英文、数字、单位和符号。
参考图很小的英文装饰/脚注不能按同样观看大小照搬到课程正文。

素材参考：柔光、浅色、轻体积感的科学主题插画；画面主要区域保留干净空间。生成要求
要写明主题正确性、构图、背景透明/不透明、独立对象粒度、标签净空、允许裁切和锚点。
图片中的文字和统计值优先交 HTML；不可从参考拼图裁剪宇航员/地球当作正式资产库。
没有运行生图，因此尚未验证这种画风的生成稳定性。

动作是静态参考没有提供的部分：先用已有出现/强调/勾画试制，观察节奏，不自行添加
未经定义的漂浮、镜头移动或随机粒子。插画可有丰富度，教学信息应保持清晰稳定。

## 5. 参考暴露的实际扩展缺口

| 缺口 | 正确落点 | 实施前条件 |
| --- | --- | --- |
| 多色标题/句内固有强调 | 公共文字变体或有明确身份的标题组件 | 文本范围和公开目标保持，不能塞任意 HTML |
| 多类别柔和色板 | 风格协议的分类/数据色角色扩展 | 新字段/版本与冲突规则；不能任意塞入 P01 固定角色 |
| 白卡细阴影/柔和渐变 | 登记视觉参数和渲染/导出支持 | 不通过未登记 CSS 绕过能力表 |
| 编号条目/说明列表 | 公共列表、要点或步骤组件 | 保留 itemId 与语义顺序 |
| 统计卡、柱图、环图 | 指标/图表语义模型 | 数据/单位/来源/目标和输出能力 |
| 封面与图文不同组合 | 公共区域/配方 | 保留内容身份，容量和素材槽位可检验 |

这说明参考图不能靠“给 P01 换颜色”完整实现。先挑其中一张符合当前能力或只需小幅
扩展的内容页做样板，再按实际需要补公共能力；风格支持范围如实记录。

## 6. 样板审阅清单

标题是否抓住知识点；正文是否完整且实际观看可读；粉色强调是否节制；插图是否有
解释价值；类别色是否一致；初始/单侧出现是否构图稳定；替换长短内容后是否仍成立；
要点/单位/来源是否保留；独立素材是否便于控制；复杂效果的 PPTX 降级是否可接受。
按 S01—S08 记录观察、改动与证据，再回收成风格参数与定制经验。
