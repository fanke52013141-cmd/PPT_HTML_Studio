# PPT Visualization Studio（内容可视化工作台）产品介绍

> 一句话定位：一个部署在本地的「文章 → 课件 → 讲解视频 / PPT」智能生产工作站。
> 输入一篇讲稿或一个话题，系统自动完成分镜、配图、动画拆解、配音、字幕、重点标注，输出带旁白的讲解视频（MP4）和图片型演示文稿（PPTX）。

---

## 一、产品介绍：它能干什么

### 1.1 核心生产流水线（八步，其中两步可选）

| 步骤 | 用户动作 | 系统自动完成的事 |
| --- | --- | --- |
| 1. 导入文章 | 粘贴讲稿，或只给一个话题 | AI 直接生成文章；文章是全流程唯一事实来源 |
| 2. 分镜规划 | 审核确认 | 大模型把文章拆页，规划每页「讲什么、画什么」，生成可视化契约；分镜 Prompt 模板可自定义、可复用 |
| 3. 图片 | 选风格 / 上传替换 | 按 16:9（1920×1080）或 9:16（1080×1920）画幅生成纯白底配图；支持风格参考图反推、风格模板、图片上传 |
| 4. AI Mask 标注 | 审核自动结果 | 多模态模型识别画面元素，生成像素级精确蒙版（RLE）并与旁白语块一一对应——「讲到哪、画面元素就出现到哪」的逐元素揭示动画 |
| 5. 旁白与音频 | 编辑讲稿、试听确认 | TTS 合成配音（MiniMax、火山引擎豆包/Seed Audio、CosyVoice 等多家），自动字幕、音频时间轴 |
| 6. 勾画标注（可选） | 三栏工作区人工微调 | OCR 定位画面文字，AI 自动圈重点，生成手写风格的圆圈、横线、荧光笔标注，与讲稿短语精确关联、随语音时间轴播放 |
| 7. 数字人（可选） | 上传真人参考视频 | LatentSync 音频驱动口型同步，圆形画中画叠加到视频；未部署模型时可走 MOCK 链路先打通流程 |
| 8. 作品输出 | 下载 / 删除 | Remotion 引擎渲染 MP4（含倍速变体），或导出图片型 PPTX；渲染任务持久化，中断可恢复重跑 |

### 1.2 关键技术亮点

- **AI Mask 逐元素揭示**：自动像素标注覆盖率门禁 99.5%、零未分配组件、零跨组重叠；画面内被内容包围的白色不会被误抠除；画笔/橡皮人工兜底。这是「电子黑板边讲边写」效果的引擎。
- **勾画标注**：OCR 文字级定位 + AI 重点识别 + 手写笔迹动画，还原「老师拿笔划重点」的教学感，这是普通 PPT 动画和录屏做不到的。
- **IP 形象贯穿**：每个项目最多定义 2 个 IP 形象（名称 + 描述 + 参考图），自动注入生图提示词与参考图，让虚拟讲师/吉祥物形象贯穿全套课件。
- **一键全自动流水线**：可以一键跑通「文章 → 成片」，断点续跑；也可以每步人工把关后手动推进——全自动与人工质检可自由组合。
- **课程库管理**：课程 → 章节 → 项目三级树结构，封面与主题色管理，适合成体系的内容资产归档。
- **多账号与用量治理**：账号体系 + 配置包（LLM/生图/TTS 凭据一键导入导出），网关级并发与配额自动排队重试，多账号跑量不打爆上游。
- **Agent / MCP 接口**：内置 Agent API、MCP Server 与 CLI，能力矩阵版本化管理，可让外部 AI Agent / 自动化脚本远程驱动整条产线。
- **便携交付与数据安全**：Windows 便携包双击即用（内置 Python、Node.js、ffmpeg、Remotion 渲染内核）；全部数据留在本机（SQLite + 文件目录），不依赖云服务，内容不外泄。

### 1.3 重点模块详解：数字人讲师（可选 Step 7）

**两句话介绍**：数字人讲师，就是给每套课件配一位「出镜老师」——只需上传一段真人参考视频，即可生成机构专属的数字人形象，系统用 LatentSync 口型同步模型以每页配音驱动其「开口讲课」。数字人以画中画窗口叠加在课件画面上，成片就是「真人讲师出镜授课」的效果，但全程无需老师进棚录制、无需拍摄剪辑。

**具体能力**（对应独立推理服务，默认端口 9001，与主系统 HTTP 协同）：

- **形象素材库**：参考视频（avatar）上传 / 列表 / 预览，一个形象全课程复用；支持形象图片上传（可结合 ComfyUI 工作流生成/加工形象图）。
- **口型同步**：LatentSync 音频驱动重对口型，配音改了口型跟着改，无需重新拍摄。
- **画中画窗口三向自定义**：圆形或方形窗口，圆内拖动调讲师与窗口的相对位置、手柄拖动调窗口大小、圆外拖动调窗口在页面上的落位——不遮挡正文重点内容。
- **两种合成粒度**：可按页合成（每页旁白驱动该页数字人），也可整片一次合成（全片音频驱动）；未部署推理模型时可走 MOCK 链路先打通全流程。
- **隐私与成本**：形象与推理全部本地运行，无需第三方云服务，无按条计费的合成成本。

**数字人适用场景**：

| 场景 | 说明 |
| --- | --- |
| 课程虚拟主讲 | 系统班/刷题班/冲刺班微课统一由数字人出镜授课，形象稳定、无限复用，规避名师档期与流失风险 |
| 短视频虚拟主播 | 时政快评、每日一题、考点干货等竖屏口播短视频，打造机构自有 IP（如「XX 老师」），支撑矩阵号日更 |
| 题目讲解画中画点评 | 讲师以小窗出镜圈重点、给点评，与勾画标注联动，增强「真人教学感」与信任感 |
| 招生运营口播 | 课程介绍、开班通知、活动播报、备考提醒等运营类视频批量产出 |
| 周期性固定栏目 | 如遴选「公文写作小课堂」「时策点评」等栏目化内容，固定形象强化栏目辨识度 |

## 二、产品价值

产品价值的主战场是三类视频：**微课视频、题目讲解视频、短视频**。

### 2.1 微课视频：把「知识点文档」变成「能播的课」

传统微课 = 讲师写教案 → 做 PPT → 录屏/出镜 → 剪辑，周期以天计，强依赖讲师本人出镜与录音。本产品把这条产线压缩为「一篇讲稿进、一条成片出」：分镜、配图、逐元素动画、配音、字幕、划重点全部自动完成，讲师只需审核。

- 单条微课生产从「半天到一天」降到「审核几分钟 + 渲染几分钟」；
- 画面风格由风格包与模板统一保证，不用每条视频重新调设计；
- 讲稿改动后可快速重出片，内容迭代成本极低。

### 2.2 题目讲解视频：天然契合「逐步揭示」的讲解形态

讲题的本质是分步呈现：先出题干 → 再出选项 → 讲一步揭示一步 → 最后亮答案与解析。本产品的三个能力正好逐条对应：

- **AI Mask 逐元素揭示**：题干、选项、图形、演算步骤按旁白节奏依次出现；
- **勾画标注**：OCR 精确定位题干文字，讲到关键条件时自动圈出，错误选项划除、正确选项荧光标记；
- **旁白-画面-音频时间轴对齐**：讲解节奏完全可控。

等效于把「老师拿着笔讲题」的录制过程完全自动化，且每道题只需一份解析讲稿。

### 2.3 短视频：一套产线，两种画幅

- 项目画幅原生支持横屏 1920×1080 与竖屏 1080×1920，同一篇内容可分别产出横屏完整版和竖屏短视频版；
- IP 形象 + 数字人能力让短视频有稳定的虚拟出镜角色，圆形画中画口播形态适合干货类短视频；
- 一键流水线 + 多账号配额治理支撑批量生成，可承接矩阵号的日更节奏。

### 2.4 通用价值

| 维度 | 价值 |
| --- | --- |
| 产能 | 内容生产从「名师个人产能」变成「标准产线产能」，普通教研人员即可产出成片 |
| 一致性 | 风格包/模板保证全部视频视觉统一，机构品牌感强 |
| 资产化 | 每个项目同时沉淀 MP4（传播用）和图片型 PPTX（讲义用）双产物，课程库归档、长期复用 |
| 安全 | 全本地运行，题库、内部讲义等敏感内容不出内网 |
| 可扩展 | Agent API / MCP 接口可接入企业自动化流程，实现「文档库 → 视频库」批量转换 |

## 三、与公司业务结合（公务员考试 & 公务员遴选培训）

公司主营公务员考试与遴选考试培训，内容特点是：知识点高度结构化、题目讲解需求大、时政时效性强、课程体系化。与产品能力逐条对应如下。

### 3.1 场景一：知识点微课体系（主打卡：系统班/题库配套课）

- **行测**：资料分析速算技巧、判断推理（图形/定义/类比/逻辑）、数量关系公式、言语理解、常识积累——每个考点一条 3–8 分钟微课，用课程库「课程 → 章节 → 项目」组织成完整体系；
- **申论**：材料阅读方法、概括归纳、综合分析、提出对策、应用文格式、大作文写作范式；
- **遴选**：案例分析答题框架、法定公文格式（通知/请示/报告/函）、策论文结构与范例精讲。

**价值**：一次制作、多期复用；新讲师入职直接使用标准化课件，降低对名师录制的依赖；系统班、刷题班、冲刺班的配套视频可批量补齐。

### 3.2 场景二：题目讲解视频（勾画标注的主战场）

- **真题解析**：题干与选项逐项揭示，讲到某选项时自动圈出，错误选项划除、正确选项荧光标记，配合旁白解析；
- **行测例题精讲**：数量关系、资料分析逐步演算，勾画标注自动划出题干关键数据；
- **申论范文批注**：逐句圈划范文的结构词、规范词、得分点；
- **遴选案例分析**：材料要点逐条勾画，答题框架逐层展开。

**价值**：把「老师拿着笔讲题」规模化复制，无需真人出镜、无需剪辑，一份解析讲稿出一条视频。

### 3.3 场景三：短视频引流获客（招生侧）

- **内容形态**：每日一题、考点干货 60 秒、时政热点快评、公文格式小课堂，竖屏 9:16 批量产出，投放抖音/视频号/小红书/B 站；
- **虚拟 IP**：用 IP 形象 + 数字人打造机构自有虚拟讲师（如「XX 老师」），IP 资产归公司所有，规避名师流失风险；
- **热点响应**：时政热点当天 → 话题生成文章 → 一键成片，当天出视频抢流量窗口。

**价值**：内容供给从「依赖讲师拍摄」变成「教研供稿 + AI 产线 + 审核」的流水线，支撑矩阵号稳定日更/周更，形成「短视频引流 → 试听课 → 正价课」的转化链路。

### 3.4 场景四：数字人讲师落地（机构虚拟 IP）

公考培训高度依赖「老师出镜」，而名师档期紧、拍摄成本高、流失风险大。数字人讲师把「出镜」从一次性投入变成可复用的机构资产：

- **全套课程统一主讲**：选定一位授课老师的参考视频（或设计虚拟形象）生成数字人，系统班、专项班微课全部由该形象出镜，课程换季只需改讲稿重出片，老师本人零参与；
- **短视频 IP 化运营**：时政快评、每日一题、公文小课堂等栏目由虚拟讲师固定出镜，形象即品牌，矩阵号内容供给不再受真人排期限制；
- **题目讲解增强信任感**：讲题视频以画中画小窗出镜点评，配合勾画标注的圈划动画，「真人感」与重点呈现兼得；
- **招生与学员运营**：开班通知、备考规划、活动播报等口播视频批量制作，运营团队自助产出，不占用教研资源。

### 3.5 场景五：课程产品与学员服务

- **正价课批量制作**：把现有讲义、教案批量转成标准视频课，显著降低录课成本；
- **讲义同步生成**：每次出片同时获得图片型 PPTX，直接作为课后讲义/资料包发放；
- **内部赋能**：新员工培训、教研标准化手册也能用同一条产线出片。

### 3.6 落地路线建议

1. **第一阶段（跑通样板）**：选一个成熟考点（如资料分析「截位直除」）做端到端样板：讲稿 → 微课视频 → 审核定版，沉淀机构专属的风格包与分镜 Prompt 模板；
2. **第二阶段（模板化量产）**：沉淀「知识点微课」和「题目讲解」两类模板资产，教研团队批量生产首批 50–100 条，灌入课程库；
3. **第三阶段（IP 化 + 矩阵）**：确定机构 IP 形象与数字人讲师，竖屏短视频矩阵日更，打通「引流 → 转化」链路；
4. **第四阶段（自动化）**：通过 Agent API / MCP 接入内部自动化流程，实现「题库/讲义库 → 视频库」的批量无人值守转换。
