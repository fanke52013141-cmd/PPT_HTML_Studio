## 内容核对与修订

1. “最小单元”改为“模型处理文本的基本单位”。不同 tokenization 可以把一个字符拆为多个字节片段，也可能一个 token 包含多个字符。来源：[官方概念](https://developers.openai.com/api/docs/concepts)。
2. 删除通用“1000 Token≈750个中文汉字”。官方约0.75词/Token的估算针对英文，不能搬成中文字符比。中文本课采用指定编码实测。
3. “人工｜智能｜很｜有｜趣”和“un＋happiness”不作为实测。tiktoken 0.13.0 / cl100k_base 实测：Hello world! 为3；人工智能很有趣为10；unhappiness 为3，分段 un/h/appiness。中文有 token 只含部分 UTF-8 字节，本课不把单 token 不完整解码显示成汉字。见 [编号与字节证据](tokenizer-evidence.json) 和 [复现脚本](measure-tokenizer.py)。未绑定任何当前模型，不能把该编码等同所有模型。
4. 输入/输出分别理解计费，不写实时单价；实际服务可能另有缓存/推理/工具规则。费用表达仅为基础文字请求示意。
5. 上下文不是永久记忆，输入和输出需要一起考虑，部分模型还包括推理预算。见 [官方上下文说明](https://developers.openai.com/api/docs/guides/conversation-state)。超限不一定自动丢弃旧内容：Responses disabled 默认会报错，auto 才截断较早项目；应用还可以压缩。见 [接口规则](https://developers.openai.com/api/reference/python/resources/responses/methods/create)。4k 仅教学假设，不声称某当前模型上限。
6. 数字、表情、换行、空格“影响数量”，不承诺每个固定占1。不同模型也可能共享编码，差异不是必然。

这些是事实修订，不是用户已经认可的改稿；旁白可进一步调整措辞。原文最后的提问改为课程练习提示，未将教材中的提问当作用户指令。

## 视觉与资产分工

书本是通用知识插图，负责柔和3D造型，不承担 Token 机制证明。所有知识文字、例子、数字、顺序均由 HTML 文本节点实现；每个步骤按时间出现。书本始终可见，避免随机装饰运动。每页同图验证资源复用，也意味着画面变化较少，不能将其视为已经完成最佳叙事设计。

v1 左右主体留边约7.1%/6.2%，未满足10%；v2改善至11.0%/11.2%，但非零 alpha 的低透明度杂点仍触及下边界，且未完全消除外部光晕。选择v2作为 conditional-experiment 预览，G3不升级生产通过。原图/修订/提示保留；见 [质量数据](../../evidence/token-course/asset-quality.json)、[浅深底对照](assets.html)。不要降低质量规则以接受这一个模型输出。
