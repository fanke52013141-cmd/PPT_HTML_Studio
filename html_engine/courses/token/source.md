# 用户原始课程：大模型领域的 Token

Token 是大模型处理文本时，拆分出来的最小文本单元，模型不能直接读懂人类的句子，必须先把文字切成一个个 token，再转成数字向量进行计算。

不是简单按字或者词切：英文常是单词、单词片段、标点，比如 unhappiness 可能拆成 un + happiness；中文大多是单个汉字、少数常用词语、标点符号、空格。粗略换算：1000 token ≈ 750个中文汉字（含标点）。举例：人工智能很有趣 → 人工｜智能｜很｜有｜趣。

两个核心作用：计费，很多大模型 API 输入提问和输出回答都会统计 token；上下文窗口，每个模型有最大 token 上限，比如4k，历史对话加新提问超过4k就会丢掉最早内容、遗忘前面的对话。

数字、emoji、换行、空格也会占用 token；切分算法叫分词器，模型规则不同；训练也用 token 作为基础单位。

总结：Token 是大模型眼里的文字碎片，是阅读、计算、记忆文本的最小单位。
