# Token视觉试作 v2：共享设计定义

格式 hps.visual-study 0.1.0，独立设计探索；不更改E1/E2/P01运行格式或宣称生产模板。依据 HPS-023—030。画布1600×900，五页共同风格为用户指定柔和3D科普：暖白、蓝灰正文、珊瑚重点、淡紫/淡蓝氛围。每页有独立构图/关系/运动，设计图先于资产和还原。

实现职责：中文标题/正文、Token片段/编号、数据/公式、精确容量、路径/箭头由HTML/SVG；复杂模型装置外观与总结脑形资产由生图；背景渐变/容器/分隔由代码。所有资产示意，不作为真实模型内部结构图。每个运动节点稳定ID，纯时间求值；不把整个设计图作运行背景。

对象/布局/关键帧/动作/生图任务保存在design-definition.json；定义为探索实例，不是正式schema。计划时间为手工，可向前/向后跳转，未绑定音频。测试最终审美优先，几何检查不能代替审阅。五份设计图作为关键状态参照；本轮只需三个复杂对象，因此各自生成透明资产，没有生成资产合图。如果资产/设计构图偏离，保存差异、回写修订，不默默更换。

流程：G1定义→G2五设计图→检查/选定→G3按图独立资产→G4HTML/SVG组合→G5首/中/末逐状态对照→无声视频与课程预览。用户审阅仍pending，旧v1拒绝状态不覆盖。

## 完成结果与使用

[实际动画](index.html)有五个场景，总计79秒：处理链16秒、分词对照15秒、用量流16秒、容量预算18秒、总结14秒。点击“播放整段”连续观看；章节按钮显示该场景终态，点击“播放本场景”观看出现与运动。时间条可任意跳转。“生图设计参考”切换生成参考图，不参与实际渲染。[并排对照](comparison.html)展示五张设计图与五个实际终态。[旧版](../legacy-v1.html)仅作历史对照。

当前结果完整走过人工设计试作链路；未接旁白音频，节奏为手工预演。无声MP4保存在项目 `outputs/token-visual-v2`，参数、帧数、哈希与解码结果见 `evidence/video-export.json`。不把MP4提交Git。

## 本轮实际分工

| 场景 | 构图与解释关系 | 生图职责 | HTML/SVG与运动职责 |
| --- | --- | --- | --- |
| 文字进入模型 | 左文字→中心装置→右向量，底部结论 | 独立透明立方装置 | 真正文字/编号/向量示意；三个临时片段飞入装置，终态保留原始片段 |
| 一个字≠一个Token | 上下两组对照，右侧数量对比 | 无；不能为生图而生图 | 英文三片段、中文十个真实编号逐个出现；编号来自分词实测 |
| 输入输出用量 | 左输入→中心球形装置→右输出，底部算式 | 与此设计图匹配的独立球形装置 | 120/80教学假设、输入输出方向、符号粒子移动、分别核对单价的公式 |
| 容量预算 | 大容量管与三个处理结果 | 无；比例与数字必须精准 | 容量各段增长；斜线表示预留输出；新增1,500覆盖剩余1,000并超出500；处理结果逐个出现 |
| 三个关键词 | 中心插图、左右和下方关系 | 独立脑形比喻插图 | 三组概念和曲线依次出现，末尾显示练习提示 |

用量流只使用少量符号粒子表达方向，不把粒子数量伪装成实际120/80计数。脑形与装置属于解释性比喻，不是模型的真实内部结构。最小字体20px，常规说明22–30px，标题64px，实际画布1600×900。

## 设计到还原的差异

所有生成图片中的文字只是视觉参照。第二页生图出现错误中文切分，实际改为 `cl100k_base` 的真实十个编号；不把编号硬配成十个汉字。第四页生图比例不准确，实际按4,000容量计算，预留输出与已输入分开表达；“截断”按接口策略移除输入，不承诺固定丢弃顺序。

第一页和第三页的无关地球、小球装饰被省略；第三页没有强行复用第一页立方装置，而是按球形设计另生成资产。第五页减少参考图冗长段落，保留三个概念的环绕构图。布局、间距和文字密度在实际浏览器中调整；这些是明确的设计适配，不宣称像素级复刻。

`design-definition.json` 的 `objects[].box` 记录G1规划位置；实际终态位置以 `evidence/actual-geometry.json` 为准，实验坐标实现在 `player.js`。目前还原由人工辅助完成，不是自动图片转HTML。后续如果视觉获认可，需要把选定构图整理成E2布局与输入约束、完成规划对象到运行对象的显式映射；不能直接把当前硬编码页面标成生产模板。

## 资产与验证记录

五个完整画面提示保存在 `design-prompts.json`；三个独立透明资产提示保存在 `asset-prompts.json`。设计图先生成、检查，再以对应设计图作参考生成独立资产；没有把设计图裁成整页背景。资产保留模型原始PNG，没有自动抠图。三资产尺寸、透明范围、主体边界与SHA256见 `evidence/asset-quality.json`。资产存在柔光边缘，在本轮浅色底上已检查；深色底、换风格和批量复用尚未批准。

实际检查：五页各五帧共25帧、乱序跳转同时间像素一致、终态文字范围、容量段宽度450/150/300/450、过渡对象出现和消失、章节边界、参考模式与播放按钮，详见 `evidence/verification.json`。五个终态和处理链/用量流/容量的中途帧已进行人工视觉审查；修正了分词说明断行和新增内容后错误的“余量”标签。检查通过不等于用户认可美感。

在 `html_engine` 安装锁定依赖后运行：

```powershell
node courses/token/visual-v2/build-definition.cjs
node courses/token/visual-v2/playback-clock.test.cjs
node courses/token/visual-v2/verify-export.cjs
node courses/token/visual-v2/verify-export.cjs --export
```

Chromium由Playwright提供，可通过 `HPS_CHROME` 指定已有Chrome路径。必须存在Microsoft YaHei；字体缺失会报错，不能静默换字体。导出需要ffmpeg/ffprobe，1280×720、24fps、1,896帧、79秒、无音轨，先写唯一临时文件，检查后转正式文件。预览文件可离线双击运行；无需API凭据。

## 下一阶段的入口条件

本轮只提交可观看的完整视觉实验。用户判断画面、构图与动作是否达到预期后，再决定是否把这些布局固化为可复用模板并接入现有音频时间轴。语音合成和数字人继续用现有方案。当前没有变更E1/E2格式、应用服务、Agent接口、数据库或原有TTS/视频管线。

## 播放无响应修复

用户报告“播放整段”无反应后，隔离执行真实播放器时钟函数，复现首个requestAnimationFrame时间戳早于点击时performance.now的情况：旧计算产生-5ms，时间范围校验抛错，后续帧未调度。修复为只累积非负时间差，并保持时间基准单调；时间范围校验仍然保留。增加资源就绪前禁用按钮、播放失败提示和脚本版本参数。

回归测试覆盖早到首帧、后续时间推进、暂停、单场景终点、整段终点、未就绪和渲染失败反馈。它直接执行源文件中的时钟函数，不替代用户浏览器的点击验证。浏览器操作工具拒绝访问file协议，因此本次未宣称已在用户当前标签页完成点击验证。画面与纯时间导出没有变化，已有无声视频无需重导出。
