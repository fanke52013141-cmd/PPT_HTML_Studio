# 彩铅水彩手绘风格样板 0.1.0

> 当前状态：用户视觉审阅未通过；手绘水彩已退出当前建设范围。以下保留历史实验，不得用作已批准风格。后续遵守[视觉能力边界表](../../../docs/contracts/html-presentation/framework/10-visual-capability-boundaries.md)。

[打开完整样板](index.html) · [效果图板](atlas.html) · [主风格规范](../../../docs/styles/handdrawn-science/README.md)

这是独立风格实验，承接用户给出的彩铅水彩参考图。用同一组真实组件完成一张12秒蒸发讲解页，底部100px专用字幕区。当前为一页单对象过程，不宣称其他页面布局已经完成，也未集成既有项目的语音和数字人。

## 可复用部分

| ID | 对象 | 实现 | 变体 / 动效 |
| --- | --- | --- | --- |
| B01 | 手绘水彩标签 | SVG轮廓/分层渐变/边缘排线 + HTML可变文字 | 短词、尺寸、粉/黄/蓝/绿/紫；渐显与描线 |
| B02 | 双线彩铅下划线 | SVG | 宽度、颜色；逐笔出现 |
| B03 | 弯箭头 | SVG | 宽度、颜色；逐笔出现 |
| B04 | 小图标 | SVG | 星、叶；逐笔出现 |
| B05 | 平静水面烧杯 | 独立透明PNG | 当前主题资产；其他内容需另选科学正确的插画 |

统一组件接口`WatercolorEffects.mount(parent,type,options)`返回`at(0..1)`、`geometry()`、`destroy()`。组件只处理外观与进度；场景对象顺序、字幕与时钟在scene.js。标签中文字长度与实际宽度均校验；动态和跳帧共用纯时间取值。图板由真实代码渲染并保存为evidence/atlas.png，后续同版本直接复用。

图像生产记录见asset-provenance.json。最初生成的烧杯带气泡和液滴，容易误导蒸发知识表达，已弃用；当前资产是无气泡、平静水面的独立插画。图板上的组件注释不进入成片。

## 验证与边界

运行`node html_engine/effects/handdrawn-watercolor-v1/verify.cjs`；结果见evidence/verification.json。检查五个时间点乱序取帧、底部字幕区、字号20/32/44px、实际播放/暂停、非法组件参数和浏览器错误。`export.cjs`输出12秒、1280×720、24fps无声MP4，视频经ffprobe和完整解码检查，记录在evidence/video.json。

视觉对照：相较此前平涂标签，新增不规则水彩底与边缘彩铅排线；标题采用本机华文楷体/楷体回退，正文保持清晰；烧杯保留独立水彩质感。与用户参考拼图相比，本样板仍是简洁单页，图标种类、插画叙事和多布局尚未建立。用户视觉审阅待完成，不据此把整套风格标为生产批准。华文楷体依赖本机字体，跨机器分发前须解决可授权字体嵌入与回退验证。

本实验不修改既有handdrawn-v1、E1/E2格式、应用服务、TTS、数字人或旧视频。
