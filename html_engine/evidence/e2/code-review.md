# E2 五轴审查

正确性：配方字段拒绝自由布局；派生输入仍经 E1 Schema/语义校验，浏览器验证真实容量、资源及逐时求值。裁切已实测；所有旧测试继续通过。

可读性：公共配方模块、资源工具和遮挡诊断各自独立，实例 JSON 保存知识内容。两个固定配方不提前引入通用排版算法。

架构：作者配方与 E1 运行数据分层；P01/应用/API 不变。开放配方当前基于两个已验证 E1 示例作为几何基底，未来应升为独立模板基底；现在不宣称完全独立的样式系统。

安全：输入不能提供脚本/任意 CSS；资产限包内直属 PNG，真实路径检查防符号链接逃逸，像素预算在解码前检查；crop 输出不覆盖已有文件。无新外部网络运行依赖或密钥。CLI 仍是本地可信开发工具，未提供多用户服务权限边界。

性能：构建阶段审计资源，运行继续复用 E1；限定两个槽位及固定画幅。遮挡仅包围框，不执行昂贵像素分割。

结论：可以作为独立 E2 探索工具发布。视觉待用户审阅、资产边缘条件状态、单一风格、人工时间、代表性课程内容而非完整用户课程明确保留，不升级生产批准。
