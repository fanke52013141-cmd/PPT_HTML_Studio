# 效果库图片约束实验 01

目的：比较生图模型仅接收文字分工与同时接收效果库图片时，对具体视觉语法的遵守情况。案例为“水为什么会蒸发？”。A仅文字，B相同文字加atlas.png及说明其参考角色。提示词见prompts.json。

atlas.html包含实验CSS纸片标签、SVG箭头/圈注/太阳及Canvas 2D粒子轨迹；atlas.png是同源代码实际渲染。局部编号A01—A05仅为此实验图板索引，不注册正式效果能力。粒子预览是固定代表状态，尚未提供完整运动模板；本实验不证明动画可行。

评估项预先固定：标签硬偏移阴影；箭头单线；圈注单线；太阳8根光线且无脸；6个粒子和虚线轨迹；无额外烟雾/材质/图标；不出现实现标签；中文标题与说明；烧杯仍是独立图像资产任务。标为遵守、偏离或无法由截图精确判断，不以整体精美替代逐项判断。

单次A/B属于设计探索：工具未提供固定随机种子或模型标识，结果存在随机差异，不能将一对图的差异推断为稳定的因果效应。即使B更接近仍需逐项验收，更多样本才可评估重复可靠性。此次只生成设计图，未生成独立烧杯资产或最终课程，不宣称最终HTML可交付。

运行atlas渲染：在html_engine安装锁定依赖后，从项目根执行 `node html_engine/experiments/effect-reference-01/render-atlas.cjs`，可用HPS_CHROME指定Chromium路径。字体为Microsoft YaHei。实验网页与原Token课程独立。

## 实际结果

[对照页面](index.html)展示输入图板、两张原始输出和逐项人工审查。生成工具为内置image_gen.imagegen；提示词与图片保存在此目录，不裁切、不修改生成图。A的7个粒子、B的8个粒子都不满足要求的6个；B漏掉主标题，且烧杯增加白色高光。两者太阳8根光线、标签硬阴影、圈注与不画生产标签基本遵循；B弯箭头较贴近细单线参考，A明显加粗。严格线宽、色值和倾角不能从生成图片证明符合代码参数。

结论：模型可理解常见效果描述，图片能提供具体外观参照；本轮无法证明附图总体优于文字，也无法证明遵守稳定。两图都有明确偏差，不生产批准。后续有意义的测试应固定评估项、多次重复，并检查实际HTML/SVG/Canvas还原结果；本轮不为“让图片上的粒子数量精确”追加无止境重试，运行精确数量由代码负责。

审查：正确性已检查文字/数量/图形；实现为独立小实验，不改变公共运行接口；固定Canvas样例无需随机；本地页面无远程依赖/秘密，文字静态，图片本地引用。没有新增库。图板实现仅覆盖本轮五个固定样例，尚未有完整组件参数与运动验证。所有结果和局限如实记录，可作为探索证据发布。
