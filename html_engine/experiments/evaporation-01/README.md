# 手绘蒸发完整试作

本轮完成：七类可执行效果组件→带注释效果库图片→附图和分工二次约束的场景设计→独立透明烧杯→20秒HTML动画→两主题/尺寸/文字复用验证→无声视频。视觉待用户审阅，运行验证不自动批准全部效果范围。

入口：[动画](index.html)、[设计对照](comparison.html)、[复用样例](reuse.html)、[效果库](../../effects/handdrawn-v1/atlas.html)、[组件定义](../../effects/handdrawn-v1/DEFINITION.md)。独立实验不改变E1/E2/P01格式、原Token课程或应用服务。

## 流程与实现

场景定义是scene-definition.json，离线包definition.js与其一致；当前人工组装在player.js，不宣称自动从图编译。七类组件同一入口FlatEffects.mount，实例分别传内容、尺寸、ID和主题；CSS文字/标签/容器，SVG箭头/圈注/太阳，Canvas 2D粒子。参数与限制先在组件定义中登记。容器作为公共效果在图板与复用页使用，当前场景无需强加卡片布局。

生成任务先附实际代码效果板，再明确每个对象的实现归属，实验提示见prompts.json。选定设计后独立生成烧杯；保留透明原始PNG，不自动抠图、不修改生图像素。资产大小、透明边界、哈希和图板版本见generation.json。设计图完整标题与六个粒子可用，线宽与颜色仍不能由生成图严格保证。

实际构图保留主要视觉关系，但不是逐像素复制：标题采用已定义最大字号62px；扩大烧杯显示框以补偿资产透明留白；缩短并外移箭头避免杯沿相交；粒子固定六个且按不同高度上升；增加数量示意说明。烧杯生成仍带水面渐变和较粗边线，作为资产差异明确保留，不能宣称完全遵循“纯色4px”。未遗漏图标：太阳为真实八光线SVG，箭头和圈注均代码绘制。

## 运动与知识表达

0—4秒标题/烧杯/太阳进入；4—10秒六粒子从水面沿曲线逐步上升；10—14.5秒箭头描画、标签轻弹性落位；14.5—18秒状态转变文字和圈注出现、解释揭示；最后停留。整个对象状态由毫秒时间求值，固定种子，不依赖先播放多少帧。太阳二维小幅转动，不做3D。减少装饰运动选项去掉太阳弹性与杯体落位，保留解释运动。

科学边界：蒸发可在不沸腾、无太阳直射时发生；太阳是日常背景。蓝点和虚线表示过程方向，不是实测分子或轨迹。没有沸腾泡或白雾。当前人工无声时间，不声称旁白已对齐；语音和数字人后续沿用既有方案。

## 验证与输出

evidence/verification.json保存14个复用实例、六类非法参数拒绝、六关键帧、乱序取帧像素一致、六粒子几何、文字范围、实际播放时间推进、暂停及时间条检查。复用页使用同一代码，暖色小尺寸/短文字与冷色大尺寸/长文字；不是复制两套样式实现。视觉检查了终态、7/12秒过程及复用整页。仍需后续独立内容复用与用户视觉审阅，不能以14个实例推断所有参数都获批准。

从项目根运行以下命令，依赖html_engine已有锁定安装，HPS_CHROME可指定Chromium：

```powershell
node html_engine/experiments/evaporation-01/verify.cjs
node html_engine/experiments/evaporation-01/export.cjs
```

视频在outputs/evaporation-01，20秒、1280×720、24fps、480帧、无音轨；参数、哈希和完整解码检查见evidence/video.json。导出用相同renderAt，唯一临时文件验收后改为正式文件；MP4不提交Git。预览可离线打开，要求Microsoft YaHei；缺字体/资产会明确报错。

## 审查结论

正确性：真实播放推进与时间跳转检查通过，保留此前首帧非负时钟修复。可读性：公共效果与场景分离，七类共享有限入口，未构建万能布局器。架构：独立效果库、版本定义和图板同源，未注册通用后端。安全：无凭据/外部脚本、文字用textContent、导出参数数组。性能：当前场景有限对象，Canvas粒子≤24、DPR≤2、清屏重绘、编码回压；未对未测设备给出性能保证。未新增依赖，用户视觉批准仍待完成。
