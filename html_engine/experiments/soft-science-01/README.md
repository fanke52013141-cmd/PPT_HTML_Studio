# 柔和彩色科普：单主体解释页

契约0.9.0、HPS-026—037。V05柔和科普插画与V02编辑图文结合。当前是单主体解释页的独立风格实验，不是已发布通用模板或应用集成。内容基于项目已有[知识来源](../../../docs/styles/science-explainer/content-sources.md)。

## 本次流程

先定义讲解对象、出现顺序、实现分工与资产预算，保存scene-definition.json。建立共享theme.css的六种效果参考并实际截图，再向生图模型附最初风格板、真实效果图板和已有冷杯资产，生成一张完整设计参考。实际页按同一知识内容组装，并对照设计调整插画尺寸、间距、结论色块与杯壁目标；设计图始终只作为参考，不进入运行画面。

独立素材只复用hybrid-01的透明冷杯，一次设计参考生成、零次新增插画生成。CSS承担真实文字、字阶、编号、色块、标签和背景，SVG承担气态→液态箭头与杯外圈注/引线。当前内容没有需要Canvas表达的过程，不强加粒子。图板按版本复用，注释不进入成片。模板布局与内容是人工限定组装；尚未自动从设计图编译。

## 布局与运动

1600×900，内容区0—800px，底部100px为专用字幕区。左侧标题与三步解释，右侧单主体和杯外标注；不堆叠额外卡片。默认32px字幕可调20—44px，预览控件临时设置不会自动保存到导出；当前导出固定32px。

0—2秒标题/插画出现；2/5/8.5秒依次揭示三个解释步骤；10.5秒气态→液态关系出现并描线；12秒圈注与引线定位杯外水滴；14秒总结揭示，至18秒停留。纯时间求值、可跳帧/暂停/重播，减少装饰运动保留知识揭示。时间为人工无声预演，尚未接入已有语音/数字人。

插画含静态已有水滴，本动画用于解释来源，不能声称模拟了凝结速率或真实分子过程。杯外水滴来自空气中水蒸气；圈注位置随当前固定资产尺寸定义，更换资产须重审。

## 验证与限制

verify.cjs检查五个关键帧乱序取帧像素一致、播放推进/暂停、字幕20/32/44px和专用区域；证据在evidence/verification.json及PNG。export.cjs生成18秒1280×720/24fps/432帧无声MP4，用ffprobe和完整解码确认，视频不提交Git。缺资产明确报错。本机微软雅黑，跨机器字体分发尚待完成。

视觉检查了终态与设计对照：清晰单行标题、三步字阶、主体留白，避免圈注指向冰块。AI设计对杯子有所重绘，实际使用原资产；位置、字体与阴影不逐像素复制。完整视觉待用户审阅，不把工程检查当作模板批准。数据/逻辑页、双对象页后续分别验证，这一页不代表整套课程布局覆盖。

审查：场景与theme分离，定时/资源就绪统一，输入时间/字幕字号有边界，无外部脚本和凭据，保留原实验；未改E1/E2格式或应用服务。当前最多一个图片主体、有限对象，无循环动画或不必要Canvas开销。
