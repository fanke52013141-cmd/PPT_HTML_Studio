# 标准组件库 1.0 发布交接

2026-10-09。用户明确要求：本次成果作为后续标准组件库，代码更新到 PPT_HTML_Studio 线上仓库。

## 后续基线

以本目录 `standard-library.css`、`standard-library.js`、`standard-pages.json` 和登记组件目录为准，截图入口为 `standard/`。不要恢复被否定的自建课程模板，也不要使用历史风格实验替代标准组件规格。保留稳定 ID；外观调整优先修改公共样式，不能为每种配色重复创建业务组件。

基础参考固定为白底黑白灰；配色使用 `palettes.json`，图片风格单独提供。当前只建设静态库，动效以后复用成熟开源方案，并另行验证。

## 已交付

- 24 张 1920×1080 分类页和缩略总图。
- 32 基础组件、16 呈现变体、28 静态效果、18 组合及 5 字体。
- 内置生图设计研究及可编辑 HTML/CSS/SVG 复刻。
- 组件查询、离线 DOM 调用、构建/导出脚本、像素与内容哈希验证。
- 全页 Agent 静态审阅记录；用户要求采用为后续基线。此采用不代替未来课程页面的逐页视觉签收。

使用说明见 [STANDARD-LIBRARY.md](STANDARD-LIBRARY.md)，代码审阅和已修复问题见 [STANDARD-REVIEW.md](STANDARD-REVIEW.md)。字体目前依赖本机安装，尚未完成跨平台打包。R/D/P/V/X/H 保持固定示例范围，不冒充任意数据或拓扑引擎。生产 scene/规划器适配另行开展。

## 下一步

1. 选相关分类 PNG，搭配独立配色、图片风格和准确文案，生成完整页面设计参考。
2. 按登记 ID 将标题、正文、卡片、关系和数据还原成可编辑代码；复杂主体使用少量独立图片。
3. 对照设计稿验证字阶、比例、间距、语义和素材融合，再接入既有音频、字幕、动画链路。
4. 用多页真实内容验证一致性和效率，完成生产适配后再开展课程量产。

具体开发顺序仍见仓库的视觉参考库开发计划。本次发布不含 outputs、运行目录、数据库、依赖缓存或密钥。
