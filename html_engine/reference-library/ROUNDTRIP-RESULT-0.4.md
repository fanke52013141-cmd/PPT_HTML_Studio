## 结论与下一步

定义：PAIR-03 参考契约及此次实例适配已明确。实现：完成一次真实生图与人工静态 HTML 还原。验证：尺寸、请求参数、结算、浏览器内容/安全区/可编辑性检查完成；用户于2026-10-09连续反馈“效果不错”，认可此次静态HTML实例。该认可不自动扩展到整个参考库或其他内容。它不是自动识别或自动还原系统，也不是完整生产链路验收。

还原沿用冻结的原书本素材，未提取生成图中新书本，大小、轮廓和阴影有差异；代码改回纯白背景。不能宣称像素级还原或完整素材拆分。当前页面适配 CSS 只属于实验实例，不能直接升级为公共模板。运行脚本的截图/验证秒数不是人工还原耗时。

单例未建立可比较的人工计时与批量返工率，所以不能量化效率提升。先评价生成与还原的美感损失；若认可，再用两组其他风格和不同内容容量复测，统一记录人工耗时、修改次数、文案错误、素材差异。需要忠实保留新主体时，再增加独立素材提取/边缘审阅；不要重复生成整页作为默认返工方式。动效继续留给后续开源方案。

复现还原：设置 HPS_CHROME 后运行 `node html_engine/reference-library/reconstruct-experiment.cjs`，需要本地基准和本次实际生成图。生图测试脚本增加官方模型选项，保持默认 VIP 行为；官方 payload 转换只存在实验客户端，未更改应用的生产适配器。生图需要授权凭据且会产生新付费任务，不属于普通离线复现。
