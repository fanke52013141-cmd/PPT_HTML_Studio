# 基础样式审核与精修

## 结论

常用基础类别够启动，但不完整；基础美感此前不足，问题集中在展示容器喧宾夺主、层级对比弱、卡片差异过小，而不是代码表现能力不足。本轮已精修基础外观，仍需要继续完善呈现变体，不能把工程通过当美感通过。

| 类别 | 当前覆盖 | 缺口与优先级 |
| --- | --- | --- |
| 文字 | 主/副/分组标题、正文、解释、注释、强调、数字 | 优先补同一语义的编号式、边线式、编辑式呈现；不是新增组件 ID |
| 容器 | 平面、描边、柔影、编号 | 优先补标题区/内容区及引用呈现规则，避免所有信息都卡片化 |
| 关系 | 四种箭头、分支、汇合、循环、层级 | 补标签位置、节点长文与多节点容量；当前不是自动布线器 |
| 数据 | 数量、比例、对照、时间 | 缺坐标轴/图例/误差及真实数据接口，需独立定义 |
| 形状/标注 | 基本几何、胶囊、徽章、括号、引线 | 缺完整统一图标系列与语义锚点 |
| 效果 | 28 项渐变、阴影、描边等 | 应选择性使用；强光、纹理和文字描边不能默认铺满 |
| 专业表达 | 暂未覆盖 | 公式/化学式/复杂科学结构按真实内容需求补齐 |

## 已落地

移除样例外层灰色圆角框，参考板恢复白底；展示分隔线与组件自身边框区分。修复小标题 section 类名继承额外上边距。副标题降低字重，与主标题拉开差别；解释语增加轻边线。卡片调整内距、文案长度与行距，柔影采用接触/扩散多层，编号容器使用独立对齐与克制渐变。保留 32 项 ID、独立配色、统一风格原则，不改已认可课程。

## 下一步美感提升顺序

1. 在相同组件身份下登记有限呈现变体，优先标题、强调、引用、卡片；同一内容并列比较，保持黑白可读。
2. 给节点、标签、连接线建立统一线宽、端点与间距，补长短文本容量证据。
3. 用已有三套配色检查角色与对比，再与一张独立主体图检查视觉重量；配色不能弥补不合格的比例和排版。
4. 真实生成只选相关参考，验证模型是否遵循；美感评价与文字/关系正确性分别记录。

本轮没有新增组件、付费生图或动态能力。build、32 组件浏览器检查、18 组合及三套配色 PNG 导出通过；卡片和配色截图已目视检查，无裁切。新视觉仍待用户反馈。

## 第二轮整套精修（当前结果）

本轮已落实此前标题/强调/卡片变体优先建议：新增 16 项呈现并做中性/彩色实际图板，语义仍为原 32 项。旧灰色样例框移除；字阶、解释语边线、单位比例、圆角尺度、图形线宽统一精修。关系 SVG 的分支/汇合添加完整目的节点，时间节点增加浅面与中心点。静态效果板降低展示边框与强阴影，组合示例收轻渐变和重点浮层投影。

修复真实发现的样式冲突：通用强调规则曾覆盖 PV05–PV07，使三种呈现看起来相同，已调整选择器并用实际计算样式核验差异。字体通过浏览器实际字形检查（PV03 确认 Noto Serif SC）；32 基础预览、16 变体及文字范围无溢出，18 组合和 3 历史示例检查通过。导出时曾遇到打开的 PNG 文件写入冲突，改为完整字节经同目录临时文件原子替换后成功。

已有源代码、目录、查询、PNG 与验证证据同步；新版美感需要查看实际截图评价，不能把通过验证称为用户已批准。固定关系/数据示例、字体跨环境与生产适配限制不变。下一步重点是参考输入真实试点及缺口内容容量，而非继续堆装饰。
