蒸发让液态水进入空气；凝结让水蒸气回到液态。熟悉的现象，指向相反方向的变化。

蒸发

蒸发是液态水变成水蒸气的过程；水不必先沸腾。湿衣物变干时，水进入周围空气；它没有凭空消失，只是换了状态。

配图展示同一相变机制，不把容器误说成衣物本身。

凝结

凝结是水蒸气变成液态水的过程。冷饮杯外的水滴来自杯子周围的空气，并不是杯中液体漏出。

水蒸气通常不可见；图中的小球仅为分子示意，不代表真实大小或数量。

看见的是水滴；看不见的水蒸气，仍在空气中。
