# 柔和彩色科普参考风格样板

2026-10-08；visual-review。用户否定了V1预览的视觉风格：虽然工程检查通过，却丢失原参考的图标、容器、渐变和层次。本目录是针对该偏差的实际代码样板，不替代完整生产运行格式。

[打开样板](index.html)，默认显示完整终态，再播放讲解。页面内可展开原参考图。当前只还原参考板中“内容讲解页”的设计语言，不声称已实现其中封面、图表或整套模板。两个内容用于验证组件复用，并非两张不同布局的课程成品。

## 源文件归属

- [style.json](style.json)：风格参数，包括色彩、渐变、文字角色及外观数值。
- [layout.json](layout.json)：画布、安全区、内容和主体区域的位置、尺寸。
- [content.cjs](content.cjs)：从V1已有课程取文字、状态、字幕和资产引用，选择语义图标和色彩角色。
- [icons.cjs](icons.cjs)、[components.css](components.css)、[sample.cjs](sample.cjs)：公共标题行、知识条、观察卡、关系条及字幕组件；图标为自行绘制的统一SVG，未新增图标生图。

CSS数值包含组件内部的固定结构，例如图标盒、内容间距和辅助标签字阶；这些是本样板公共呈现变体的一部分，并非已开放给作者的任意样式接口。此样板未提供JSON编辑器，也未扩写hps.visual.scene 0.1.0。

复用E1资源哈希/解码/尺寸/透明边界校验与contain/缓动工具。每页仅一个既有独立PNG主体；圈注绑定资产锚点。字幕保持y=800的固定100px区域，字号20—44；全文说明由字幕承载。主体自然比例未改变，无整页图片、OCR切层或新增生图。

在 html_engine 目录执行：

```powershell
node visual/style-review/build.cjs
node visual/style-review/verify.cjs
```

修改源文件后重建sample.js，CSS直接刷新；生成bundle不可单独手改。[验证记录](evidence/verification.json)覆盖两内容、原参考加载、跳转确定性、锚点与窗口缩放、固定字幕区域、字号、播放/暂停/继续及页面异常。终态：[冷杯](evidence/condensation.png)、[蒸发](evidence/evaporation.png)。

## 尚未达到的目标

写实插画仍沿用旧资产，不承诺与参考图的柔和3D插画材质完全一致。没有新增封面、数据图表页、多页规划和设计模型接入。独立样板的渐变/图标/面板能力还未登记为新版本生产Schema。

样板运行检查通过，仅表示能稳定呈现和播放。视觉是否符合原参考，仍待用户审阅。下一步应先确认实际视觉，再将这些公共呈现变体和风格参数按显式版本接回统一渲染，而不是继续扩充未经批准的生产流程。

规则与特征对应见[参考风格还原检查](../../../docs/styles/science-explainer/reference-fidelity-review.md)。
