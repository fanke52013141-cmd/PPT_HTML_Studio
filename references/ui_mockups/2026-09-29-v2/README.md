# 现有功能约束下的 UI 排布参考（修订版）
日期：2026-09-29。使用内置 imagegen 生成。第一版概念稿作废，不作为实现依据。

## 用户规则
以现有分镜规划为样板，只优化现有功能的排布、间距、尺寸、对齐与视觉层级。不能为了图好看增加功能、虚构状态或改变工作流。功能以代码和真实页面为准，生成图不构成功能需求。

## 核对依据
- static/index.html：五页现有控件与容器。
- static/ai_mask_extension.js、static/mask_workspace.js：AI 标注设置/执行，画笔橡皮，语块与旁白关联。
- static/narration_audio.js：逐页旁白 textarea、单独生成和页级原生 audio。
- static/annotations_workspace.js、static/annotations_editor.js：讲稿、候选、标注与完整属性表单。
- static/digital_human_panel.js：上传/ComfyUI、空白定位画布、裁切和六个位置/缩放参数。
- static/output_render.js：视频播放器、语速版本、下载/删除、独立 PPTX 记录。
- docs/ui-spec.md：分镜规划的公共页面规范。
- 幻灯片内容参考实际项目 ac8d47c4_230536 的 slide_001/visual_draft.png。

## 生成图的已知偏差（不可照图实现）
- 五图公共侧栏、状态点/徽标、顶部标题栏的高度与控件字号仍有差异，统一沿用现有分镜规划实现：顶部 56px、标题栏 59px、侧栏 256px、步骤项 40px、按钮 30px，不随图片放大。
- 勾画页仍画成下划线页签；实际统一用分镜规划的紧凑圆角页签。
- 个别图省略状态图例、弱化或误画完成状态；状态必须来自真实项目，数字人禁用仍保留第 7 步且不计必需进度。
- Mask 图中的矩形角点仅用于示意覆盖范围，不新增拖拽矩形 Mask 功能，保留精确 Mask 和既有画笔/橡皮。
- 数字人示意图的裁切手柄位置未完全遵守现有左上角手柄，实现沿用原交互。
- 视频时间、日期、页数及输入内容仅为图示，不写入项目数据。幻灯片实际显示原始图片，不用图中重绘内容替换。
- 图只展示一种可见状态：ComfyUI 工作流/头像上传、生成全部页、音频空态/失败态、历史输出等现有功能仍保留。
- 生产页面已据此调整标题栏下方的内容区；侧栏、全局顶部和各页标题栏仍沿用原样。

## 落地备注
- `static/workspace_content.css` 仅作用于 AI Mask、旁白与音频、勾画标注、数字人讲解、作品输出五页的内容区；`static/index.html` 加载该样式并调整已有控件的排布。
- AI Mask 的确认按钮放在语块列表底部，列表可独立滚动，按钮容器压缩；旁白页缩小页卡、输入框与音频状态的上下间隔。
- 数字人页取消三栏等高，把已有的整段语音导出移到右侧精调区下方，按新的视觉顺序编号。没有新增功能或修改生成逻辑。
- 验证：`node checks/test_frontend_quality.js`、`node checks/test_visible_flow.js` 均通过，并在本地页面核对三处实际布局。
