## 动效说明(重要)

Stitch MCP **没有动效接口**,只能产静态设计稿。已内置/建议的动效标注:

- 已内置(Stitch 生成的 HTML 自带,网页端预览可交互):按钮 hover 变色/按压 scale(.95)、卡片 hover 上浮+边框变橙、菜单/下拉 hover 展开、聚焦橙色光环。
- 需前端实现(按本记录落地):弹窗打开 = 遮罩 rgba(0,0,0,.45) 淡入 + 弹窗 scale(.96→1) 200ms;Tab 切换 = 面板 150ms 淡入;侧栏步骤切换 = 当前行 #FFF5F0 过渡 150ms;列表卡片入场 = fadeInUp 依次 stagger 50ms;进度条段位填充动画 300ms。

3. 各屏 Token 示意图为示意重绘,生产页面显示原始图片。
